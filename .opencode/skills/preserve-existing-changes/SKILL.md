## 既存変更の保護原則

作業開始時点ですでに存在する変更は、すべて**ユーザーによる変更**として扱います。

* **変更の保護:** AI エージェントは、ユーザーの既存変更を削除、復元、退避してはなりません。ただし、追記は許可します。
* **作業環境の扱い:** 現在の作業ディレクトリーを「作業開始時の状態」としてそのまま受け入れ、その状態に対して自身の変更を追記します。

## 作業開始時の手順

1. **Git の状態確認**

最初に必ず以下のコマンドを実行し、現在のステータスと差分を確認します。

```bash
git status --short
git diff
git diff --cached
```
2. **バックアップの作成**

作業開始時点ですでに存在する変更を持つファイルをバックアップします。

* **退避先ディレクトリ構造:** 作業ディレクトリー内の `.tmp-ai/<YYYYMMDD-HHMMSS>/` （例: `.tmp-ai/20260919-123456/`）
* **配置ルール:** 対象となるトップレベルのディレクトリーやファイルを作業開始時点の状態のまま、バックアップディレクトリー直下へコピーします。
* **構成例 (`src/foo.ts`, `packages/bar/index.ts`, `README.md` が変更された状態の場合):**
```text
.tmp-ai/20260919-123456/
├── src/
     └── foo.ts
├── packages/
     └── bar
          └── index.ts
└── README.md
```

## 禁止事項

既存変更の処理・整理を目的とした、以下の Git 操作を**固く禁止**します。

* `git restore`
* `git checkout`
* `git reset`
* `git stash`
* `git clean`

**特に警戒すべき破壊的操作:**

```bash
git reset --hard
git restore .
git checkout -- .
git clean -fd
```

* **禁止される回避策:** 「一時的に変更を削除し、作業完了後に元に戻す」といったアプローチも一切禁止します。

## 作業終了時の手順

1. **状態の再確認**

作業完了後、作業開始時の既存変更が問題なく保持されていることを確認します。

```bash
git status --short
git diff
git diff --cached
```

2. **バックアップの保持**
作成したバックアップ（`.tmp-ai/` 配下）は、作業完了後も削除せず残してください。
