Suru UI は、React 向けの UI コンポーネントライブラリーです。フォーム、ナビゲーション、オーバーレイ、データ表示など、アプリケーションを組み立てるためのコンポーネントを提供しています。

## ドキュメントの構成 [#documentation-structure]

このサイトは Diátaxis の考え方に基づき、読者の目的に合わせて 4 つの区分に分かれています。

| 区分           | 目的                   | 向いている場面                               |
| -------------- | ---------------------- | -------------------------------------------- |
| はじめに       | 実際に手を動かして学ぶ | 初めて Suru UI を使う                        |
| ガイド         | 特定の課題を解決する   | コンポーネントの合成、外観のカスタマイズ     |
| コンポーネント | 仕様を調べる           | props や状態、CSS のフックを確認する         |
| 説明           | 設計意図を理解する     | プリセット、パーツ、Base UI の役割を把握する |
