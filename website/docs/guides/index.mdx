## 読み方 [#how-to-read]

ガイドは、すでに Suru UI のセットアップが完了していることを前提としています。まだセットアップしていない場合は、先に[インストール](/getting-started/installation)を完了してください。

各ガイドは独立しています。すべてを順番に読む必要はありません。Button の具体的な props や型を調べたい場合は、[Button のリファレンス](/components/button)を参照してください。
