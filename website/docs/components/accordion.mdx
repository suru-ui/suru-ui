Accordion は、複数の項目を折りたたんで表示するコンポーネントです。FAQ や設定項目など、情報量の多いページで、必要な内容だけを展開して読めるようにします。`items` に項目を渡すと、見出しとパネルが自動で構成されます。

## 使い方 [#basic-usage]

`items` の各項目には、見出しの `title` とパネルの `content` を指定します。`defaultValue` には、最初から開いておく項目の `value` を配列で渡します。

<Component path="accordion/basic" />

項目の値は `value` で指定します。`value` を省略した場合はインデックスが使われます。`disabled` を `true` にすると、その項目だけを無効にできます。

```tsx
<Accordion
  items={[
    { value: "profile", title: "プロフィール", content: "..." },
    { value: "security", title: "セキュリティー", content: "...", disabled: true },
  ]}
  defaultValue={["profile"]}
/>
```

## 複数の項目を開く [#multiple]

既定では、同時に開ける項目は 1 つだけです。`multiple` を指定すると、複数の項目を同時に展開できます。`defaultValue` に複数の値を渡す場合は、`multiple` も指定してください。

<Component path="accordion/multiple" />

## 状態と区切り線 [#states]

`separator` は隣接する項目の区切り線を、`indicator` は開閉状態を示すインジケーターを制御します。`indicator={false}` を指定するとインジケーターを非表示にできます。`size` と `radius` で大きさと角丸を調整できます。

<Component path="accordion/states" />

項目ごとの `disabled` に加えて、ルートの `disabled` で全体を無効にできます。全体を無効にした場合も、開いている項目の内容はそのまま表示されます。

`className`、`style`、`render` も利用できます。`className` と `style` には状態を受け取る関数を渡せます。残りの props は Base UI の Accordion から継承します。

## スタイル [#styling-hooks]

ルート要素には `sui_accordion` が付与されます。props に応じて、`sui_accordion-size_md`、`sui_accordion-radius_none`、`sui_accordion-separator`、`sui_accordion-disabled`、`sui_accordion-orientation_vertical` などのクラス名も加わります。

内部のパーツには `sui_accordion_item`、`sui_accordion_heading`、`sui_accordion_trigger`、`sui_accordion_indicator`、`sui_accordion_content` が付与されます。開いている項目には `sui_accordion_item-open`、`sui_accordion_trigger-open` などの状態クラスが加わります。

`className` や `style` で調整できるほか、CSS 変数を使って余白や境界線を上書きできます。
