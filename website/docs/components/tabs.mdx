Tabs は、関連する複数のパネルをタブで切り替えるコンポーネントです。`items` にタブのラベルと内容を並べると、タブ一覧と対応するパネルが自動で組み立てられます。矢印キーでタブ間を移動でき、`Enter` または `Space` で選択できます。

## 使い方 [#basic-usage]

`items` の各項目に `label`、`value`、`content` を指定します。`defaultValue` には最初に表示するタブの `value` を渡します。`content` を省略した項目にはパネルが作られません。

<Component path="tabs/basic" />

タブの幅はルート要素の幅に従います。`style` で幅を指定すると、レイアウトに合わせて調整できます。

## 外観 [#appearance]

`variant` は `line` と `segments` から選択できます。`segments` では `activeVariant` を組み合わせて、選択中のタブの塗りつぶしを変えられます。

<Component path="tabs/appearance" />

`size` は `sm`、`md`、`lg` の 3 段階で、`thin` を指定すると上下の余白が半分になります。`radius` の既定値は `size` と同じ値です。

## 配置と制御 [#orientation-and-controlled]

`orientation` に `vertical` を指定すると、タブが縦方向に並びます。キーボードの矢印キーも方向に合わせて動作します。

<Component path="tabs/vertical" />

選択中のタブを自分で管理する場合は、`value` と `onValueChange` を組み合わせます。`onValueChange` は変更後の値を受け取ります。

<Component path="tabs/controlled" />

`items` の項目に `disabled` を指定すると、そのタブは選択できなくなります。無効なタブをクリックしても、現在の値は変わりません。

## スタイル [#styling-hooks]

ルート要素には `sui_tabs` が付与されます。props に応じて `sui_tabs-size_md`、`sui_tabs-radius_md`、`sui_tabs-variant_line`、`sui_tabs-active_variant_liquid`、`sui_tabs-outlined`、`sui_tabs-thin`、`sui_tabs-orientation_horizontal` などのクラス名も加わります。

内部のパーツには `sui_tabs_list`、`sui_tabs_tab`、`sui_tabs_indicator`、`sui_tabs_panel` が付与されます。選択中のタブには `sui_tabs_tab-active`、無効なタブには `sui_tabs_tab-disabled` が加わります。
