Tooltip は、要素にポインターを合わせるかフォーカスしたときに、短い補足を表示するコンポーネントです。アイコンだけのボタンや省略されたラベルに、意味を補足するために使います。トリガーとポップアップは自動で関連付けられ、エスケープキーでも閉じられます。

## 使い方 [#basic-usage]

`trigger` にツールチップを表示する要素を、`children` に補足の内容を指定します。トリガーにはフォーカス可能な要素を渡してください。

<Component path="tooltip/basic" />

`delay` は表示までの待ち時間をミリ秒で指定します。`closeDelay` は閉じるまでの待ち時間です。既定では表示まで 600 ミリ秒待ちます。

## 配置 [#placement]

`side` で表示する方向を、`align` でその方向に対する揃え方を指定します。`sideOffset` と `alignOffset` でトリガーからの距離を調整できます。

<Component path="tooltip/positions" />

`showArrow` を指定すると、ポップアップとトリガーをつなぐ矢印が表示されます。矢印の見た目は `slotProps.arrow` で調整できます。

## 制御と分離 [#controlled-and-detached]

開閉状態を自分で管理する場合は、`open` と `onOpenChange` を組み合わせます。`keepOpenOnClick` を `true` にすると、トリガーをクリックしても閉じません。

<Component path="tooltip/controlled" />

トリガーとポップアップを別の場所に置く場合は、`Tooltip.createHandle` で作成したハンドルを `Tooltip.Trigger` と `Tooltip` の両方に渡します。

<Component path="tooltip/detached" />

## スタイル [#styling-hooks]

ポップアップには `sui_tooltip_popup` が付与されます。props に応じて `sui_tooltip_popup-size_md`、`sui_tooltip_popup-radius_md`、`sui_tooltip_popup-outlined`、`sui_tooltip_popup-open`、`sui_tooltip_popup-side_top`、`sui_tooltip_popup-align_center` などのクラス名も加わります。

トリガーには `sui_tooltip_trigger`、配置要素には `sui_tooltip_positioner`、矢印には `sui_tooltip_arrow`、ポータルには `sui_tooltip_portal` が付与されます。`Tooltip` のルート自体は HTML 要素を描画しません。
