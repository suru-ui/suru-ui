Autocomplete は、入力した文字列に応じて候補を絞り込む入力欄です。検索フォームや項目選択など、候補が多い場面で入力を補助します。文字列の配列のほか、表示ラベルと値を組にしたオブジェクトや、グループ化した項目を渡せます。

## 使い方 [#basic-usage]

`items` に候補の一覧を、`placeholder` に入力欄の案内文を指定します。入力欄をクリックするか文字を入力すると、候補のポップアップが開きます。候補がないときは `empty` の内容が表示されます。

<Component path="autocomplete/basic" />

`items` には文字列のほか、`{ label, value }` を持つオブジェクトも渡せます。オブジェクトを使う場合は、`value` が選択値、`label` が候補の表示に使われます。

```tsx
<Autocomplete
  items={[
    { label: "東京都", value: "13" },
    { label: "大阪府", value: "27" },
  ]}
  placeholder="都道府県を検索"
/>
```

## グループ化 [#grouped]

`items` に `{ label, items }` を持つグループの配列を渡すと、グループごとに見出しと区切り線を付けて表示します。`separator={false}` を指定すると、グループ末尾の区切り線を非表示にできます。

<Component path="autocomplete/grouped" />

グループ内の項目にも、文字列または `{ label, value }` のオブジェクトを指定できます。グループの `label` を省略すると、見出しは描画されません。

## 外部で絞り込む [#filtering]

`filter={null}` を指定すると、コンポーネント内部の絞り込みを無効にできます。この場合は `filteredItems` に表示する候補を渡します。検索 API の結果や独自の照合ロジックを使うときに適しています。

<Component path="autocomplete/filtered" />

`onValueChange` で入力値を取得し、その値に応じて `filteredItems` を更新します。`status` に件数や読み込み状態を渡すと、スクリーンリーダーにも状態が伝わります。

## スタイル [#styling-hooks]

入力グループには `sui_autocomplete` が付与されます。props に応じて、`sui_autocomplete-size_md`、`sui_autocomplete-color_blue`、`sui_autocomplete-radius_md`、`sui_autocomplete-variant_liquid`、`sui_autocomplete-outlined`、`sui_autocomplete-open`、`sui_autocomplete-disabled`、`sui_autocomplete-readonly`、`sui_autocomplete-focused` などのクラス名も加わります。

内部のパーツには `sui_autocomplete_input`、`sui_autocomplete_item`、`sui_autocomplete_group`、`sui_autocomplete_group_label`、`sui_autocomplete_empty`、`sui_autocomplete_popup` などが付与されます。候補の強調表示には `sui_autocomplete_item-highlighted` が使われます。

`className` や `style` で調整できるほか、CSS 変数を使って幅や余白を上書きできます。
