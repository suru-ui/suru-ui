Combobox は、入力欄で候補を絞り込みながら、定義済みの項目から値を選ぶコンポーネントです。単一選択と複数選択の両方に対応し、候補が多い場面や、入力に合わせて候補を取得する場面で使います。入力欄をポップアップの中に置く配置にも切り替えられます。

## 使い方 [#basic-usage]

`items` に候補の配列を指定し、`placeholder` に入力欄の案内文を渡します。文字を入力すると、既定のフィルターが候補を絞り込みます。

<Component path="combobox/basic" />

候補が 1 件もないときは `empty` の内容が表示されます。`status` は、非同期検索の進行状況などをスクリーンリーダーへ伝えるために使います。

## 複数選択 [#multiple]

`multiple` を指定すると、複数の値を選択できます。選択値はチップとして入力欄に表示され、チップの削除ボタンから選択を解除できます。

<Component path="combobox/multiple" />

`keepFilterOnSelect` を `true` にすると、項目を選んだ後も入力欄の絞り込みを維持し、ポップアップを開いたままにできます。

## グループ化 [#grouping]

`items` に `label` と `items` を持つオブジェクトを並べると、グループごとに見出しと区切り線を付けて表示します。`separator={false}` でグループ末尾の区切り線を消せます。

<Component path="combobox/grouped" />

## 非同期検索 [#async-search]

候補をサーバーから取得する場合は、`filter={null}` で既定の絞り込みを無効にし、`onInputValueChange` で入力値を受け取って `items` を更新します。`status` に検索中やエラーのメッセージを渡すと、状態が読み上げられます。

<Component path="combobox/async-search" />

`itemToStringLabel` は、選択値を入力欄やチップに表示する文字列へ変換します。`isItemEqualToValue` を指定すると、項目の同一性を独自に判定できます。

### slotProps [#slot-props]

`slotProps` では、既定のレンダラーが組み立てる各パーツへ props を渡せます。

| キー                | 説明                                                                            |
| ------------------- | ------------------------------------------------------------------------------- |
| `addon`             | 入力欄の付属要素です。`children` は `startAddons` と `endAddons` で指定します。 |
| `arrow`             | ポップアップの矢印です。                                                        |
| `backdrop`          | ポップアップの背景です。                                                        |
| `chip`              | 複数選択時のチップです。`value` は選択項目から渡されます。                      |
| `chipRemove`        | チップの削除ボタンです。                                                        |
| `chips`             | チップをまとめる要素です。                                                      |
| `clear`             | 選択値を消去するボタンです。                                                    |
| `collection`        | グループ内の項目を描画するコレクションです。                                    |
| `content`           | スクロール領域の内容です。                                                      |
| `corner`            | スクロール領域の角です。                                                        |
| `display`           | 入力欄の代わりに選択値を表示する要素です。                                      |
| `empty`             | 候補がないときの表示です。`children` は `empty` で指定します。                  |
| `group`             | 候補のグループです。                                                            |
| `groupLabel`        | グループの見出しです。                                                          |
| `icon`              | 入力欄の末尾に表示するアイコンです。                                            |
| `input`             | 検索用の入力欄です。                                                            |
| `inputGroupInPopup` | ポップアップ内の入力グループです。                                              |
| `item`              | 候補項目です。                                                                  |
| `itemIndicator`     | 選択済みの候補に表示するインジケーターです。                                    |
| `list`              | 候補リストです。                                                                |
| `popup`             | 候補を表示するポップアップです。                                                |
| `portal`            | ポップアップを描画するポータルです。                                            |
| `positioner`        | ポップアップの配置を制御する要素です。                                          |
| `scrollArea`        | 候補リストのスクロール領域です。                                                |
| `scrollbar`         | スクロールバーです。                                                            |
| `separator`         | グループの区切り線です。                                                        |
| `status`            | 検索状態を読み上げる要素です。                                                  |
| `thumb`             | スクロールバーのつまみです。                                                    |
| `trigger`           | 入力欄をポップアップ内に置く場合のトリガーです。                                |
| `value`             | 選択値の表示です。`children` で独自のレンダラーを指定できます。                 |
| `viewport`          | スクロール領域のビューポートです。                                              |

## スタイル [#styling-hooks]

入力グループには `sui_combobox` が付与されます。状態に応じて、`sui_combobox-size_md`、`sui_combobox-color_blue`、`sui_combobox-radius_md`、`sui_combobox-variant_liquid`、`sui_combobox-outlined`、`sui_combobox-open`、`sui_combobox-disabled`、`sui_combobox-placeholder` などのクラス名も加わります。

ポップアップには `sui_combobox_popup` が付与され、`sui_combobox_popup-size_*`、`sui_combobox_popup-open`、`sui_combobox_popup-empty`、`sui_combobox_popup-side_*`、`sui_combobox_popup-align_*` などが状態に応じて加わります。

候補項目には `sui_combobox_item` が付与され、`sui_combobox_item-selected`、`sui_combobox_item-highlighted`、`sui_combobox_item-disabled` などの状態クラスも付きます。チップには `sui_combobox_chip` が付与されます。
