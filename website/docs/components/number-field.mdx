NumberField は、数値の入力に特化したテキストフィールドです。増減ボタンやキーボード操作、ドラッグによる値の変更に対応し、最小値・最大値・刻み幅を指定できます。金額や数量など、数値を厳密に扱う入力欄に適しています。

## 使い方 [#basic-usage]

`defaultValue` に初期値を指定し、`scrubArea` に表示名を渡すと、入力欄の上にラベルが表示されます。`decrement` と `increment` を指定すると、値を減らすボタンと増やすボタンが表示されます。

<Component path="number-field/basic" />

`decrement` と `increment` に `true` を渡すと既定のアイコンが表示されます。任意の要素を渡すと、その要素がボタンの内容になります。

## 操作と状態 [#interactions]

`scrubArea` を指定すると、ラベルをドラッグして値を変更できる領域が表示されます。入力欄にフォーカスした状態では、上下の矢印キーでも値を増減できます。Shift キーを押しながら操作すると `largeStep`、Alt キーを押しながら操作すると `smallStep` の幅で変化します。

`value` と `onValueChange` を使うと、値を外部の状態で管理できます。`onValueChange` の値は `number | null` であるため、空の入力も扱えます。

<Component path="number-field/controlled" />

`disabled` と `readOnly` は入力そのものを制限します。`allowOutOfRange` を指定すると、直接入力した値が `min` と `max` の範囲を超えることを許可できます。ボタンやキーボードによる増減は、この指定にかかわらず範囲内に収まります。

<Component path="number-field/states" />

## 接頭辞と接尾辞 [#addons]

`startAddons` と `endAddons` を使うと、入力欄の先頭と末尾に任意の内容を表示できます。通貨記号や単位などを添えるときに便利です。

```tsx
<NumberField
  defaultValue={1000}
  startAddons={[<JapaneseYenIcon aria-hidden="true" />]}
  endAddons={["円"]}
/>
```

## 外観 [#appearance]

`variant` は `naked` と `liquid` から選択できます。`color`、`size`、`radius`、`outlined` を組み合わせて、入力欄の見た目を調整できます。

### slotProps [#slot-props]

| キー              | 説明                                                                         |
| ----------------- | ---------------------------------------------------------------------------- |
| `addon`           | 入力欄の先頭と末尾のアドオンに渡す props です。                              |
| `decrement`       | 値を減らすボタンに渡す props です。                                          |
| `group`           | 入力欄とボタンをまとめるグループに渡す props です。                          |
| `increment`       | 値を増やすボタンに渡す props です。                                          |
| `input`           | 入力欄に渡す props です。`aria-label` や `autoComplete` などを指定できます。 |
| `scrubArea`       | ドラッグ領域に渡す props です。                                              |
| `scrubAreaCursor` | ドラッグ中のカーソルに渡す props です。                                      |

## スタイル [#styling-hooks]

ルート要素には `sui_number_field` が付与されます。props と状態に応じて、`sui_number_field-size_md`、`sui_number_field-color_blue`、`sui_number_field-radius_md`、`sui_number_field-variant_naked`、`sui_number_field-outlined`、`sui_number_field-disabled`、`sui_number_field-focused`、`sui_number_field-invalid` などのクラス名も加わります。

内部のパーツには、`sui_number_field_group`、`sui_number_field_input`、`sui_number_field_addon`、`sui_number_field_increment`、`sui_number_field_decrement`、`sui_number_field_scrub_area` などのクラス名が付与されます。
