CheckboxGroup は、複数の Checkbox を 1 つの選択グループとしてまとめるコンポーネントです。選択値の配列を管理し、グループ内の Checkbox へ大きさや配色などの外観をまとめて伝播します。

## 使い方 [#basic-usage]

子の Checkbox に `value` を指定し、`defaultValue` または `value` に選択値の配列を渡します。ラベルは `label` 要素で囲んでください。

<Component path="checkbox-group/basic" />

グループ内の Checkbox は、グループの `size`、`color`、`radius`、`variant`、`outlined` を継承します。個々の Checkbox に指定した外観より、グループの設定が優先されます。

## 全選択 [#select-all]

`allValues` にグループ内のすべての値を指定し、`parent` を付けた Checkbox を置くと、全選択と全解除を切り替えられます。親の Checkbox は、子の選択状態に応じてチェック済みまたは中間状態になります。

<Component path="checkbox-group/parent" />

## 向きと外観 [#orientation-and-appearance]

`orientation="horizontal"` を指定すると横並びになります。配色や大きさはグループ単位で指定できます。

グループの状態は `CheckboxGroup.useContext()` で取得できます。状態には `size`、`color`、`radius`、`variant`、`outlined`、`orientation`、`disabled` などが含まれます。ここに挙げた以外の props は Base UI の CheckboxGroup から継承します。

## スタイル [#styling-hooks]

ルート要素には `sui_checkbox_group` が付与されます。props に応じて、`sui_checkbox_group-size_md`、`sui_checkbox_group-color_blue`、`sui_checkbox_group-radius_md`、`sui_checkbox_group-variant_liquid`、`sui_checkbox_group-outlined`、`sui_checkbox_group-orientation_horizontal` などのクラス名も加わります。

無効状態では `sui_checkbox_group-disabled`、検証状態では `sui_checkbox_group-invalid` や `sui_checkbox_group-valid` が付与されます。
