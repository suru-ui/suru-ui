AlertDialog は、削除などの取り返しのつかない操作の前に確認を求めるモーダルダイアログです。背景を暗くし、確認または中止を選ぶまで他の操作をブロックします。タイトル、説明文、アイコン、確認ボタンと中止ボタンをまとめて構成できます。

## 使い方 [#basic-usage]

`trigger` にダイアログを開く要素を、`title` と `description` に確認内容を指定します。`cancel` と `confirm` はそれぞれ中止ボタンと確認ボタンになります。どちらも押すとダイアログが閉じます。

<Component path="alert-dialog/basic" />

`children` に要素を渡すと、説明文の下に本文として表示されます。削除される項目の一覧など、確認に必要な補足情報を置くときに使います。

```tsx
<AlertDialog
  trigger={<Button color="red">削除する</Button>}
  title="削除しますか？"
  description="この操作は取り消せません。"
  cancel={<Button variant="naked">キャンセル</Button>}
  confirm={<Button color="red">削除する</Button>}
>
  <p>削除される項目の一覧です。</p>
</AlertDialog>
```

`confirm` や `cancel` には `Button` などをそのまま渡せます。`footer` に独自の内容を渡した場合も、`cancel` と `confirm` はフッターの内容の後に配置されます。

## 外観 [#appearance]

`variant` は `default` と `stacked` から選択できます。`stacked` では見出しと説明文を中央に寄せ、操作を右上へ重ねます。`size`、`radius`、`outlined` はダイアログの大きさ、角丸、枠線を制御します。

<Component path="alert-dialog/appearance" />

`icon` にアイコンを渡すと、ヘッダーの左側に表示されます。アイコンの配色や背景は `slotProps.icon` で調整できます。`action` を省略して `showCancelIconButton` を `true` にすると、右上に閉じるアイコンボタンが表示されます。

## 開閉を制御する [#controlled]

`open` と `onOpenChange` を使うと、ダイアログの開閉を外部の状態から制御できます。`trigger` を省略し、任意のボタンから開く構成も可能です。

<Component path="alert-dialog/controlled" />

`defaultOpen` を指定すると、最初から開いた状態で表示できます。命令的に操作したい場合は `AlertDialog.createHandle()` でハンドルを作成し、`handle` に渡します。

確認ボタンの押下時に検証を行いたい場合は、`onConfirm` で問題があれば `event.preventBaseUIHandler()` を呼ぶと、ダイアログを閉じずに処理を止められます。

## スタイル [#styling-hooks]

ダイアログのポップアップには `sui_alert_dialog_popup` と、カード由来の `sui_card` が付与されます。props に応じて、`sui_alert_dialog_popup-size_md`、`sui_alert_dialog_popup-radius_md`、`sui_alert_dialog_popup-variant_stacked`、`sui_alert_dialog_popup-outlined` などのクラス名も加わります。

内部のパーツには `sui_alert_dialog_backdrop`、`sui_alert_dialog_viewport`、`sui_alert_dialog_header`、`sui_alert_dialog_icon`、`sui_alert_dialog_title`、`sui_alert_dialog_description`、`sui_alert_dialog_content`、`sui_alert_dialog_footer` が付与されます。

`className` や `style` で調整できるほか、CSS 変数を使って余白や幅を上書きできます。
