Status は、オンラインや処理中などの状態を、色付きのドットとラベルで示すコンポーネントです。ユーザーの在席状況やバックグラウンド処理の進行状態を、一覧の中で簡潔に表せます。

## 使い方 [#basic-usage]

`children` がドットの横に表示するラベルになります。`color` で状態の色を指定します。ラベルを省略すると、ドットだけを表示します。

<Component path="status/basic" />

## リップル [#ping]

`ping` を指定すると、ドットからリップルが広がるアニメーションを表示します。処理中など、状態が続いていることを目立たせたい場合に使います。

<Component path="status/ping" />

`rippleSize` はリップルの大きさです。`containRipple` を `true` にすると、リップルがはみ出す分の余白を確保し、レイアウト上の占有範囲にリップルを含めます。

## 外観 [#appearance]

`color` は 8 色から、`size` は `sm`、`md`、`lg` から選択できます。色はインジケーターのドットに適用され、ラベルの文字色は変わりません。

<Component path="status/appearance" />

### slotProps [#slot-props]

| スロット    | 型                     | 説明                                                                                  |
| ----------- | ---------------------- | ------------------------------------------------------------------------------------- |
| `indicator` | `StatusIndicatorProps` | ドットを表示するインジケーターに渡す props です。`aria-hidden` は既定で `true` です。 |

### 継承 props [#inherited-props]

Status は `span` 要素を描画します。`className`、`style`、`id`、`aria-*`、`data-*` などの属性を渡せます。`className` と `style` には `Status.State` を受け取る関数も指定でき、状態には `color`、`ping`、`rippleSize`、`size`、`containRipple` が含まれます。`render` でルート要素を置き換えられます。

## スタイル [#styling-hooks]

ルート要素には `sui_status` が付与されます。props に応じて、`sui_status-color_green`、`sui_status-size_lg`、`sui_status-ripple_size_sm`、`sui_status-ping`、`sui_status-contain_ripple` などのクラス名も加わります。

インジケーターには `sui_status_indicator` と、色、大きさ、リップルに対応するクラス名が付与されます。
