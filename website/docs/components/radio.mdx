Radio は、複数の選択肢から 1 つを選ぶためのラジオボタンです。選択状態は [RadioGroup](/components/radio-group) が管理するため、通常は RadioGroup の中で使います。同じグループ内の Radio には、それぞれ一意の `value` を指定します。

## 使い方 [#basic-usage]

RadioGroup の中に Radio を並べ、ラベルのテキストを `label` 要素で囲みます。ラベルを押しても選択できるため、選択肢全体をクリックできる領域にできます。

<Component path="radio/basic" />

`children` はインジケーターの中に表示する内容であり、ラベルではありません。通常は指定せず、既定のインジケーターを使います。ラベルは必ず `label` 要素などで関連付けてください。

```tsx
<RadioGroup defaultValue="a">
  <label>
    <Radio value="a" />
    選択肢 A
  </label>
  <label>
    <Radio value="b" />
    選択肢 B
  </label>
</RadioGroup>
```

## 外観 [#appearance]

`color`、`size`、`radius`、`variant`、`outlined` で外観を指定できます。RadioGroup の中では、グループに指定した値が個々の Radio より優先されます。

<Component path="radio/appearance" />

## 状態 [#states]

`disabled` はラジオボタンを無効にし、`readOnly` は値を変更できない状態にします。`required` はフォームの送信時に選択を必須にします。グループ全体を無効にしたい場合は、RadioGroup の `disabled` を使ってください。

### slotProps [#slot-props]

| キー        | 型                                      | 説明                                                                                             |
| ----------- | --------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `indicator` | `Omit<RadioIndicatorProps, "children">` | インジケーターに渡す props です。`keepMounted` を指定すると、未選択のときも DOM に保持できます。 |

## スタイル [#styling-hooks]

ルート要素には `sui_radio` が付与されます。props と状態に応じて、`sui_radio-size_md`、`sui_radio-color_blue`、`sui_radio-radius_full`、`sui_radio-variant_naked`、`sui_radio-outlined`、`sui_radio-checked`、`sui_radio-disabled`、`sui_radio-focused` などのクラス名も加わります。

インジケーターには `sui_radio_indicator` が付与され、選択状態に応じて `sui_radio_indicator-checked` などのクラス名も加わります。
