Toast は、操作の結果や処理の完了を一時的に通知するコンポーネントです。画面の隅に表示され、一定時間が経過すると自動で閉じます。`Toast.Provider` で通知を管理し、`Toast.useClient` で追加や削除を行います。

## 使い方 [#basic-usage]

`Toast.Provider` でアプリケーションの一部を囲み、`Toast.List` を配置します。通知を追加するコンポーネントでは `Toast.useClient` を呼び、`add` にタイトルと説明を渡します。

<Component path="toast/basic" />

`timeout` は通知が自動で閉じるまでの時間をミリ秒で指定します。`0` を指定すると自動では閉じません。`limit` は同時に表示する通知の最大数です。

## 通知の種類 [#types]

通知オブジェクトの `type` に応じて、既定の配色が決まります。`success` は緑、`info` は青、`warning` は黄色、`error` は赤になります。該当しない場合はグレーで表示されます。

<Component path="toast/types" />

配色は `Toast` の `color` で明示することもできます。`type` は通知の分類として残るため、アイコンや文言の出し分けにも利用できます。

## 操作と外観 [#actions-and-appearance]

通知に操作ボタンを付ける場合は、`actionProps` にボタンの内容とクリック時の処理を指定します。`Toast.List` の `children` に関数を渡すと、各通知を個別にカスタマイズできます。

<Component path="toast/action" />

`close` には閉じるボタンの文言を指定します。省略すると「閉じる」が表示されます。`actionsPosition` と `descriptionPosition` で、操作ボタンと説明文の配置を調整できます。

### 継承 props [#inherited-props]

`Toast` は Base UI の Toast を基盤にしているため、`swipeDirection` でスワイプして閉じる方向を指定できます。既定値は `["down", "right"]` です。`className`、`style`、`aria-*`、`data-*` などの属性もルート要素に渡せます。

## スタイル [#styling-hooks]

通知のルート要素には `sui_toast` が付与されます。状態に応じて `sui_toast-transition_status_starting`、`sui_toast-limited`、`sui_toast-swiping`、`sui_toast-expanded`、`sui_toast-type_success` などのクラス名も加わります。

内容には `sui_toast_content`、見出しには `sui_toast_title`、説明文には `sui_toast_description`、操作ボタンには `sui_toast_action`、閉じるボタンには `sui_toast_close` が付与されます。表示領域は `sui_toast_viewport`、ポータルは `sui_toast_portal` です。
