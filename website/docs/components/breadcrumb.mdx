Breadcrumb は、現在のページまでの階層をパンくずリストとして表示するコンポーネントです。サイト内の位置を伝え、上位のページへ移動しやすくします。`items` に項目を並べると、最後の項目が現在のページとして扱われます。

## 使い方 [#basic-usage]

`items` の各項目には `label` と `href` を指定します。`href` を省略した項目は遷移先を持たない項目として表示されます。最後の項目は自動的に現在のページとして扱われ、`aria-current="page"` を持つ `span` として描画されます。

<Component path="breadcrumb/basic" />

`current` を明示すると、最後の項目以外を現在のページとして扱えます。`disabled` を `true` にすると、その項目のリンクを無効にできます。

```tsx
<Breadcrumb
  items={[
    { href: "/", label: "ホーム" },
    { href: "/products", label: "製品", disabled: true },
    { label: "Suru UI" },
  ]}
/>
```

## 省略表示 [#collapsed]

`maxItems` を指定すると、項目数がその値を超えたときに省略記号へまとめます。省略記号を押すと、省略された項目を選択するための候補リストが開きます。

<Component path="breadcrumb/collapsed" />

`maxItems` は 3 未満の値が 3 として扱われます。先頭の項目と末尾側の項目を残し、それ以外が省略の対象になります。`items` の数が `maxItems` 以下なら、省略表示は行われません。

## リンクの状態 [#link-states]

`disabled` を指定した項目は、リンク先へ遷移できなくなります。現在のページの項目はリンクではなく `span` として描画され、`href` は付与されません。

<Component path="breadcrumb/states" />

`slotProps.link` を使うと、すべてのリンクに同じ props を渡せます。ただし、`children`、`current`、`href` は項目ごとの値で上書きされます。

### 継承 props [#inherited-props]

Breadcrumb は `nav` 要素を描画するため、`className`、`style`、`id`、`aria-*`、`data-*` などの属性を渡せます。`aria-label` の既定値は「パンくずリスト」です。残りの props はベースの `nav` 要素から継承します。

## スタイル [#styling-hooks]

ルート要素には `sui_breadcrumb` が付与されます。props に応じて、`sui_breadcrumb-size_md`、`sui_breadcrumb-color_grey` などのクラス名も加わります。

内部のパーツには `sui_breadcrumb_list`、`sui_breadcrumb_item`、`sui_breadcrumb_link`、`sui_breadcrumb_separator` が付与されます。現在のページのリンクには `sui_breadcrumb_link-current`、無効なリンクには `sui_breadcrumb_link-disabled` が加わります。

`className` や `style` で調整できるほか、CSS 変数を使って余白や文字色を上書きできます。
