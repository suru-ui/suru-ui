Progress は、時間のかかる処理の進捗を表示するコンポーネントです。ファイルのアップロードやデータの読み込みなど、完了までの過程を示すときに使います。`value` に `null` を指定すると、進捗が定まらない不確定状態になります。

## 使い方 [#basic-usage]

`value` に 0 から `max` までの現在値を指定します。`label` を指定すると、ラベルと現在値が表示されます。

<Component path="progress/basic" />

`value` が `max` に達すると、ルートに完了状態のクラス名が付与されます。ラベルには完了したことを示す文言を渡すと、状態が伝わりやすくなります。

## 不確定状態 [#indeterminate]

処理時間が読めない場合は、`value` に `null` を指定します。インジケーターは不定のアニメーションで表示され、支援技術には進捗が確定していないことが伝わります。

<Component path="progress/indeterminate" />

## 値の書式 [#format]

`format` に `Intl.NumberFormat` のオプションを渡すと、表示する値の書式を変更できます。`slotProps.value` の `children` に関数を渡すと、表示する文字列を独自に組み立てられます。

<Component path="progress/format" />

```tsx
<Progress
  label="アップロード中"
  value={42}
  slotProps={{
    value: { children: (formattedValue) => `${formattedValue} 完了` },
  }}
/>
```

## 外観 [#appearance]

`variant` は `liquid` と `naked` から選択できます。`color` で配色を、`size` で大きさを、`radius` で角丸を指定します。`outlined` はトラックの枠線を表示するかどうかを決めます。

### slotProps [#slot-props]

| キー        | 型                                     | 説明                                                                                 |
| ----------- | -------------------------------------- | ------------------------------------------------------------------------------------ |
| `indicator` | `ProgressIndicatorProps`               | 進捗を示すインジケーターに渡す props です。                                          |
| `label`     | `Omit<ProgressLabelProps, "children">` | ラベルに渡す props です。表示内容は `label` で指定します。                           |
| `track`     | `Omit<ProgressTrackProps, "children">` | トラックに渡す props です。                                                          |
| `value`     | `ProgressValueProps`                   | 現在値の表示に渡す props です。`children` に関数を渡すと表示をカスタマイズできます。 |

## スタイル [#styling-hooks]

ルート要素には `sui_progress` が付与されます。props と状態に応じて、`sui_progress-size_md`、`sui_progress-color_blue`、`sui_progress-radius_full`、`sui_progress-variant_liquid`、`sui_progress-outlined`、`sui_progress-status_progressing` などのクラス名も加わります。

内部のパーツには、`sui_progress_label`、`sui_progress_value`、`sui_progress_track`、`sui_progress_indicator` などのクラス名が付与されます。
