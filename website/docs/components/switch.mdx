Switch は、設定のオンとオフを切り替えるコンポーネントです。変更は即座に反映されるため、送信操作を必要としない設定に向いています。ラベルと組み合わせて、何を切り替えるのかを明確にしてください。

## 使い方 [#basic-usage]

`label` 要素でテキストと組み合わせます。`defaultChecked` を指定すると、初期状態をオンにできます。

<Component path="switch/basic" />

オンとオフの状態を自分で管理する場合は、`checked` と `onCheckedChange` を組み合わせます。`onCheckedChange` は第 1 引数に真偽値を受け取ります。

```tsx
const [checked, setChecked] = useState(false);

<Switch checked={checked} onCheckedChange={setChecked} />;
```

## 外観 [#appearance]

`variant` で背景の有無を、`color` でオンのときの配色を指定します。`size` は `sm`、`md`、`lg` の 3 段階です。`outlined` を `false` にすると枠線を消せます。

<Component path="switch/appearance" />

角丸は `radius` で指定します。既定値は `full` で、`none`、`sm`、`md`、`lg`、`circle` から選択できます。

## 制御 [#controlled]

制御されたスイッチでは、`checked` の値を更新しない限り表示は変わりません。フォームの検証や非同期処理と連動させる場合に使います。

<Component path="switch/controlled" />

`readOnly` は値の変更だけを禁止し、`disabled` はフォーカスを含む操作を無効にします。どちらの場合も、ラベルを含めて状態が分かるようにしてください。

## スタイル [#styling-hooks]

ルート要素には `sui_switch` が付与されます。props に応じて `sui_switch-size_sm`、`sui_switch-color_blue`、`sui_switch-radius_full`、`sui_switch-variant_liquid`、`sui_switch-outlined` などのクラス名も加わります。

状態に応じて `sui_switch-checked`、`sui_switch-disabled`、`sui_switch-readonly`、`sui_switch-focused`、`sui_switch-dirty`、`sui_switch-valid` なども付与されます。つまみには `sui_switch_thumb` と、同じ接尾辞を持つクラス名が付きます。
