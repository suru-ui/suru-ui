HoverCard は、リンクやボタンにマウスカーソルを重ねると補足情報を表示するコンポーネントです。利用規約の概要や、ユーザーのプロフィールなど、画面遷移せずに確認したい内容を提示できます。トリガーとポップアップは自動で関連付けられ、遅延の後に開きます。

## 使い方 [#basic-usage]

`trigger` にホバーの対象となる要素を、`children` に表示する内容を指定します。トリガーにはリンクやボタンなどの要素を渡します。

<Component path="hover-card/basic" />

`children` に関数を渡すと、アクティブなトリガーの `payload` を受け取って内容を組み立てられます。複数のトリガーで 1 つのホバーカードを共有する場合は、`HoverCard.createHandle` で作成したハンドルを `handle` に渡します。

## 矢印と配置 [#placement]

`arrow` を指定すると、ポップアップに矢印が表示されます。配置は `slotProps.positioner` の `side` と `align` で調整でき、`sideOffset` でトリガーとの距離を指定します。

<Component path="hover-card/placement" />

`arrow` を有効にすると、矢印の高さに合わせて `sideOffset` の既定値が 6 px になります。`side` は `"top"`、`"bottom"`、`"left"`、`"right"` から選べます。画面の端に近い場合は、表示領域に収まるように位置が自動で調整されます。

## 開閉の制御 [#controlled]

`open` と `onOpenChange` を指定すると、開閉状態を外部から制御できます。`delay` と `closeDelay` はミリ秒単位で指定します。`delay` を `0` にすると、ホバーした直後に開きます。

<Component path="hover-card/controlled" />

非制御で初期状態を指定する場合は `defaultOpen` を使います。開閉のアニメーションが完了したタイミングで処理を行いたい場合は、`onOpenChangeComplete` を利用できます。

## スタイル [#styling-hooks]

ポップアップには `sui_hover_card_popup` が付与されます。props に応じて `sui_hover_card_popup-size_md`、`sui_hover_card_popup-radius_md`、`sui_hover_card_popup-outlined`、`sui_hover_card_popup-open`、`sui_hover_card_popup-side_top` などのクラス名も加わります。

トリガーには `sui_hover_card_trigger`、矢印には `sui_hover_card_arrow`、配置要素には `sui_hover_card_positioner` が付与されます。ポップアップの余白や背景色は `--sui_hover_card_popup-*` の CSS 変数で調整できます。
