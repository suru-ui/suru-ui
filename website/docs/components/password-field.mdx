PasswordField は、パスワードの入力に特化したテキストフィールドです。既定では入力内容を隠し、表示と非表示を切り替えるボタンを備えています。ログインフォームやアカウント設定など、パスワードを扱う場面で使います。

## 使い方 [#basic-usage]

`defaultValue` または `value` で値を指定し、`placeholder` で入力の目安を示します。表示切替ボタンは既定で表示されます。

<Component path="password-field/basic" />

入力欄の属性を指定する場合は `slotProps.input` を使います。`aria-label`、`autoComplete`、`minLength` などは入力欄へ直接渡してください。

```tsx
<PasswordField
  slotProps={{
    input: {
      "aria-label": "パスワード",
      autoComplete: "current-password",
      minLength: 8,
    },
  }}
/>
```

## 表示の切り替え [#visibility]

`visible` と `onVisibleChange` を使うと、パスワードの表示状態を外部の状態で管理できます。非制御で初期状態を指定したい場合は `defaultVisible` を使います。表示切替ボタンは、状態に応じて `aria-pressed` を切り替えます。

<Component path="password-field/visibility" />

`visibilityToggle` に `false` を指定すると、表示切替ボタンを非表示にできます。`slotProps.toggle` を指定した場合は、`visibilityToggle` が `false` でもボタンが表示されます。

## 接頭辞と接尾辞 [#addons]

`startAddons` と `endAddons` を使うと、入力欄の先頭と末尾に任意の内容を表示できます。鍵のアイコンや文字数の条件などを添えるときに便利です。

<Component path="password-field/addons" />

## 外観 [#appearance]

`variant` は `naked` と `liquid` から選択できます。`color`、`size`、`radius`、`outlined` を組み合わせて、入力欄の見た目を調整できます。

<Component path="password-field/appearance" />

このほか、`className`、`style`、`id`、`data-*` などの属性はルート要素へ渡せます。入力欄だけに適用したい属性は `slotProps.input` を使ってください。

### slotProps [#slot-props]

| キー     | 説明                                                                             |
| -------- | -------------------------------------------------------------------------------- |
| `addon`  | 入力欄の先頭と末尾のアドオンに渡す props です。                                  |
| `input`  | 入力欄に渡す props です。トップレベルに指定した入力欄の props より優先されます。 |
| `toggle` | 表示切替ボタンに渡す props です。内容や `aria-label` を変更できます。            |

## スタイル [#styling-hooks]

ルート要素には `sui_password_field` が付与されます。props と状態に応じて、`sui_password_field-size_md`、`sui_password_field-color_blue`、`sui_password_field-radius_md`、`sui_password_field-variant_naked`、`sui_password_field-outlined`、`sui_password_field-visible` などのクラス名も加わります。

内部のパーツには、`sui_password_field_input`、`sui_password_field_addon`、`sui_password_field_toggle` などのクラス名が付与されます。
