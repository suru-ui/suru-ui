Chip は、タグや属性、短い状態を表示する小さなラベルです。一覧の絞り込み条件や、項目に付いたラベルを表すときに使います。`render` で `button` 要素に置き換えると、押せるチップとしても使えます。

## 使い方 [#basic-usage]

`children` に表示するテキストやアイコンを指定します。アイコンは `lucide-react` などから読み込み、装飾用なら `aria-hidden="true"` を付けます。

<Component path="chip/basic" />

チップ自体を操作可能にする場合は、`render` に `button` 要素を渡します。内容がアイコンだけの場合は `aria-label` で名前を補ってください。

```tsx
<Chip render={<button type="button" />} onClick={removeTag} aria-label="タグを削除">
  デザイン
  <XIcon aria-hidden="true" />
</Chip>
```

## 外観 [#appearance]

`variant` は `solid`、`naked`、`liquid` から選択できます。`color` で配色を、`size` で大きさを、`radius` で角丸を指定します。

<Component path="chip/appearance" />

`outlined` を指定すると枠線が付きます。既定の `radius` は `full` なので、丸みのあるチップになります。

## スタイル [#styling-hooks]

ルート要素には `sui_chip` が付与されます。props に応じて、次のクラス名も加わります。

| クラス名                       | 条件                                        |
| ------------------------------ | ------------------------------------------- |
| `sui_chip`                     | 常に付与されます。                          |
| `sui_chip-size_sm` など        | `size` に応じて付与されます。               |
| `sui_chip-color_blue` など     | `color` に応じて付与されます。              |
| `sui_chip-radius_full` など    | `radius` に応じて付与されます。             |
| `sui_chip-variant_liquid` など | `variant` に応じて付与されます。            |
| `sui_chip-outlined`            | `outlined` が `true` のときに付与されます。 |

`className` や `style` で調整できるほか、CSS 変数 `--sui_chip-*` を使って余白や文字の大きさを上書きできます。
