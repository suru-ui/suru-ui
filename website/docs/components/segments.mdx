Segments は、関連する選択肢から 1 つを選ぶセグメントコントロールです。表示期間の切り替えや並び順の選択など、少数の選択肢を常に表示しておきたい場面に適しています。内部的にはタブの仕組みを使っています。

## 使い方 [#basic-usage]

`items` に選択肢を配列で指定します。各項目は値そのもの、または `label` と `value` を持つオブジェクトです。`defaultValue` で初期の選択値を指定します。

<Component path="segments/basic" />

`items` を省略し、`children` に項目を直接渡すこともできます。通常は `items` を使うと、ラベルと選択値の対応が明確になります。

## 外観 [#appearance]

`activeVariant` は選択中の項目の外観です。`solid` は塗りつぶし、`liquid` は薄い塗りつぶし、`naked` は背景なしになります。`color`、`size`、`radius`、`thin` を組み合わせて調整できます。

<Component path="segments/appearance" />

`radius` を省略すると `size` と同じ値になります。`thin` を指定すると上下の余白が半分になり、高さを抑えられます。

## 選択の制御 [#controlled]

`value` を指定すると制御コンポーネントになります。`onValueChange` で新しい値を受け取り、状態を更新します。項目の `disabled` を `true` にすると、その項目だけを選択不可にできます。

<Component path="segments/controlled" />

```tsx
const [value, setValue] = React.useState("week");

<Segments items={items} value={value} onValueChange={(nextValue) => setValue(String(nextValue))} />;
```

`orientation="vertical"` を指定すると、項目を縦に並べられます。

### slotProps [#slot-props]

| スロット    | 型                                               | 説明                                                                              |
| ----------- | ------------------------------------------------ | --------------------------------------------------------------------------------- |
| `indicator` | `SegmentsIndicatorProps`                         | 選択中の項目を示すインジケーターに渡す props です。                               |
| `item`      | `Omit<SegmentsItemProps, "children" \| "value">` | すべての項目に共通して渡す props です。`children` と `value` は上書きされません。 |
| `list`      | `Omit<SegmentsListProps, "children">`            | 項目を並べるリストに渡す props です。                                             |

## スタイル [#styling-hooks]

ルート要素には `sui_segments` が付与されます。props と状態に応じて、`sui_segments-size_md`、`sui_segments-color_blue`、`sui_segments-radius_full`、`sui_segments-active_variant_liquid`、`sui_segments-orientation_vertical`、`sui_segments-thin` などのクラス名が加わります。

内部のパーツには `sui_segments_list`、`sui_segments_item`、`sui_segments_indicator` が付与されます。選択中の項目には `sui_segments_item-active`、無効な項目には `sui_segments_item-disabled` が加わります。
