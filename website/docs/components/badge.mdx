Badge は、状態や数値を示す小さなラベルです。単独で表示するほか、`position` を指定してアバターやアイコンの隅に重ねられます。

## 使い方 [#basic-usage]

`children` に表示する内容を指定します。通知の件数のように、短い数値やラベルを渡します。

<Component path="badge/basic" />

`variant="dot"` を指定すると、内容を表示せず小さな点だけを描画します。内容を持たない状態表示には `aria-label` を添えてください。

```tsx
<Badge variant="dot" color="blue" aria-label="未読の通知があります" />
```

**外観**

`color` で配色を、`size` で大きさを指定します。`outlined` は枠線、`ring` は重ねた要素との境界を分けるリングを表示します。

```tsx
<Badge color="green">対応済み</Badge>
<Badge color="orange" outlined>保留</Badge>
<Badge color="red" ring>3</Badge>
```

## 重ね合わせ [#overlay]

`position` を指定すると、基準となる位置指定要素の四隅に絶対位置で配置されます。`overlap` は基準要素の形状に合わせて、バッジの中心を合わせる位置を調整します。

<Component path="badge/overlay" />

- `overlap="rectangular"`: 四角形の角にバッジの中心を合わせます。
- `overlap="circular"`: 円形の円周上にバッジの中心を合わせます。

### 継承 props [#inherited-props]

Badge は `span` 要素を描画するため、`className`、`style`、`id`、`aria-*`、`data-*` などの属性を渡せます。`position` を使うときは、親要素に `position: relative` または `position: absolute` を指定してください。

## スタイル [#styling-hooks]

ルート要素には `sui_badge` が付与されます。props に応じて、`sui_badge-size_sm`、`sui_badge-color_red`、`sui_badge-radius_full`、`sui_badge-variant_dot` などのクラス名も加わります。

`className` や `style` で調整できるほか、CSS 変数 `--sui_badge-*` を使って大きさや余白を上書きできます。
