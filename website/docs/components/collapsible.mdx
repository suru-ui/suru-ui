Collapsible は、見出しやボタンを操作して内容を展開または折りたたむコンポーネントです。補足情報や詳細設定など、常に表示する必要のない内容を隠すときに使います。`Collapsible.Indicator` をトリガーの中に置くと、開閉状態に応じてアイコンが回転します。

## 使い方 [#basic-usage]

`trigger` に開閉ボタンとして描画する要素を、`children` に折りたたむ内容を指定します。トリガーには `Button` などを渡し、`Collapsible.Indicator` を組み合わせます。

<Component path="collapsible/basic" />

`trigger` を省略するとトリガーは描画されません。トリガーを独自の要素にする場合は、`slotProps.trigger` で属性を補えます。

## 開閉の制御 [#controlled]

`open` と `onOpenChange` を指定すると、開閉状態を制御できます。`defaultOpen` は初期状態を開いた状態にするときに使います。

<Component path="collapsible/controlled" />

`onOpenChange` の第 2 引数には、開閉理由などの詳細が渡されます。`disabled` を指定すると、トリガーを操作できなくなります。

## インジケーターの差し替え [#custom-indicator]

`Collapsible.Indicator` の `children` を指定すると、既定の矢印アイコンを別のアイコンに置き換えられます。インジケーターは開閉状態に合わせて自動で回転します。

```tsx
<Collapsible
  trigger={
    <Button variant="naked">
      詳細
      <Collapsible.Indicator>
        <PlusIcon aria-hidden="true" />
      </Collapsible.Indicator>
    </Button>
  }
>
  折りたたまれる内容です。
</Collapsible>
```

コンテンツ側の `keepMounted` を `true` にすると、閉じた後も DOM に保持できます。`hiddenUntilFound` は、ブラウザーのページ内検索で折りたたまれた内容を見つけたときに自動で展開するかどうかを指定します。

## スタイル [#styling-hooks]

ルート要素には `sui_collapsible` が付与されます。props と状態に応じて、`sui_collapsible-size_md`、`sui_collapsible-open`、`sui_collapsible-disabled`、`sui_collapsible-transition_status_*` などのクラス名も加わります。

内部のパーツには `sui_collapsible_trigger`、`sui_collapsible_content`、`sui_collapsible_indicator` が付与されます。コンテンツには `keepMounted` で保持されている場合も `sui_collapsible_content` が付きます。
