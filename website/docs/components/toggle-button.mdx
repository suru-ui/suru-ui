ToggleButton は、押すたびに押下状態を切り替えるボタンです。書式設定のツールバーや表示の切り替えなど、選択状態を保ちながら操作する場面で使います。押下状態は `pressed` で管理され、見た目も状態に合わせて変わります。

## 使い方 [#basic-usage]

`children` にラベルやアイコンを指定します。アイコンだけのボタンには `squared` と `aria-label` を組み合わせてください。

<Component path="toggle-button/basic" />

初期状態を押下済みにする場合は `defaultPressed` を指定します。押下状態を自分で管理する場合は `pressed` と `onPressedChange` を使います。

```tsx
const [pressed, setPressed] = useState(false);

<ToggleButton pressed={pressed} onPressedChange={setPressed}>
  オン
</ToggleButton>;
```

## 外観 [#appearance]

`variant` は `liquid` と `naked` から選択できます。押下状態では `variant` に関係なく solid の外観になり、`color` でその配色を指定します。

<Component path="toggle-button/appearance" />

`size` は `xs`、`sm`、`md`、`lg` の 4 段階です。`radius` の既定値は `size` に応じて `sm` または `md` になります。`outlined` を指定すると枠線が付きます。

## 制御と保留 [#controlled-and-pending]

押下状態を外部の状態と同期させる場合は、`pressed` と `onPressedChange` を組み合わせます。

<Component path="toggle-button/controlled" />

`pending` を `true` にすると押下が無効になり、進行状況を示す円形プログレスバーが表示されます。`percentage` に 0〜100 の値を渡すと進捗率を表示できます。

<Component path="toggle-button/pending" />

保留中もフォーカスを維持するため、`disabled` を併用しない限りキーボード操作の文脈が途切れません。

## スタイル [#styling-hooks]

ToggleButton は Button のルート要素を共有するため、ルートには `sui_button` が付与されます。props に応じて `sui_button-size_md`、`sui_button-color_blue`、`sui_button-radius_md`、`sui_button-variant_solid`、`sui_button-outlined`、`sui_button-squared`、`sui_button-pending` などのクラス名も加わります。

押下状態は Base UI の Toggle が付与する `data-pressed` 属性で判別できます。内部のパーツには `sui_button_content`、`sui_button_pending`、`sui_button_circular_progress` などが付与されます。
