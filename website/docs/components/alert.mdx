Alert は、重要なメッセージや通知をステータスインジケーター付きで表示するコンポーネントです。フォームの送信結果や警告など、ユーザーに気づいてほしい情報を目立たせるときに使います。タイトル、説明文、アイコン、操作ボタンを組み合わせられます。

## 使い方 [#basic-usage]

`title` に見出しを、`children` に説明文を指定します。`icon` には状態を表すアイコンを渡します。アイコンを省略すると、アイコン領域は描画されません。

<Component path="alert/basic" />

`icon=""` のように空文字を渡すと、アイコンの代わりに状態色の丸いインジケーターが表示されます。内容を持たない状態表示には `aria-label` を添えてください。

```tsx
<Alert color="green" title="同期が完了しました" icon="" aria-label="完了" />
```

## 外観 [#appearance]

`variant` は `muted`、`liquid`、`naked` から選択できます。`color` で配色を変えると、アイコンと背景色に反映されます。`outlined` は枠線の表示を制御します。

<Component path="alert/appearance" />

`size` は `sm`、`md`、`lg` の 3 段階です。`radius` を省略すると `size` と同じ値になります。

## アクションと配置 [#actions]

`actions` に操作ボタンを渡すと、アラート内にアクション領域が追加されます。`actionsPosition` は `side` または `bottom` を指定できます。`descriptionPosition` を使うと、説明文をタイトルの下または横に配置できます。

<Component path="alert/actions" />

`descriptionPosition` の値は次のとおりです。

- `bottom`: タイトルの下に説明文を置きます。
- `side-start`: タイトルの右側に説明文を並べ、左寄せにします。
- `side-end`: タイトルの右側に説明文を並べ、右寄せにします。

### 継承 props [#inherited-props]

Alert は `div` 要素を描画するため、`className`、`style`、`id`、`aria-*`、`data-*` などの属性を渡せます。`role` の既定値は `alert` です。静的なお知らせとして読み上げたい場合は `role="status"` を指定できます。

`className` と `style` には状態を受け取る関数を渡せます。残りの props はベースの `div` 要素から継承します。

## スタイル [#styling-hooks]

ルート要素には `sui_alert` が付与されます。props に応じて、`sui_alert-color_red`、`sui_alert-size_md`、`sui_alert-radius_md`、`sui_alert-variant_muted`、`sui_alert-outlined`、`sui_alert-actions_position_side`、`sui_alert-description_position_bottom` などのクラス名も加わります。

内部のパーツには `sui_alert_icon`、`sui_alert_title`、`sui_alert_description`、`sui_alert_actions` が付与されます。

`className` や `style` で調整できるほか、CSS 変数を使って余白や色を上書きできます。
