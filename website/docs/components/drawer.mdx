Drawer は、画面の端からスライドして表示される領域です。補足の操作や設定、確認などを、現在の画面を保ったまま表示したい場面で使います。`swipeDirection` で表示する端とスワイプ方向を指定できます。

## 使い方 [#basic-usage]

`trigger` にドロワーを開く要素を、`title`、`description`、`children` に内容を渡します。`footer` は下部に固定して表示されます。

<Component path="drawer/basic" />

`showCloseIconButton` は既定で `true` になり、右上に閉じるアイコンが表示されます。`controls` を使うと、その手前に独自の操作を追加できます。

## 表示方向 [#direction]

`swipeDirection` には `up`、`down`、`left`、`right` を指定できます。`showSwipeHandle` を `true` にすると、ドロワーの端にスワイプ用のハンドルが表示されます。

<Component path="drawer/directions" />

`swipeDirection` は、ドロワーを閉じるスワイプの方向も決めます。`modal={false}` を指定すると、背後の画面を操作できる非モーダルのドロワーになります。

## スナップポイント [#snap-points]

`snapPoints` を指定すると、ドロワーを決まった高さに止められます。0 から 1 の数値はビューポートの高さに対する割合、1 より大きい数値はピクセル値として扱われます。`px` や `rem` を含む文字列も指定できます。

```tsx
const snapPoints = ["148px", 0.5, 1];

<Drawer
  title="クイック設定"
  trigger={<Button>設定を開く</Button>}
  snapPoints={snapPoints}
  defaultSnapPoint={0.5}
  onSnapPointChange={(snapPoint) => {
    console.log(snapPoint);
  }}
>
  ドラッグして高さを切り替えられます。
</Drawer>;
```

`snapToSequentialPoints` を `true` にすると、スワイプで隣り合うスナップポイントへ順番に移動します。

## スタイル [#styling-hooks]

ポップアップには `sui_drawer_popup` が付与されます。状態に応じて、`sui_drawer_popup-swipe_direction_down`、`sui_drawer_popup-open`、`sui_drawer_popup-swiping`、`sui_drawer_popup-expanded`、`sui_drawer_popup-nested` などのクラス名も加わります。

内部のパーツには `sui_drawer_content`、`sui_drawer_header`、`sui_drawer_title`、`sui_drawer_description`、`sui_drawer_body`、`sui_drawer_footer`、`sui_drawer_swipe_handle` などのクラス名が付きます。
