Meter は、既知の範囲に対する現在値の割合を表示するコンポーネントです。ストレージの使用量やバッテリーの残量など、測定値を示すときに使います。処理の進捗を示す場合は、代わりに [Progress](/components/progress) を使います。

## 使い方 [#basic-usage]

`value` に現在値を指定し、必要に応じて `min` と `max` で範囲を指定します。`label` を指定すると、ラベルと現在値が表示されます。

<Component path="meter/basic" />

`label` を指定しない場合は、ラベルと値の表示が省略されます。この場合は `aria-label` や `aria-valuetext` で、支援技術へ意味を伝えてください。

## 範囲と値 [#range]

`min` と `max` は表示する値の範囲を決めます。既定値はそれぞれ `0` と `100` です。負の値を含む範囲を指定したい場合は、`min` に負の数を渡します。

```tsx
<Meter label="気温" min={-20} max={40} value={12} />
```

`value` が範囲を超えた場合は、最小値または最大値に丸められた値が表示されます。

## 値の書式 [#format]

`format` に `Intl.NumberFormat` のオプションを渡すと、表示する値の書式を変更できます。`locale` を合わせて指定すると、言語や地域に応じた表記になります。

<Component path="meter/format" />

```tsx
<Meter
  label="ストレージ"
  value={183}
  max={256}
  format={{ style: "unit", unit: "gigabyte", maximumFractionDigits: 0 }}
  locale="ja-JP"
/>
```

## 外観 [#appearance]

`variant` は `liquid` と `naked` から選択できます。`color` で配色を、`size` で大きさを、`radius` で角丸を指定します。`outlined` はトラックの枠線を表示するかどうかを決めます。

### slotProps [#slot-props]

| キー        | 型                                  | 説明                                                                                 |
| ----------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `indicator` | `MeterIndicatorProps`               | 現在値を示すインジケーターに渡す props です。                                        |
| `label`     | `Omit<MeterLabelProps, "children">` | ラベルに渡す props です。表示内容は `label` で指定します。                           |
| `track`     | `Omit<MeterTrackProps, "children">` | トラックに渡す props です。                                                          |
| `value`     | `MeterValueProps`                   | 現在値の表示に渡す props です。`children` に関数を渡すと表示をカスタマイズできます。 |

## スタイル [#styling-hooks]

ルート要素には `sui_meter` が付与されます。props に応じて、`sui_meter-size_md`、`sui_meter-color_blue`、`sui_meter-radius_full`、`sui_meter-variant_liquid`、`sui_meter-outlined` などのクラス名も加わります。

内部のパーツには、`sui_meter_label`、`sui_meter_value`、`sui_meter_track`、`sui_meter_indicator` などのクラス名が付与されます。
