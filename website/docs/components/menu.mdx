Menu は、ボタンなどのトリガーから開くメニューを表示するコンポーネントです。`items` に項目の配列を渡すと、通常の操作項目、チェック項目、ラジオ項目、サブメニュー、リンク項目をまとめて組み立てられます。キーボード操作やフォーカス管理は Base UI の Menu が担当します。

## 使い方 [#basic-usage]

`trigger` にメニューを開く要素を、`items` に表示する項目を指定します。項目の `label` には文字列だけでなく、アイコンを含む React ノードも渡せます。

<Component path="menu/basic" />

各項目には `disabled` や `color` を指定できます。`color="red"` は削除など、注意を促したい操作に適しています。区切り線が必要な場合は、項目をグループに分けると自動で挿入されます。

## 項目の種類 [#item-types]

項目オブジェクトの `type` で、表示する項目の種類を切り替えます。`type` を省略すると通常の操作項目になります。チェック項目とラジオ項目は、選択状態を `checked` や `value` で管理します。

<Component path="menu/item-types" />

| `type`            | 主なフィールド                          | 説明                                                         |
| ----------------- | --------------------------------------- | ------------------------------------------------------------ |
| `"item"`（省略）  | `label`、`disabled`、`onClick`、`color` | 通常の操作項目です。                                         |
| `"link"`          | `label`、`href`、`target`               | リンクとして動作する項目です。                               |
| `"checkbox"`      | `label`、`checked`、`onCheckedChange`   | 選択状態を持つチェック項目です。                             |
| `"radio-group"`   | `value`、`onValueChange`、`items`       | ラジオ項目をまとめるグループです。                           |
| `"radio"`         | `label`、`value`                        | ラジオグループ内の項目です。                                 |
| `"submenu"`       | `label`、`items`                        | 子メニューを開く項目です。                                   |
| `"group"`（省略） | `label`、`items`                        | 見出し付きのグループです。グループ間には区切り線が入ります。 |

グループの `items` には、通常の項目、リンク項目、チェック項目、ラジオグループ、サブメニューを入れられます。サブメニューの中にも同じ項目オブジェクトを指定できます。

## 外観と無効化 [#appearance]

`size` はメニュー全体と項目の大きさ、`radius` は角丸、`variant` は項目の主な外観を指定します。`outlined` はポップアップの枠線を切り替えます。

<Component path="menu/appearance" />

`disabled` を指定すると、メニュー全体が操作できなくなります。特定の項目だけを無効にする場合は、その項目オブジェクトに `disabled` を指定します。`modal` を `false` にすると、メニューを開いたままページ内の他の要素を操作できます。

## スタイル [#styling-hooks]

トリガーには `sui_menu_trigger`、ポップアップには `sui_menu_popup`、通常の項目には `sui_menu_item` が付与されます。チェック項目は `sui_menu_checkbox_item`、ラジオ項目は `sui_menu_radio_item`、リンク項目は `sui_menu_link_item`、サブメニューを開く項目は `sui_menu_submenu_trigger` になります。

項目は状態に応じて `sui_menu_item-checked`、`sui_menu_item-disabled`、`sui_menu_item-highlighted`、`sui_menu_item-outlined` などのクラス名を持ちます。ポップアップには `sui_menu_popup-size_md`、`sui_menu_popup-radius_md`、`sui_menu_popup-variant_naked`、`sui_menu_popup-open` などが加わります。

グループには `sui_menu_group`、グループの見出しには `sui_menu_group_label`、区切り線には `sui_menu_separator`、インジケーターには `sui_menu_item_indicator` が付与されます。間隔や背景色は `--sui_menu_popup-*` や `--sui_menu_item-*` の CSS 変数で調整できます。
