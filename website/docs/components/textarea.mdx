Textarea は、複数行のテキストを入力するためのコンポーネントです。問い合わせ内容やメモなど、長さのある文章を受け取るときに使います。ネイティブの `textarea` と同じ属性を渡せるため、既存のフォームにも組み込みやすいコンポーネントです。

## 使い方 [#basic-usage]

`rows` で表示する行数を指定します。省略した場合はブラウザーの既定の行数になります。`placeholder` や `defaultValue` もそのまま渡せます。

<Component path="textarea/basic" />

ラベルや説明を添える場合は、`Field` で囲みます。入力値の検証とエラー表示も `Field` にまとめられます。

```tsx
<Field label="問い合わせ内容" description="できるだけ詳しく入力します。">
  <Textarea rows={4} placeholder="問い合わせ内容" />
</Field>
```

## 外観 [#appearance]

`variant` は `naked` と `liquid` から選択できます。`size`、`radius`、`color`、`outlined` を組み合わせて、周囲のフォームに合わせられます。

<Component path="textarea/appearance" />

`size` は `sm`、`md`、`lg` の 3 段階です。`radius` の既定値は `size` と同じ値になります。

## 制御と状態 [#controlled-and-states]

入力値を自分で管理する場合は、`value` と `onValueChange` を組み合わせます。文字数を表示するなど、入力内容に応じた処理に向いています。

<Component path="textarea/controlled" />

`disabled` は入力自体を無効にし、`readOnly` は値を変更できない状態にします。検証エラーは `Field` の `invalid` と組み合わせると、枠線の色に反映されます。

## スタイル [#styling-hooks]

ルート要素は `textarea` で、`sui_textarea` が付与されます。props に応じて `sui_textarea-size_md`、`sui_textarea-color_blue`、`sui_textarea-radius_md`、`sui_textarea-variant_naked`、`sui_textarea-outlined` などのクラス名も加わります。

状態に応じて `sui_textarea-focused`、`sui_textarea-filled`、`sui_textarea-invalid`、`sui_textarea-valid`、`sui_textarea-disabled`、`sui_textarea-dirty` なども付与されます。
