Menubar は、アプリケーションのメニューバーのように複数のメニューを横または縦に並べるコンポーネントです。各メニューはトリガーと項目の組で指定し、項目にはサブメニューやチェック項目などを含められます。メニュー間の移動や開閉はキーボードでも操作できます。

## 使い方 [#basic-usage]

`items` に、メニューを開く `trigger` と、ポップアップに表示する `items` を持つオブジェクトを並べます。`trigger` にはボタンなどの要素を指定します。

<Component path="menubar/basic" />

```tsx
<Menubar
  items={[
    {
      trigger: <Button variant="naked">ファイル</Button>,
      items: [{ label: "新規作成" }, { label: "開く" }, { label: "保存" }],
    },
  ]}
/>
```

矢印キーで隣のメニューへ移動し、Enter キーまたは Space キーでメニューを開きます。開いたメニューの中では上下の矢印キーで項目を移動できます。

## 項目の種類 [#item-types]

各メニューの `items` には、次の項目を指定できます。

- `label` を持つ項目は、通常のメニュー項目になります。
- `type: "submenu"` と `label`、`items` を持つ項目は、サブメニューを開く項目になります。
- `type: "checkbox"` と `label` を持つ項目は、チェック状態を切り替える項目になります。
- `type: "radio-group"` と `items` を持つ項目は、排他的な選択肢をまとめたグループになります。
- `type: "link"` と `label` を持つ項目は、リンクとして動作する項目になります。

```tsx
items={[
  { type: "checkbox", label: "ルーラーを表示", defaultChecked: true },
  {
    type: "submenu",
    label: "ズーム",
    items: [{ label: "50%" }, { label: "100%" }, { label: "200%" }],
  },
]}
```

## 向き [#orientation]

`orientation` に `"vertical"` を指定すると、メニューを縦に並べられます。既定値は `"horizontal"` です。

## メニューのカスタマイズ [#menu-customization]

`slotProps.menu` を使うと、すべてのメニューに同じ props を渡せます。メニューの大きさや外観、角丸などをまとめて変更するときに便利です。

```tsx
<Menubar slotProps={{ menu: { size: "sm", variant: "liquid", radius: "md" } }} items={items} />
```

個別のメニューだけ外観を変えたい場合は、その項目のオブジェクトに `size` や `variant` などを直接指定します。項目のオブジェクトに指定した値は、`slotProps.menu` の値より優先されます。

### slotProps [#slot-props]

| キー   | 型                                       | 説明                                                                                                       |
| ------ | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `menu` | `Omit<Menu.Props, "items" \| "trigger">` | すべてのメニューに渡す props です。`items` と `trigger` は項目ごとに指定するため、ここでは指定できません。 |

## スタイル [#styling-hooks]

ルート要素には `sui_menubar` が付与されます。props と状態に応じて、`sui_menubar-orientation_horizontal`、`sui_menubar-orientation_vertical`、`sui_menubar-disabled`、`sui_menubar-modal`、`sui_menubar-has_submenu_open` などのクラス名も加わります。

各メニューのトリガーには `sui_menu_trigger`、ポップアップには `sui_menu_popup`、項目には `sui_menu_item` などのクラス名が付与されるため、メニューの外観は `slotProps.menu` の `className` でも調整できます。
