Dialog は、画面の中央に一時的な領域を表示するコンポーネントです。確認、入力、詳細の表示など、ユーザーの操作を一時的に集中させたい場面で使います。既定ではモーダルとして表示され、背景の操作を遮ります。

## 使い方 [#basic-usage]

`trigger` にダイアログを開く要素を指定し、`title`、`description`、`children` に内容を渡します。`close` はフッターに配置される閉じる操作で、`footer` はその手前に追加する内容です。

<Component path="dialog/basic" />

右上の閉じるアイコンは既定で表示されます。`showCloseIconButton={false}` を指定すると非表示になります。`action` を使うと、閉じるアイコンの手前に独自の操作を追加できます。

## 開閉の制御 [#controlled]

`open` と `onOpenChange` を指定すると、ダイアログの開閉を制御できます。トリガーを使わず、外部のボタンから開く場合にも使えます。

<Component path="dialog/controlled" />

`onClose` は `close` がクリックされたときに呼ばれます。閉じる前に検証したい場合は、イベントの `preventBaseUIHandler()` を呼ぶと閉じる操作を止められます。

```tsx
<Dialog
  close={<Button>保存する</Button>}
  onClose={(event) => {
    if (!isValid) {
      event.preventBaseUIHandler();
    }
  }}
  title="プロフィールを編集"
>
  入力内容を確認してください。
</Dialog>
```

## 積み上げ式の外観 [#stacked]

`variant="stacked"` を指定すると、見出しと説明を中央に寄せ、操作を右上へ重ねた外観になります。

<Component path="dialog/stacked" />

`outlined={false}` で枠線を消せます。`size` と `radius` はカードと同じ段階から選択できます。

## 命令的な操作 [#imperative]

`Dialog.createHandle()` で作成したハンドルを使うと、コンポーネントの外から開閉できます。ハンドルは `handle` に渡します。

```tsx
const handle = Dialog.createHandle();

handle.open(null);
handle.close();

<Dialog handle={handle} title="通知" />;
```

`Dialog.ToggleTrigger` は、ハンドルと関連付けたトリガーを個別に配置したい場合に使います。

`Dialog` コンポーネントは `createHandle` と `ToggleTrigger` を静的メンバーとして持ちます。`Dialog.createHandle()` でハンドルを作成し、`Dialog.ToggleTrigger` でトリガーを個別に配置できます。

`className` と `style` はポップアップに適用されます。ポップアップの要素を置き換える場合は `render` を使います。ここに挙げた以外の props は Base UI の Dialog から継承します。

## スタイル [#styling-hooks]

ポップアップには `sui_dialog_popup` が付与されます。状態に応じて、`sui_dialog_popup-size_md`、`sui_dialog_popup-radius_md`、`sui_dialog_popup-variant_stacked`、`sui_dialog_popup-outlined`、`sui_dialog_popup-open`、`sui_dialog_popup-nested` などのクラス名も加わります。

トリガーには `sui_dialog_trigger` が付与されます。内部のパーツには `sui_dialog_header`、`sui_dialog_title`、`sui_dialog_description`、`sui_dialog_content`、`sui_dialog_footer` などのクラス名が付きます。
