RadioGroup は、複数のラジオボタンを 1 つのグループにまとめ、選択状態を管理するコンポーネントです。グループ内では 1 つの値だけが選択され、矢印キーで選択肢を移動できます。個々のラジオボタンには [Radio](/components/radio) を使います。

## 使い方 [#basic-usage]

`defaultValue` に初期選択の値を指定し、子要素に Radio とラベルを並べます。制御された状態にしたい場合は、`value` と `onValueChange` を使います。

<Component path="radio-group/basic" />

グループには `aria-label` または外部のラベルを関連付けて、何を選ぶグループなのかを伝えてください。

## 向き [#orientation]

`orientation` に `"horizontal"` を指定すると、ラジオボタンを横に並べられます。既定値は `"vertical"` です。

<Component path="radio-group/orientation" />

## 選択値の制御 [#controlled]

`value` と `onValueChange` を使うと、選択値を外部の状態で管理できます。`onValueChange` の第 1 引数には、選択された Radio の `value` が渡されます。

<Component path="radio-group/controlled" />

## 外観 [#appearance]

`color`、`size`、`radius`、`variant`、`outlined` でグループ内のラジオボタンの外観をまとめて指定できます。グループに指定した値は、個々の Radio に指定した値より優先されます。

```tsx
<RadioGroup defaultValue="a" color="blue" size="lg" variant="liquid">
  <label>
    <Radio value="a" />
    選択肢 A
  </label>
</RadioGroup>
```

このほか、`className`、`style`、`render`、`data-*` などの属性も渡せます。RadioGroup には `slotProps` はありません。

## スタイル [#styling-hooks]

ルート要素には `sui_radio_group` が付与されます。props と状態に応じて、`sui_radio_group-size_md`、`sui_radio_group-color_blue`、`sui_radio_group-radius_full`、`sui_radio_group-variant_naked`、`sui_radio_group-orientation_vertical`、`sui_radio_group-outlined`、`sui_radio_group-disabled` などのクラス名も加わります。
