Checkbox は、オンとオフの 2 つの状態を持つ入力です。設定の切り替えや、複数の選択肢から該当するものを選ぶ場面で使います。ラベルのテキストは `label` 要素で囲んで指定すると、クリックでチェック状態を切り替えられます。

## 使い方 [#basic-usage]

ラベルのテキストは `label` 要素の子として配置します。Checkbox とラベルを同じ `label` 要素に入れると、テキストのクリックでも状態を切り替えられます。`defaultChecked` を指定すると、初期状態をチェック済みにできます。

<Component path="checkbox/basic" />

Checkbox の `children` はインジケーターの中に描画されます。チェックマークを独自のアイコンに差し替えたい場合に使います。

## 選択状態 [#selection-states]

`checked` と `onCheckedChange` を指定すると、選択状態を制御できます。`indeterminate` は、複数の子項目の一部だけが選択されていることを示す中間状態です。

<Component path="checkbox/states" />

`disabled` は操作とフォーカスを無効にし、`readOnly` は状態を変えずにフォーカスだけを許可します。フォームで必須にする場合は `required` を指定します。

## グループとの連携 [#within-checkbox-group]

複数の Checkbox をまとめる場合は、[CheckboxGroup](/components/checkbox-group) の子として配置し、各 Checkbox に `value` を指定します。グループ内では、`color`、`size`、`radius`、`variant`、`outlined` をグループ側でまとめて指定できます。

```tsx
<CheckboxGroup defaultValue={["design"]}>
  <label>
    <Checkbox value="design" />
    デザイン
  </label>
  <label>
    <Checkbox value="engineering" />
    エンジニアリング
  </label>
</CheckboxGroup>
```

## 外観 [#appearance]

`color` で配色を、`size` で大きさを指定します。`variant="liquid"` にすると薄い塗りつぶしが付き、`outlined={false}` で枠線を消せます。

## スタイル [#styling-hooks]

ルート要素には `sui_checkbox` が付与されます。props と状態に応じて、次のクラス名も加わります。

| クラス名                           | 条件                                        |
| ---------------------------------- | ------------------------------------------- |
| `sui_checkbox`                     | 常に付与されます。                          |
| `sui_checkbox-size_sm` など        | `size` に応じて付与されます。               |
| `sui_checkbox-color_blue` など     | `color` に応じて付与されます。              |
| `sui_checkbox-radius_full` など    | `radius` に応じて付与されます。             |
| `sui_checkbox-variant_liquid` など | `variant` に応じて付与されます。            |
| `sui_checkbox-outlined`            | `outlined` が `true` のときに付与されます。 |
| `sui_checkbox-checked`             | チェック済みのときに付与されます。          |
| `sui_checkbox-indeterminate`       | 中間状態のときに付与されます。              |
| `sui_checkbox-disabled`            | 無効のときに付与されます。                  |
| `sui_checkbox-readonly`            | 読み取り専用のときに付与されます。          |
| `sui_checkbox-required`            | 必須のときに付与されます。                  |
| `sui_checkbox-invalid` など        | 検証状態に応じて付与されます。              |

インジケーターには `sui_checkbox_indicator` が付与され、`sui_checkbox_indicator-checked` や `sui_checkbox_indicator-disabled` などの状態クラスも加わります。
