Input は、テキストやメールアドレスなどの入力欄を表示するコンポーネントです。Base UI の Input を基盤にしており、ネイティブの input 要素が受け付ける属性をそのまま渡せます。ラベルや説明、エラーをまとめたい場合は `Field` や `Label` と組み合わせます。

## 使い方 [#basic-usage]

`type` で入力項目の種類を指定します。省略すると `"text"` になります。`Label` の `htmlFor` と `Input` の `id` を揃えると、ラベルと入力欄が関連付きます。

<Component path="input/basic" />

`Field` を使うと、ラベル、説明、エラー表示をまとめて管理できます。`Input` は `Field` の検証状態を読み取り、無効な値のときは枠線の色が変わります。

## 外観 [#appearance]

`variant` は `naked` と `liquid` から選べます。`outlined` は枠線の有無、`size` は高さと文字の大きさ、`radius` は角丸の大きさを指定します。`color` はフォーカス時の枠線の色に使われます。

<Component path="input/appearance" />

`radius="full"` はカプセル形、`radius="circle"` は完全な円形になります。`circle` は検索ボタンなど、入力欄を丸く見せたい場合に適しています。

## 状態と制御 [#states]

`value` と `onValueChange` を指定すると、入力値を外部の状態で管理できます。非制御で初期値を指定する場合は `defaultValue` を使います。`disabled` と `readOnly` は見た目と操作の両方に影響します。

<Component path="input/states" />

`onValueChange` は入力値の文字列を受け取ります。数値として扱いたい場合も、まずは文字列として受け取り、必要に応じて変換します。

## スタイル [#styling-hooks]

ルート要素には `sui_input` が付与されます。props に応じて `sui_input-size_md`、`sui_input-color_grey`、`sui_input-radius_md`、`sui_input-variant_naked`、`sui_input-outlined` などのクラス名も加わります。

検証状態や操作状態に応じて、`sui_input-valid`、`sui_input-invalid`、`sui_input-unverified`、`sui_input-disabled`、`sui_input-touched`、`sui_input-dirty`、`sui_input-filled`、`sui_input-focused` が付与されます。

`--sui_input-min_height`、`--sui_input-padding_inline`、`--sui_input-border_radius`、`--sui_input-focusring_width` などの CSS 変数で見た目を調整できます。
