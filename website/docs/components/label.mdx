Label は、フォームコントロールに紐付けるラベルを表示するコンポーネントです。`htmlFor` でコントロールの `id` を指定するか、コントロールを子要素として配置すると、クリックやフォーカスの対象がラベルと結び付きます。`Field` を使わずに、入力欄とラベルだけを配置したい場合に適しています。

## 使い方 [#basic-usage]

`htmlFor` に、関連付けるコントロールの `id` を指定します。`Input` 側の `id` と同じ値にしてください。ラベルをクリックすると、対応する入力欄にフォーカスが移ります。

<Component path="label/basic" />

`children` にはラベルとして表示する内容を指定します。必須項目であることを示す `*` などを添える場合は、装飾として `aria-hidden="true"` を指定し、別途 `required` をコントロール側に設定します。

## コントロールを子に置く [#nesting]

ラベルの子要素としてコントロールを配置すると、`htmlFor` と `id` を指定せずに関連付けられます。チェックボックスのように、ラベル全体をクリックできるようにしたい場合に便利です。

<Component path="label/nested" />

入力欄を子に置く場合は、ラベルと入力欄を縦に並べる `style` を指定すると読みやすくなります。チェックボックスと横に並べる場合は、`display: flex` と `alignItems: center` を組み合わせます。

## 外観と無効状態 [#states]

`color` で文字色を、`size` で大きさを指定します。`disabled` はラベル自身の見た目だけを変えるため、関連するコントロールは無効になりません。コントロールを無効にする場合は、コントロール自身の `disabled` を指定してください。

<Component path="label/states" />

`color` は 8 色から選べます。`size` は `sm`、`md`、`lg` の 3 段階です。入力欄と並べるときは、`Input` の `size` と揃えると高さのバランスが取りやすくなります。

## スタイル [#styling-hooks]

ルート要素には `sui_label` が付与されます。props に応じて `sui_label-size_md`、`sui_label-color_grey`、`sui_label-disabled` などのクラス名も加わります。

`--sui_label-font_size`、`--sui_label-font_weight`、`--sui_label-color` などの CSS 変数で文字組みを調整できます。
