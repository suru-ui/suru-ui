title: ContextMenu

ContextMenu は、右クリックまたは長押しで開くメニューです。ファイル操作やテキスト編集など、対象を選んでから操作を表示する場面で使います。`items` に項目オブジェクトを並べるだけで、グループやサブメニュー、チェック項目、ラジオ項目を組み立てられます。

## 使い方 [#basic-usage]

`trigger` に右クリックの対象を、`items` にメニューの項目を指定します。項目は `label` を持つオブジェクトで、`color` を指定すると破壊的な操作を赤系で表示できます。

<Component path="context-menu/basic" />

メニューを開く対象には、`div` や画像などを渡せます。開閉を `open` で制御する場合は、トリガーを省略して外部の要素から開けます。

## グループとサブメニュー [#groups-and-submenus]

`items` を入れ子にするとグループになり、`label` を付けると見出しが表示されます。`type: "submenu"` の項目は、子の `items` をサブメニューとして表示します。

<Component path="context-menu/items" />

グループの末尾には区切り線が表示されます。項目の `label` には、アイコンやキーボードショートカットを表す `kbd` 要素なども配置できます。

## 状態を持つ項目 [#stateful-items]

`type: "checkbox"` の項目はオンとオフを切り替えられます。`type: "radio-group"` の項目は、子の `type: "radio"` から 1 つを選びます。選択状態を制御する場合は、`checked` と `onCheckedChange`、または `value` と `onValueChange` を指定します。

<Component path="context-menu/stateful" />

チェック済みの表示には `checkboxIndicator`、ラジオ選択済みの表示には `radioIndicator` を使います。どちらも `slotProps` で個別に props を渡せます。

## スタイル [#styling-hooks]

ルートは HTML 要素を描画しないため、クラス名はポップアップとトリガーに付与されます。

| クラス名                                    | 条件                                        |
| ------------------------------------------- | ------------------------------------------- |
| `sui_context_menu_popup`                    | 常に付与されます。                          |
| `sui_context_menu_popup-open`               | メニューが開いているときに付与されます。    |
| `sui_context_menu_popup-size_md` など       | `size` に応じて付与されます。               |
| `sui_context_menu_popup-radius_md` など     | `radius` に応じて付与されます。             |
| `sui_context_menu_popup-variant_naked` など | `variant` に応じて付与されます。            |
| `sui_context_menu_popup-outlined`           | `outlined` が `true` のときに付与されます。 |
| `sui_context_menu_trigger`                  | トリガーに常に付与されます。                |
| `sui_context_menu_item`                     | 各項目に常に付与されます。                  |
| `sui_context_menu_checkbox_item`            | チェック項目に付与されます。                |

項目には `sui_context_menu_item-highlighted` と `sui_context_menu_item-disabled` が、チェック項目にはさらに `sui_context_menu_item-checked` が加わります。ポップアップの配置に応じて `sui_context_menu_popup-side_*` と `sui_context_menu_popup-align_*` が付与されます。
