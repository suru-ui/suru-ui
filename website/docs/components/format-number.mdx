FormatNumber は、数値をロケールに従って書式化して表示するコンポーネントです。桁区切り、通貨、パーセント、単位、短縮表記などを `Intl.NumberFormat` のオプションで指定できます。テキストノードとして描画されるため、見た目の調整は親要素側で行います。

## 使い方 [#basic-usage]

`value` に書式化する数値を指定します。`locales` を省略すると実行環境の既定ロケールが使われるため、表示を固定したい場合は `"ja-JP"` などを明示します。

<Component path="format-number/basic" />

`style` を切り替えると、小数、通貨、パーセント、単位の書式を選べます。通貨の場合は `currency` に ISO 4217 の通貨コードを指定します。

## 表記と単位 [#notation]

`notation="compact"` を使うと、大きな数値を短縮表記にできます。`style="unit"` と `unit` を組み合わせると、数値に単位を付けられます。

<Component path="format-number/notation" />

`currencySign="accounting"` は、負の通貨額を括弧で囲んで表示します。`signDisplay` を使うと、正の値にも符号を付けられます。桁数は `minimumFractionDigits` と `maximumFractionDigits` で調整します。

## スタイル [#styling-hooks]

FormatNumber は書式化したテキストを描画するため、HTML 要素や `sui_` で始まるクラス名を出力しません。文字色や大きさを変えたい場合は、`span` や `strong` などの親要素でスタイルを指定します。

```tsx
<p style={{ fontSize: "1.5rem", fontWeight: 700 }}>
  <FormatNumber value={1234} style="currency" currency="JPY" locales="ja-JP" />
</p>
```
