Field is a component that handles labels, input fields, descriptions, and error messages as a single unit. Automatically associate input fields with labels and display messages depending on the form validation status. In addition to text input, it can be combined with checkboxes and selection components.

## Basic usage [#basic-usage]

Specify `label` and `description` and place the input field in the child element. When using native input fields, use `Field.Control` to automatically associate and validate labels.

<Component path="field/basic" />

`errorMatches` specifies the validation state of the error to display. Passing an object allows you to change the message for each validation state, and passing `true` displays error elements regardless of validation state. Messages are retrieved from `validate` and form validation results.

## Validation and errors [#validation]

You can add your own validation by specifying `validate` . You can select the verification timing for `validationMode` from `onSubmit` , `onBlur` , and `onChange` .

<Component path="field/validation" />

By passing a function to `validity` , you can display arbitrary content depending on the validation state. The argument is passed a state containing `validity` and `errors` .

```tsx
<Field
  label="email address"
  errorMatches={false}
  validity={(state) => (state.validity.valid === true ? <span>Valid.<</span> : null)}
>
  <Field.Control type="email" required />
</Field>
```

`errorMatches` can be specified with a message for each verification state, like `{ valueMissing: "Please enter.", typeMismatch: "Please check the format." }` . Keys can be `valueMissing` , `typeMismatch` , `patternMismatch` , `tooShort` , `tooLong` , `customError` , etc. Adjust the style of the entire error message with `slotProps.error` .

## Parts configuration [#parts]

`Field` is a preset that internally assembles labels, input fields, explanations, and error messages. Available directly from the package root are `Field` and its static members `Field.Control` and `Field.Item` . Adjust labels and descriptions using `slotProps` .

```tsx
<Field
  label="nickname"
  description="It will be visible to other users."
  errorMatches={{ valueMissing: "Please enter your nickname." }}
  slotProps={{ label: { style: { color: "#1d4ed8" } } }}
>
  <Field.Control required placeholder="Sooooo" />
</Field>
```

If you want to combine multiple inputs into one field, such as a checkbox, surround each item with `Field.Item` .

### parts [#parts-props]

`Field` has `Field.Control` and `Field.Item` as static members. Labels, descriptions, errors, and validation status displays are configured as internal parts and adjusted from `slotProps` .

| Parts                   | Description                                                                  |
| ----------------------- | ---------------------------------------------------------------------------- | ------------ | --- |
| `Field.Control`         | Native input field associated with label and validation.                     |
| `Field.Item`            | Combines multiple inputs, such as checkboxes and radios, into a single item. | `Field.Item` |     |
| `slotProps.label`       | Adjust label styles and attributes.                                          |
| `slotProps.description` | Adjust the style and attributes of the description text.                     |
| `slotProps.error`       | Adjust styles and attributes common to all error messages.                   |
| `slotProps.validity`    | Adjust the display style and attributes according to the validation state.   |

## Styling [#styling-hooks]

The root element is given `sui_field` . Depending on the state, class names such as `sui_field-disabled` , `sui_field-touched` , `sui_field-dirty` , `sui_field-invalid` , `sui_field-valid` , `sui_field-unverified` , `sui_field-filled` , `sui_field-focused` are also added.

Internal parts are given `sui_field_label` , `sui_field_description` , `sui_field_error` , `sui_field_control` , and `sui_field_item` , each with the same status qualification class.
