title: ToggleButton
description: Explains ToggleButton props, pressed state, appearance, and pending display.
---

ToggleButton toggles its pressed state on each press. Use it for stateful actions such as formatting toolbars or view switching. Pressed state is managed via `pressed`, and appearance follows the state.

## Basic usage [#basic-usage]

Pass a label or icon to `children`. For icon-only buttons, combine `squared` with `aria-label`.

<Component path="toggle-button/basic" />

Pass `defaultPressed` to start pressed. To manage pressed state yourself, use `pressed` and `onPressedChange`.

```tsx
const [pressed, setPressed] = useState(false);

<ToggleButton pressed={pressed} onPressedChange={setPressed}>
  On
</ToggleButton>;
```

## Appearance [#appearance]

`variant` accepts `liquid` or `naked`. When pressed, the appearance becomes solid regardless of `variant`, and `color` sets that color scheme.

<Component path="toggle-button/appearance" />

`size` has 4 steps: `xs`, `sm`, `md`, `lg`. The default `radius` is `sm` or `md` depending on `size`. `outlined` adds a border.

## Control and pending [#controlled-and-pending]

To sync pressed state with external state, combine `pressed` and `onPressedChange`.

<Component path="toggle-button/controlled" />

Passing `true` to `pending` disables pressing and shows a circular progress indicator. Passing 0–100 to `percentage` shows progress.

<Component path="toggle-button/pending" />

Focus is preserved while pending, so the keyboard context continues unless `disabled` is also used.

## Styling [#styling-hooks]

ToggleButton shares the Button root, so the root carries `sui_button`. Depending on props, class names such as `sui_button-size_md`, `sui_button-color_blue`, `sui_button-radius_md`, `sui_button-variant_solid`, `sui_button-outlined`, `sui_button-squared`, and `sui_button-pending` are added.

The pressed state is exposed via the `data-pressed` attribute from Base UI Toggle. Inner parts carry `sui_button_content`, `sui_button_pending`, `sui_button_circular_progress`, and similar class names.
