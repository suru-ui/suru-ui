Accordion is a component that shows multiple collapsible items. Use it on information-dense pages such as FAQs or settings so readers can expand only what they need. Passing items in `items` automatically builds headings and panels.

## Basic usage [#basic-usage]

Each entry in `items` takes a heading `title` and a panel `content`. Pass the `value` of initially open items as an array to `defaultValue`.

<Component path="accordion/basic" />

Specify each item's value with `value`. When omitted, the index is used. Passing `disabled` as `true` disables only that item.

```tsx
<Accordion
  items={[
    { value: "profile", title: "Profile", content: "..." },
    { value: "security", title: "Security", content: "...", disabled: true },
  ]}
  defaultValue={["profile"]}
/>
```

## Opening multiple items [#multiple]

By default, only one item can be open at a time. With `multiple`, several items can expand simultaneously. When passing multiple values to `defaultValue`, also specify `multiple`.

<Component path="accordion/multiple" />

## States and dividers [#states]

`separator` controls the divider between adjacent items, and `indicator` controls the open/close indicator. Passing `indicator={false}` hides the indicator. Adjust size and radius with `size` and `radius`.

<Component path="accordion/states" />

In addition to per-item `disabled`, the root `disabled` disables the whole accordion. Already open panels stay visible even when everything is disabled.

## Styling [#styling-hooks]

The root element gets `sui_accordion`. Depending on props, class names such as `sui_accordion-size_md`, `sui_accordion-radius_none`, `sui_accordion-separator`, `sui_accordion-disabled`, and `sui_accordion-orientation_vertical` are added.

Inner parts get `sui_accordion_item`, `sui_accordion_heading`, `sui_accordion_trigger`, `sui_accordion_indicator`, and `sui_accordion_content`. Open items also get state classes such as `sui_accordion_item-open` and `sui_accordion_trigger-open`.

You can adjust them with `className` or `style`, or override spacing and borders with CSS variables.
