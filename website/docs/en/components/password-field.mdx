PasswordField is a text field specialized for password entry. It hides input by default and provides a show/hide toggle button. Use it in login forms and account settings wherever passwords are handled.

## Basic usage [#basic-usage]

Specify the value with `defaultValue` or `value`, and hint at the expected input with `placeholder`. The visibility toggle button is shown by default.

<Component path="password-field/basic" />

Use `slotProps.input` to set input attributes. Pass `aria-label`, `autoComplete`, `minLength`, and similar attributes directly to the input.

```tsx
<PasswordField
  slotProps={{
    input: {
      "aria-label": "パスワード",
      autoComplete: "current-password",
      minLength: 8,
    },
  }}
/>
```

## Visibility [#visibility]

Use `visible` and `onVisibleChange` to manage visibility in external state. Use `defaultVisible` to set the initial state uncontrolled. The toggle button switches `aria-pressed` according to state.

<Component path="password-field/visibility" />

Passing `false` to `visibilityToggle` hides the toggle button. If `slotProps.toggle` is specified, the button renders even when `visibilityToggle` is `false`.

## Addons [#addons]

Use `startAddons` and `endAddons` to show content at the start and end of the input. Useful for lock icons or character requirements.

<Component path="password-field/addons" />

## Appearance [#appearance]

`variant` accepts `naked` or `liquid`. Combine `color`, `size`, `radius`, and `outlined` to adjust the look.

### slotProps [#slot-props]

| Key      | Description                                                                     |
| -------- | ------------------------------------------------------------------------------- |
| `addon`  | Props passed to the start/end addons.                                           |
| `input`  | Props passed to the input. Takes precedence over top-level input props.         |
| `toggle` | Props passed to the visibility toggle button. Accepts content and `aria-label`. |

## Styling [#styling-hooks]

The root element carries `sui_password_field`. Depending on props and state, class names such as `sui_password_field-size_md`, `sui_password_field-color_blue`, `sui_password_field-radius_md`, `sui_password_field-variant_naked`, `sui_password_field-outlined`, and `sui_password_field-visible` are added.

Inner parts carry `sui_password_field_input`, `sui_password_field_addon`, `sui_password_field_toggle`, and similar class names.
