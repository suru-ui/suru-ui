AspectRatio is a container component that preserves a given width-to-height ratio. It renders images, videos, or embedded maps at a fixed ratio against a responsively sized width. Its direct child fills the entire container.

## Basic usage [#basic-usage]

Pass the width-to-height ratio to `ratio`. You can pass a string in the same format as CSS `aspect-ratio` (e.g. `16 / 9`), or a number such as `1`. Numbers are interpreted as "width / height".

<Component path="aspect-ratio/basic" />

Children fill the whole container without needing explicit width or height. For images, combine it with `object-fit: cover` to crop while preserving the ratio.

```tsx
<AspectRatio ratio="16 / 9">
  <img
    alt="Scenery"
    src="/cover.jpg"
    style={{ width: "100%", height: "100%", objectFit: "cover" }}
  />
</AspectRatio>
```

## Ratios and radius [#ratios]

`ratio` accepts any value for your use case, such as `1 / 1`, `4 / 3`, `16 / 9`, or `9 / 16`. `radius` controls the container's corner radius.

<Component path="aspect-ratio/ratios" />

The default `radius` is `none`. To round the corners of cards or images, choose from `sm`, `md`, or `lg`.

### Inherited props [#inherited-props]

AspectRatio renders a `div`, so it accepts attributes such as `className`, `style`, `id`, `aria-*`, and `data-*`. You can also replace the root element with `render`. Remaining props are inherited from the base `div` element.

## Styling [#styling-hooks]

The root element gets `sui_aspect_ratio`. Depending on props, class names such as `sui_aspect_ratio-radius_md` are added. The ratio itself is set as the CSS variable `--sui_aspect_ratio-ratio`.

Use `className` or `style` to adjust width or background. To override the ratio itself, use `ratio`.
