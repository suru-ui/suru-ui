TextField arranges a single-line input with adornments inside a bordered box. Prefixes and icons can sit before and after the input. Clicking border padding moves focus to the input, keeping it usable in tight spaces.

## Basic usage [#basic-usage]

Specify input props such as `placeholder`, `defaultValue`, and `type` at the top level. To set input attributes individually, use `slotProps.input`.

<Component path="text-field/basic" />

To add a label and description, wrap with `Field`. Validation results also display together with `Field`.

```tsx
<Field label="Email address" description="Used as contact.">
  <TextField type="email" placeholder="you@example.com" />
</Field>
```

## Addons [#addons]

Pass content shown before and after the input to `startAddons` and `endAddons`. You can pass iterable values such as string prefixes, icons, or arrays.

<Component path="text-field/addons" />

Clicking an addon moves focus to the input. Passing `disableFocusOnClick` stops this automatic focus.

## Appearance and states [#appearance-and-states]

`variant` accepts `naked` or `liquid`. Combine `size`, `radius`, `color`, and `outlined` to match the surrounding design.

<Component path="text-field/appearance" />

`disabled` disables input itself; `readOnly` makes the value unchangeable. Combining a validation error with `Field` `invalid` reflects it in the border color.

### Inherited props [#inherited-props]

The root element is a `div`, so attributes such as `className`, `style`, `id`, `aria-*`, and `data-*` go to the root element. To pass attributes to the input itself, use `slotProps.input`.

## Styling [#styling-hooks]

The root element carries `sui_text_field`. Depending on props, class names such as `sui_text_field-size_md`, `sui_text_field-color_blue`, `sui_text_field-radius_md`, `sui_text_field-variant_naked`, and `sui_text_field-outlined` are added.

The input carries `sui_text_field_input`; addons carry `sui_text_field_addon`. Depending on input state, `sui_text_field_input-focused`, `sui_text_field_input-filled`, `sui_text_field_input-invalid`, `sui_text_field_input-disabled`, and similar classes are added.
