title: FormatNumber

FormatNumber is a component that formats and displays numbers according to the locale. You can specify thousands separators, currency, percentages, units, abbreviations, etc. with the `Intl.NumberFormat` options. Since it is drawn as a text node, visual adjustments are made on the parent element side.

## Basic usage [#basic-usage]

Specifies the number to format in `value` . If `locales` is omitted, the default locale of the execution environment will be used, so if you want to fix the display, specify `"ja-JP"` etc.

<Component path="format-number/basic" />

Toggle `style` to select decimal, currency, percent, and unit formats. For currency, specify the ISO 4217 currency code in `currency` .

## Notation and units [#notation]

`notation="compact"` can be used to shorten large numbers. Combining `style="unit"` and `unit` allows you to attach units to numbers.

<Component path="format-number/notation" />

`currencySign="accounting"` displays negative currency amounts in parentheses. `signDisplay` can also be used to add a sign to positive values. Adjust the number of digits with `minimumFractionDigits` and `maximumFractionDigits` .

## Styling [#styling-hooks]

Because FormatNumber draws formatted text, it does not output HTML elements or class names that start with `sui_` . If you want to change the font color or size, specify the style in the parent element such as `span` or `strong` .

```tsx
<p style={{ fontSize: "1.5rem", fontWeight: 700 }}>
  <FormatNumber value={1234} style="currency" currency="JPY" locales="ja-JP" />
</p>
```
