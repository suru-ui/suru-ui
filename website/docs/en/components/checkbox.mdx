A Checkbox is an input that has two states: on and off. Use this to switch settings or select the appropriate option from multiple options. If you specify the label text by surrounding it with the `label` element, you can toggle the checked state with a click.

## Basic usage [#basic-usage]

Place the label text as a child of the `label` element. If you put the Checkbox and label in the same `label` element, you can toggle the state by clicking the text. Specify `defaultChecked` to make the initial state checked.

<Component path="checkbox/basic" />

The Checkbox `children` is drawn inside the indicator. Use this when you want to replace the check mark with your own icon.

## selection state [#selection-states]

You can control the selection state by specifying `checked` and `onCheckedChange` . `indeterminate` is an intermediate state that indicates only some of the child items are selected.

<Component path="checkbox/states" />

`disabled` disables operations and focus, `readOnly` only allows focus without changing state. Specify `required` if it is required in the form.

## Cooperation with groups [#within-checkbox-group]

If you want to group multiple Checkboxes together, place them as children of CheckboxGroup ](/components/checkbox-group) and specify `value` for each Checkbox. Within a group, `color` , `size` , `radius` , `variant` , and `outlined` can be specified together on the group side.

```tsx
<CheckboxGroup defaultValue={["design"]}>
  <label>
    <Checkbox value="design" />
    design
  </label>
  <label>
    <Checkbox value="engineering" />
    engineering
  </label>
</CheckboxGroup>
```

## Appearance [#appearance]

Specify the color scheme with `color` and the size with `size` . Setting it to `variant="liquid"` will add a thin fill, and setting it to `outlined={false}` will remove the border.

## Styling [#styling-hooks]

The root element is given `sui_checkbox` . Depending on the props and state, the following class names will also be added:

| class name                         | condition                                  |
| ---------------------------------- | ------------------------------------------ |
| `sui_checkbox`                     | Always given.                              |
| `sui_checkbox-size_sm` etc.        | Granted according to `size` .              |
| `sui_checkbox-color_blue` etc.     | Granted according to `color` .             |
| `sui_checkbox-radius_full` etc.    | Granted according to `radius` .            |
| `sui_checkbox-variant_liquid` etc. | Granted according to `variant` .           |
| `sui_checkbox-outlined`            | Granted when `outlined` is `true` .        |
| `sui_checkbox-checked`             | Granted when checked.                      |
| `sui_checkbox-indeterminate`       | Granted when in intermediate state.        |
| `sui_checkbox-disabled`            | Granted when disabled.                     |
| `sui_checkbox-readonly`            | Granted when read-only.                    |
| `sui_checkbox-required`            | Provided when required.                    |
| `sui_checkbox-invalid` etc.        | Granted depending on the validation state. |

Indicators are given `sui_checkbox_indicator` and additional state classes such as `sui_checkbox_indicator-checked` and `sui_checkbox_indicator-disabled` .
