Label is a component that displays labels associated with form controls. If you specify a control's `id` with `htmlFor` or place the control as a child element, clicks and focus will be tied to the label. Suitable when you want to place only the input field and label without using `Field` .

## Basic usage [#basic-usage]

Specify `id` of the control to be associated with `htmlFor` . Make it the same value as `id` on the `Input` side. Clicking on a label will move the focus to the corresponding input field.

<Component path="label/basic" />

Specify the content to be displayed as a label in `children` . If you want to add something like `*` to indicate that it is a required item, specify `aria-hidden="true"` as a decoration and separately set `required` on the control side.

## put control in child [#nesting]

If you place the control as a child element of a label, it will be associated without specifying `htmlFor` and `id` . This is useful if you want the entire label to be clickable, such as a checkbox.

<Component path="label/nested" />

When placing an input field as a child, specifying `style` , which aligns the label and input field vertically, makes it easier to read. If you want to line it up next to a checkbox, combine `display: flex` and `alignItems: center` .

## Appearance and disabled state [#states]

Specify the font color with `color` and the size with `size` . `disabled` only changes the appearance of the label itself, so the associated controls are not disabled. If you want to disable a control, specify the control's own `disabled` .

<Component path="label/states" />

`color` is available in 8 colors. `size` has three stages: `sm` , `md` , and `lg` . When lining up with the input field, aligning `Input` with `size` makes it easier to balance the height.

## Styling [#styling-hooks]

The root element is given `sui_label` . Class names such as `sui_label-size_md` , `sui_label-color_grey` , `sui_label-disabled` are also added depending on the props.

You can adjust mojikumi with CSS variables such as `--sui_label-font_size` , `--sui_label-font_weight` , and `--sui_label-color` .
