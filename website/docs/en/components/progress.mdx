title: Progress

Progress displays the progress of a time-consuming task. Use it to show the path to completion, e.g. file uploads or data loading. Passing `null` to `value` renders an indeterminate state with unknown progress.

## Basic usage [#basic-usage]

Pass the current value from 0 to `max` to `value`. Passing `label` shows a label alongside the current value.

<Component path="progress/basic" />

When `value` reaches `max`, the root gains a completed-state class. Pass copy stating completion as the label so the state is communicated clearly.

## Indeterminate state [#indeterminate]

When the duration is unknown, pass `null` to `value`. The indicator animates indeterminately, and assistive technology is told the progress is undetermined.

<Component path="progress/indeterminate" />

## Formatting [#format]

Pass `Intl.NumberFormat` options to `format` to change how the displayed value is formatted. Passing a function to `slotProps.value` `children` lets you compose a custom display string.

<Component path="progress/format" />

```tsx
<Progress
  label="アップロード中"
  value={42}
  slotProps={{
    value: { children: (formattedValue) => `${formattedValue} 完了` },
  }}
/>
```

## Appearance [#appearance]

`variant` accepts `liquid` or `naked`. Use `color` for the color scheme, `size` for scale, and `radius` for corners. `outlined` toggles the track border.

### slotProps [#slot-props]

| Key         | Type                                   | Description                                                             |
| ----------- | -------------------------------------- | ----------------------------------------------------------------------- |
| `indicator` | `ProgressIndicatorProps`               | Props passed to the progress indicator.                                 |
| `label`     | `Omit<ProgressLabelProps, "children">` | Props passed to the label. Content is set via `label`.                  |
| `track`     | `Omit<ProgressTrackProps, "children">` | Props passed to the track.                                              |
| `value`     | `ProgressValueProps`                   | Props passed to the value display. A `children` function customizes it. |

## Styling [#styling-hooks]

The root element carries `sui_progress`. Depending on props and state, class names such as `sui_progress-size_md`, `sui_progress-color_blue`, `sui_progress-radius_full`, `sui_progress-variant_liquid`, `sui_progress-outlined`, and `sui_progress-status_progressing` are added.

Inner parts carry `sui_progress_label`, `sui_progress_value`, `sui_progress_track`, `sui_progress_indicator`, and similar class names.
