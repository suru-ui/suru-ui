Collapsible is a component that expands or collapses content by manipulating headings or buttons. Use this to hide content that does not need to be displayed all the time, such as supplementary information or detailed settings. If you place `Collapsible.Indicator` inside the trigger, the icon will rotate depending on the open/closed state.

## Basic usage [#basic-usage]

Specify the contents to be folded into `children` of the element drawn as an open/close button in `trigger` . Pass something like `Button` to the trigger and combine it with `Collapsible.Indicator` .

<Component path="collapsible/basic" />

If `trigger` is omitted, no trigger will be drawn. If you want the trigger to be its own element, you can supplement the attribute with `slotProps.trigger` .

## Opening/closing control [#controlled]

`open` and `onOpenChange` can be specified to control the open/closed state. `defaultOpen` is used to set the initial state to an open state.

<Component path="collapsible/controlled" />

The second argument to `onOpenChange` is passed details such as the reason for opening and closing. Specifying `disabled` prevents the trigger from being manipulated.

## Replacing the indicator [#custom-indicator]

Specifying `children` of `Collapsible.Indicator` allows you to replace the default arrow icon with another icon. The indicator automatically rotates according to the open/closed state.

```tsx
<Collapsible
  trigger={
    <Button variant="naked">
      detail
      <Collapsible.Indicator>
        <PlusIcon aria-hidden="true" />
      </Collapsible.Indicator>
    </Button>
  }
>
  This is the content that will be collapsed.
</Collapsible>
```

## Styling [#styling-hooks]

The root element is given `sui_collapsible` . Depending on the props and state, class names such as `sui_collapsible-size_md` , `sui_collapsible-open` , `sui_collapsible-disabled` , `sui_collapsible-transition_status_*` are also added.

Internal parts are given `sui_collapsible_trigger` , `sui_collapsible_content` , `sui_collapsible_indicator` . Content is marked with `sui_collapsible_content` even if it is held in `keepMounted` .
