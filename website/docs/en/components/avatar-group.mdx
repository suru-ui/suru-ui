AvatarGroup renders multiple avatars stacked together. Use it to show several people in limited width, such as member lists or users who reacted. You can cap the visible count and collapse the excess into a `+3` count.

## Basic usage [#basic-usage]

Place `Avatar` elements as children. `size`, `color`, and `radius` propagate from the group to child avatars. When a child avatar sets the same prop, the child's `color` and `radius` win. The group's `size` always wins.

<Component path="avatar-group/basic" />

With `color="auto"`, each child avatar gets an automatically assigned color scheme. The default `color` is `auto`.

```tsx
<AvatarGroup size="md" color="auto">
  <Avatar>A</Avatar>
  <Avatar>B</Avatar>
  <Avatar>C</Avatar>
</AvatarGroup>
```

## Surplus [#surplus]

`max` is the maximum number of avatars shown in the group. The excess is collapsed into a trailing `+N` avatar. `max` includes the surplus avatar.

<Component path="avatar-group/surplus" />

For example, with 6 avatars and `max={4}`, the first 3 plus `+3` are shown. When the avatar count is at most `max`, no surplus is shown.

Pass `reverse` as `true` to reverse the stacking order.

### Inherited props [#inherited-props]

AvatarGroup renders a `div`, so it accepts attributes such as `className`, `style`, `id`, `aria-*`, and `data-*`. Descendants can read the group state via `AvatarGroup.useContext()` or `useAvatarGroupContext()`.

Remaining props are inherited from the base `div` element.

## Styling [#styling-hooks]

The root element gets `sui_avatar_group`. Depending on props, class names such as `sui_avatar_group-size_md`, `sui_avatar_group-color_auto`, `sui_avatar_group-radius_full`, `sui_avatar_group-reverse`, and `sui_avatar_group-forward` are added.

Child avatars get `sui_avatar` class names reflecting the group state.

You can adjust them with `className` or `style`, or override overlap width and spacing with CSS variables.
