Alert displays important messages and notifications with a status indicator. Use it to highlight information the user should notice, such as form submission results or warnings. It combines a title, description, icon, and action buttons.

## Basic usage [#basic-usage]

Pass the heading to `title` and the description to `children`. Pass a status icon to `icon`. When omitted, no icon area is rendered.

<Component path="alert/basic" />

Passing an empty string as `icon=""` shows a round status-colored indicator instead of an icon. Add an `aria-label` when the status has no content.

```tsx
<Alert color="green" title="Sync complete" icon="" aria-label="Done" />
```

## Appearance [#appearance]

Choose `variant` from `muted`, `liquid`, or `naked`. Changing `color` applies to the icon and background. `outlined` controls the border.

<Component path="alert/appearance" />

`size` has three steps: `sm`, `md`, and `lg`. When `radius` is omitted, it matches `size`.

## Actions and layout [#actions]

Passing action buttons to `actions` adds an action area to the alert. `actionsPosition` accepts `side` or `bottom`. `descriptionPosition` places the description below or beside the title.

<Component path="alert/actions" />

`descriptionPosition` accepts the following values:

- `bottom`: places the description below the title.
- `side-start`: places the description to the right of the title, left-aligned.
- `side-end`: places the description to the right of the title, right-aligned.

### Inherited props [#inherited-props]

Alert renders a `div`, so it accepts attributes such as `className`, `style`, `id`, `aria-*`, and `data-*`. The default `role` is `alert`. Use `role="status"` for static announcements.

`className` and `style` accept a function receiving the state. Remaining props are inherited from the base `div` element.

## Styling [#styling-hooks]

The root element gets `sui_alert`. Depending on props, class names such as `sui_alert-color_red`, `sui_alert-size_md`, `sui_alert-radius_md`, `sui_alert-variant_muted`, `sui_alert-outlined`, `sui_alert-actions_position_side`, and `sui_alert-description_position_bottom` are added.

Inner parts get `sui_alert_icon`, `sui_alert_title`, `sui_alert_description`, and `sui_alert_actions`.

You can adjust them with `className` or `style`, or override spacing and colors with CSS variables.
