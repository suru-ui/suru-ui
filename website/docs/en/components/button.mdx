A Button is a component that represents a clickable action. By default it draws native `<button type="button">` .

## Basic usage [#basic-usage]

`children` will be the label of the button. You can specify the appearance with `color` and `variant` , and the size with `size` .

<Component path="button/basic" />

Buttons are drawn using a combination of the following elements:

- Root element (button element by default)
- beginning and end addons
- Content to display labels
- Pending overlay
- circular progress bar

Normally, if you use Button as is, these elements will be configured automatically. If you want to pass props to individual elements, use `slotProps` described below. Direct assembly of parts is described in Component Structure ](/guides/component-anatomy) .

**icon**

If you place an icon in `children` , it will be placed with the label. An icon-only button combines `squared` and `aria-label` . The icon example uses `lucide-react` .

<Component path="button/icons" />

**exterior**

You can choose from `solid` , `naked` , `liquid` for `variant` and 8 colors for `color` .

<Component path="button/appearance" />

**Size**

`size` has four stages: `xs` , `sm` , `md` , and `lg` . The height can be reduced by combining `thin` .

<Component path="button/sizes" />

**shape**

`squared` specifies the square, and `radius` specifies the size of the rounded corners.

<Component path="button/shapes" />

**width**

Specifying the width and flex in `style` will match the layout of the parent element.

<Component path="button/width" />

**qualification**

This is a combination of `muted` , `outlined` , and `disabled` .

<Component path="button/states" />

**situation**

A Button's state is determined by its appearance props and operation state.

| Status   | Condition                                                                                                             | Description                                                                           |
| -------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Normal   | -                                                                                                                     | Displayed in default appearance.                                                      |
| Hover    | The pointer is above                                                                                                  | The background color, text color, and border color change to the values ​​for hover.  |
| Active   | Pressed                                                                                                               | The background color, text color, and border color change to the values ​​for active. |
| Focus    | A focus ring is displayed for normal buttons that are focused by keyboard operations, etc. Not displayed for `item` . |
| Disabled | `disabled` will no longer be able to be pressed, and the color scheme for disabled will be used.                      |
| Hold     | `pending` will no longer be able to press `true`                                                                      | and the progress will be displayed.                                                   |

<Component path="button/pending" />

Press the preview button to see a 1.5 second hold.

**Progress rate**

Passing a value between 0 and 100 to `percentage` will result in a spinner with percentage progress.

<Component path="button/pending-progress" />

**Void and Suspend**

`disabled` disables the button. `pending` also disables presses, but displays a spinner to indicate that it is processing and maintains focus unless used with `disabled` .

```tsx
<Button disabled>Unable to send<</Button>
<Button pending>Sending<</Button>
```

**context**

Descendants of Button can retrieve the state with `Button.useContext()` or `useButtonContext()` .

```tsx
import { Button, useButtonContext } from "@suru-ui/react";

function Status() {
  const state = useButtonContext();

  return <span>{state.pending ? "Processing" : "Waiting"}<</span>;
}

export function SaveButton() {
  return (
    <Button pending slotProps={{ pending: { overlay: false } }}>
      <Status />
    </Button>
  );
}
```

In this example, the pending display is not overlaid to make it easier to check the status change. The context includes states such as `color` , `item` , `muted` , `outlined` , `pending` , `radius` , `size` , `squared` , `thin` , `variant` .

**pending slotProps**

| Prop          | Type      | Default Value | Description                                                                                 |
| ------------- | --------- | ------------- | ------------------------------------------------------------------------------------------- |
| `overlay`     | `boolean` | `true`        | Whether to display as an overlay over the parent element. `false` is placed in normal flow. |
| `keepMounted` | `boolean` | `false`       | Whether to keep it in the DOM even when it is not in a pending state.                       |

If you change `keepMounted` to `true` , it will be hidden in `visibility: hidden` when it is not in a pending state. This can be used when you want to apply CSS transitions to change the display.

## Styling [#styling-hooks]

**Class name**

Button assigns a class name to the root element according to props. Please use this as a guide when applying additional styles.

| Class name                      | Condition                                                    |
| ------------------------------- | ------------------------------------------------------------ |
| `sui_button`                    | Always given.                                                |
| `sui_button-size_xs` etc.       | Granted according to `size` .                                |
| `sui_button-color_grey` etc.    | Granted according to `color` .                               |
| `sui_button-radius_sm` etc.     | Granted according to `radius` .                              |
| `sui_button-variant_solid` etc. | Granted according to `variant` .                             |
| `sui_button-item`               | Granted when `item` is `true` .                              |
| `sui_button-muted`              | Granted when `muted` is `true` .                             |
| `sui_button-outlined`           | Granted when `outlined` is `true` .                          |
| `sui_button-pending`            | Granted when `pending` is `true` .                           |
| `sui_button-squared`            | Granted when `squared` is `true` .                           |
| `sui_button-thin`               | Granted when `thin` is `true` .                              |
| `sui_button-disabled`           | Granted when `disabled` is `true` and `pending` is `false` . |

Internal parts are given class names such as `sui_button_content` , `sui_button_addon` , `sui_button_pending` , `sui_button_circular_progress` .
