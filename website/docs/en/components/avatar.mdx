Avatar displays an image representing a user or organization. When the image fails to load, the text or icon passed to `children` is shown as a fallback. Use it where people should be shown visually, such as profiles or comment threads.

## Basic usage [#basic-usage]

Pass the image URL to `src` and alternative text to `alt`. `children` is the fallback shown when the image cannot be displayed. Omitting `src` shows only the fallback from the start.

<Component path="avatar/basic" />

Initials or short symbols make readable fallbacks. Specifying both the image and a fallback keeps the layout stable while loading or on failure.

```tsx
<Avatar src="/avatar.png" alt="Taro Yamada" size="lg">
  Y
</Avatar>
```

## Appearance [#appearance]

Use `color` for the fallback color scheme, `size` for the size, and `radius` for the corner radius. Both `radius="full"` and `radius="circle"` render a circle.

<Component path="avatar/appearance" />

The default `radius` is `full`. For a square avatar, pass `none`, `sm`, or similar.

### Inherited props [#inherited-props]

Avatar is built on Base UI Avatar, so it accepts `className`, `style`, `render`, and more. The root element renders as a `span` by default. Remaining props are inherited from Base UI Avatar.

## Styling [#styling-hooks]

The root element gets `sui_avatar`. Depending on props, class names such as `sui_avatar-size_md`, `sui_avatar-color_blue`, `sui_avatar-radius_full`, and `sui_avatar-reverse` are added.

Inner parts get `sui_avatar_image` and `sui_avatar_fallback`. The loading state is exposed via class names like `sui_avatar-image_loading_status_loaded`.

You can adjust them with `className` or `style`, or override sizes and colors with CSS variables.
