Switch toggles a setting on and off. Changes apply immediately, so it suits settings that need no submit action. Pair it with a label to clarify what is being toggled.

## Basic usage [#basic-usage]

Combine with text in a `label` element. Passing `defaultChecked` starts in the on state.

<Component path="switch/basic" />

To manage on/off state yourself, combine `checked` and `onCheckedChange`. `onCheckedChange` receives a boolean as its first argument.

```tsx
const [checked, setChecked] = useState(false);

<Switch checked={checked} onCheckedChange={setChecked} />;
```

## Appearance [#appearance]

`variant` toggles the background; `color` sets the on-state color scheme. `size` has 3 steps: `sm`, `md`, `lg`. Passing `false` to `outlined` removes the border.

<Component path="switch/appearance" />

Corners are set with `radius`. The default is `full`; you can pick `none`, `sm`, `md`, `lg`, or `circle`.

## Control [#controlled]

A controlled switch does not visually change unless the `checked` value is updated. Use it when coupling with form validation or async work.

<Component path="switch/controlled" />

`readOnly` only forbids value changes, while `disabled` disables interaction including focus. In both cases, keep the state clear including the label.

## Styling [#styling-hooks]

The root element carries `sui_switch`. Depending on props, class names such as `sui_switch-size_sm`, `sui_switch-color_blue`, `sui_switch-radius_full`, `sui_switch-variant_liquid`, and `sui_switch-outlined` are added.

Depending on state, `sui_switch-checked`, `sui_switch-disabled`, `sui_switch-readonly`, `sui_switch-focused`, `sui_switch-dirty`, `sui_switch-valid`, and similar classes are added. The thumb carries `sui_switch_thumb` plus the same suffixes.
