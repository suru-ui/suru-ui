CheckboxGroup is a component that collects multiple Checkboxes into a selection group. It manages an array of selection values ​​and propagates the appearance such as size and color scheme to the Checkboxes in the group.

## Basic usage [#basic-usage]

Specify `value` for the child Checkbox and pass an array of selection values ​​to `defaultValue` or `value` . Enclose the label in `label` elements.

<Component path="checkbox-group/basic" />

Checkboxes within a group inherit the group's `size` , `color` , `radius` , `variant` , `outlined` . Group settings override the appearance specified for individual Checkboxes.

## Select all [#select-all]

By specifying all the values ​​in the group in `allValues` and placing a Checkbox with `parent` attached, you can switch between selecting all and deselecting all. The parent Checkbox will be in a checked or intermediate state depending on the selected state of the child.

<Component path="checkbox-group/parent" />

## Orientation and appearance [#orientation-and-appearance]

If you specify `orientation="horizontal"` , they will be arranged horizontally. Color scheme and size can be specified for each group.

## Styling [#styling-hooks]

The root element is given `sui_checkbox_group` . Depending on the props, class names such as `sui_checkbox_group-size_md` , `sui_checkbox_group-color_blue` , `sui_checkbox_group-radius_md` , `sui_checkbox_group-variant_liquid` , `sui_checkbox_group-outlined` , `sui_checkbox_group-orientation_horizontal` are also added.

It is given `sui_checkbox_group-disabled` in the disabled state, and `sui_checkbox_group-invalid` or `sui_checkbox_group-valid` in the verified state.
