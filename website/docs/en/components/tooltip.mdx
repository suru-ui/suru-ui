Tooltip shows a short note when an element is hovered or focused. Use it to supplement icon-only buttons or truncated labels. Trigger and popup are linked automatically and close with Escape.

## Basic usage [#basic-usage]

Pass the element showing the tooltip to `trigger` and the note content to `children`. Pass a focusable element as the trigger.

<Component path="tooltip/basic" />

`delay` is the milliseconds to wait before showing; `closeDelay` is the wait before closing. By default it waits 600 ms before showing.

## Placement [#placement]

Use `side` for the display direction and `align` for alignment along that direction. Adjust the distance from the trigger with `sideOffset` and `alignOffset`.

<Component path="tooltip/positions" />

Passing `showArrow` shows an arrow connecting the popup and trigger. Adjust the arrow via `slotProps.arrow`.

## Control and detached [#controlled-and-detached]

To manage open state yourself, combine `open` and `onOpenChange`. Passing `true` to `keepOpenOnClick` keeps it open when the trigger is clicked.

<Component path="tooltip/controlled" />

To place the trigger and popup separately, create a handle with `Tooltip.createHandle` and pass it to both `Tooltip.Trigger` and `Tooltip`.

<Component path="tooltip/detached" />

## Styling [#styling-hooks]

The popup carries `sui_tooltip_popup`. Depending on props, class names such as `sui_tooltip_popup-size_md`, `sui_tooltip_popup-radius_md`, `sui_tooltip_popup-outlined`, `sui_tooltip_popup-open`, `sui_tooltip_popup-side_top`, and `sui_tooltip_popup-align_center` are added.

The trigger carries `sui_tooltip_trigger`, the positioning element `sui_tooltip_positioner`, the arrow `sui_tooltip_arrow`, and the portal `sui_tooltip_portal`. The `Tooltip` root itself renders no HTML element.
