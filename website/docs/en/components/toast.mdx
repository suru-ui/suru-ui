Toast briefly notifies operation results or completion. It appears in a screen corner and closes automatically after a delay. `Toast.Provider` manages notifications; `Toast.useClient` adds and removes them.

## Basic usage [#basic-usage]

Wrap part of the app with `Toast.Provider` and place `Toast.List`. In components adding notifications, call `Toast.useClient` and pass title and description to `add`.

<Component path="toast/basic" />

`timeout` is the milliseconds until a notification auto-closes. `0` never auto-closes. `limit` is the maximum notifications shown at once.

## Types [#types]

The default color scheme follows the notification object `type`: `success` is green, `info` is blue, `warning` is yellow, and `error` is red. Unmatched types render grey.

<Component path="toast/types" />

You can also set `color` on `Toast` explicitly. `type` remains as the notification category, so it can drive icon or copy switching.

## Actions and appearance [#actions-and-appearance]

To add action buttons, specify button content and handlers in `actionProps`. Passing a function to `Toast.List` `children` customizes each notification individually.

<Component path="toast/action" />

`close` is the close-button copy; it defaults to "Close". `actionsPosition` and `descriptionPosition` adjust the action and description layout.

### Inherited props [#inherited-props]

`Toast` is built on Base UI Toast, so `swipeDirection` sets the swipe-to-dismiss direction. The default is `["down", "right"]`. Attributes such as `className`, `style`, `aria-*`, and `data-*` also go to the root element.

## Styling [#styling-hooks]

The notification root carries `sui_toast`. Depending on state, class names such as `sui_toast-transition_status_starting`, `sui_toast-limited`, `sui_toast-swiping`, `sui_toast-expanded`, and `sui_toast-type_success` are added.

Content carries `sui_toast_content`, the heading `sui_toast_title`, the body `sui_toast_description`, action buttons `sui_toast_action`, and the close button `sui_toast_close`. The viewport is `sui_toast_viewport` and the portal `sui_toast_portal`.
