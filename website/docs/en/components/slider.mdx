Slider selects a number by dragging a thumb. Suitable for intuitively picking continuous values or ranges such as volume, opacity, or price bands. Thumbs work with pointer input plus arrow keys.

## Basic usage [#basic-usage]

Pass the initial value to `defaultValue`. Passing `label` shows a label above the slider; passing `renderValue` shows the current value. Passing `true` to `renderValue` shows the formatted value as-is.

<Component path="slider/basic" />

Passing a function to `renderValue` receives the formatted-value array and raw-value array. Use it to add units or suffixes.

```tsx
<Slider label="音量" renderValue={(formatted) => `${formatted[0]} dB`} defaultValue={40} />
```

## Appearance [#appearance]

`variant` accepts `naked` or `liquid`. `color` applies to the filled portion; `size`, `radius`, and `outlined` adjust the shape.

<Component path="slider/appearance" />

`outlined` defaults to `true`. Removing the border expresses the track with background alone.

## Range and control [#range-and-controlled]

Passing an array to `value` or `defaultValue` renders one thumb per value. Use `min`, `max`, and `step` for range and step.

<Component path="slider/range" />

Passing `value` makes it controlled. Receive changes via `onValueChange` and update state. Use `onValueCommitted` to run logic when the change settles.

```tsx
const [value, setValue] = React.useState<readonly number[]>([30, 70]);

<Slider
  min={0}
  max={100}
  step={5}
  value={value}
  onValueChange={setValue}
  renderValue={(formatted) => `${formatted[0]} から ${formatted[1]}`}
/>;
```

### slotProps [#slot-props]

| Slot        | Type                                   | Description                                                     |
| ----------- | -------------------------------------- | --------------------------------------------------------------- |
| `control`   | `Omit<SliderControlProps, "children">` | Props passed to the interaction area. Set vertical height here. |
| `indicator` | `SliderIndicatorProps`                 | Props passed to the indicator showing the selected range.       |
| `label`     | `Omit<SliderLabelProps, "children">`   | Props passed to the label element.                              |
| `thumb`     | `SliderThumbProps`                     | Props passed to every thumb. `index` is set internally.         |
| `track`     | `Omit<SliderTrackProps, "children">`   | Props passed to the track.                                      |
| `value`     | `Omit<SliderValueProps, "children">`   | Props passed to the current-value display.                      |

For `orientation="vertical"`, set the height via `slotProps.control.style`.

## Styling [#styling-hooks]

The root element carries `sui_slider`. Depending on props and state, class names such as `sui_slider-size_md`, `sui_slider-color_blue`, `sui_slider-radius_full`, `sui_slider-variant_liquid`, `sui_slider-outlined`, `sui_slider-disabled`, and `sui_slider-orientation_vertical` are added.

Inner parts carry `sui_slider_label`, `sui_slider_value`, `sui_slider_control`, `sui_slider_track`, `sui_slider_indicator`, and `sui_slider_thumb`. Each part also gains size/state classes.
