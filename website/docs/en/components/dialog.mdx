Dialog is a component that displays a temporary area in the center of the screen. It is used in situations where you want to temporarily concentrate the user's operations, such as checking, inputting information, or displaying details. By default, it appears modally and blocks interaction with the background.

## Basic usage [#basic-usage]

Specify the element that opens the dialog in `trigger` and pass the contents to `title` , `description` , and `children` . `close` is the close action that will be placed in the footer, and `footer` is the content that will be added before it.

<Component path="dialog/basic" />

The close icon in the top right corner is displayed by default. Specifying `showCloseIconButton={false}` will hide it. `action` allows you to add your own operations before the close icon.

## Opening/closing control [#controlled]

Specifying `open` and `onOpenChange` allows you to control opening and closing of the dialog. It can also be used when opening from an external button without using a trigger.

<Component path="dialog/controlled" />

`onClose` is called when `close` is clicked. If you want to validate before closing, you can stop the closing operation by calling the event's `preventBaseUIHandler()` .

```tsx
<Dialog
  close={<Button>save<</Button>}
  onClose={(event) => {
    if (!isValid) {
      event.preventBaseUIHandler();
    }
  }}
  title="Edit profile"
>
  Please check your input.
</Dialog>
```

## Stacked appearance [#stacked]

`variant="stacked"` creates an appearance with headings and descriptions centered and actions stacked to the top right.

<Component path="dialog/stacked" />

You can remove the border with `outlined={false}` . `size` and `radius` can be selected from the same stage as the card.

## imperative operation [#imperative]

The handle created with `Dialog.createHandle()` can be used to open and close it from outside the component. Pass the handle to `handle` .

```tsx
const handle = Dialog.createHandle();

handle.open(null);
handle.close();

<Dialog handle={handle} title="notification" />;
```

`Dialog.ToggleTrigger` is used when you want to place triggers associated with handles individually.

The `Dialog` component has `createHandle` and `ToggleTrigger` as static members. You can create handles with `Dialog.createHandle()` and place triggers individually with `Dialog.ToggleTrigger` .

`className` and `style` apply to popups. Use `render` to replace popup elements. Props other than those listed here are inherited from Dialog in Base UI.

## Styling [#styling-hooks]

Popups are given `sui_dialog_popup` . Depending on the state, class names such as `sui_dialog_popup-size_md` , `sui_dialog_popup-radius_md` , `sui_dialog_popup-variant_stacked` , `sui_dialog_popup-outlined` , `sui_dialog_popup-open` , `sui_dialog_popup-nested` are also added.

Triggers are given `sui_dialog_trigger` . Internal parts have class names such as `sui_dialog_header` , `sui_dialog_title` , `sui_dialog_description` , `sui_dialog_content` , `sui_dialog_footer` , etc.
