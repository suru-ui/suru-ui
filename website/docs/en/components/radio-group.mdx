RadioGroup groups multiple radio buttons and manages their selection. Only one value is selected within a group, and arrow keys move between options. Use [Radio](/components/radio) for the individual buttons.

## Basic usage [#basic-usage]

Pass the initially selected value to `defaultValue` and arrange Radio buttons with labels as children. For controlled state, use `value` and `onValueChange`.

<Component path="radio-group/basic" />

Associate the group with an `aria-label` or an external label so users know what the group selects.

## Orientation [#orientation]

Pass `"horizontal"` to `orientation` to lay radio buttons out horizontally. The default is `"vertical"`.

<Component path="radio-group/orientation" />

## Controlled selection [#controlled]

Use `value` and `onValueChange` to manage the selection externally. The first `onValueChange` argument receives the selected Radio's `value`.

<Component path="radio-group/controlled" />

## Appearance [#appearance]

`color`, `size`, `radius`, `variant`, and `outlined` set the appearance of all radio buttons in the group at once. Values set on the group take precedence over values set on individual Radios.

```tsx
<RadioGroup defaultValue="a" color="blue" size="lg" variant="liquid">
  <label>
    <Radio value="a" />
    選択肢 A
  </label>
</RadioGroup>
```

## Styling [#styling-hooks]

The root element carries `sui_radio_group`. Depending on props and state, class names such as `sui_radio_group-size_md`, `sui_radio_group-color_blue`, `sui_radio_group-radius_full`, `sui_radio_group-variant_naked`, `sui_radio_group-orientation_vertical`, `sui_radio_group-outlined`, and `sui_radio_group-disabled` are added.
