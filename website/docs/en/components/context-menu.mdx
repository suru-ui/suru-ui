title: ContextMenu
description: Describes the ContextMenu component's props, item objects, submenus, check items, and radio items.

ContextMenu is the menu that opens on right-click or long press. Used in situations such as file operations and text editing, where you select an object and then display the operation. You can assemble groups, submenus, check items, and radio items just by arranging item objects in `items` .

## Basic usage [#basic-usage]

Specify the right-click target in `trigger` and the menu item in `items` . Items are objects with `label` , and `color` can be specified to display destructive operations in red.

<Component path="context-menu/basic" />

You can pass `div` or an image to open the menu. If you want to control opening and closing with `open` , you can omit the trigger and open from an external element.

## Groups and submenus [#groups-and-submenus]

Nesting `items` creates groups, and `label` displays headings. The `type: "submenu"` item displays its child `items` as a submenu.

<Component path="context-menu/items" />

A separator line appears at the end of the group. You can also place `kbd` elements that represent icons and keyboard shortcuts in the `label` of an item.

## Items with status [#stateful-items]

The `type: "checkbox"` item can be turned on or off. For the item `type: "radio-group"` , select one from the child `type: "radio"` . If you want to control the selection state, specify `checked` and `onCheckedChange` or `value` and `onValueChange` .

<Component path="context-menu/stateful" />

Use `checkboxIndicator` to show checked and `radioIndicator` to show radio selected. Both allow you to pass props individually with `slotProps` .

## Styling [#styling-hooks]

The class name is given to popups and triggers because routes do not render HTML elements.

| class name                                  | condition                           |
| ------------------------------------------- | ----------------------------------- |
| `sui_context_menu_popup`                    | Always given.                       |
| `sui_context_menu_popup-open`               | Given when the menu is open.        |
| `sui_context_menu_popup-size_md` etc.       | Granted according to `size` .       |
| `sui_context_menu_popup-radius_md` etc.     | Granted according to `radius` .     |
| `sui_context_menu_popup-variant_naked` etc. | Granted according to `variant` .    |
| `sui_context_menu_popup-outlined`           | Granted when `outlined` is `true` . |
| `sui_context_menu_trigger`                  | Always given to triggers.           |
| `sui_context_menu_item`                     | Always given to each item.          |
| `sui_context_menu_checkbox_item`            | Assigned to check items.            |

`sui_context_menu_item-highlighted` and `sui_context_menu_item-disabled` are added to the items, and `sui_context_menu_item-checked` is added to the check items. `sui_context_menu_popup-side_*` and `sui_context_menu_popup-align_*` are given depending on the placement of the popup.
