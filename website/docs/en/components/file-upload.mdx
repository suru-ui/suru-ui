FileUpload is a component that selects files by clicking or by dragging and dropping. You can display a list of selected files, delete them individually, and inspect them by type, number, and size. Dropzones and hidden inputs are automatically configured internally.

## Basic usage [#basic-usage]

Specify the drop zone information in `children` . If omitted, "Drag and drop files here or click to select" will be displayed. You can combine `accept` , `multiple` , `maxFiles` , etc. to limit the files accepted.

<Component path="file-upload/basic" />

`accept` accepts strings in the same format as the HTML `accept` attribute. You can also combine multiple specifications in an array. If `multiple` is not specified, the new selection replaces the existing selection.

## Verification and Rejection Reporting [#validation]

Files that do not match `accept` , `maxFiles` , `maxFileSize` , `minFileSize` are not selected and are reported in `onFileReject` . `onFileAccept` allows you to retrieve only files that pass validation.

<Component path="file-upload/validation" />

The reason for the rejection can be found in `reason` of `rejectedFiles` .

| Reason         | Condition                                        |
| -------------- | ------------------------------------------------ |
| `invalid_type` | File type does not match `accept`                |
| `max_files`    | Exceeds the number of files that can be selected |
| `min_size`     | File size is smaller than `minFileSize`          |
| `max_size`     | File size is larger than `maxFileSize`           |

`acceptedFiles` of `onFileReject` contains the files accepted in the same selection. If you want to show users only the rejected files, use `rejectedFiles` to construct the message.

## Control selection state [#controlled]

`value` and `onValueChange` allow you to maintain the list of selected files in external state. Use `defaultValue` to specify an initial value without control.

<Component path="file-upload/controlled" />

`value` receives `readonly File[]` and `onValueChange` receives `File[]` . If you send a file when submitting a form, specify `name` and it will be reflected in the hidden input.

## Parts and slotProps [#parts-and-slot-props]

FileUpload consists of parts such as `Root` , `HiddenInput` , `Dropzone` , `ItemGroup` , `Item` , `ItemName` , `ItemSizeText` , `ItemDeleteTrigger` . `Trigger` and `ClearTrigger` allow you to place select buttons and delete all buttons separate from the drop zone.

`slotProps` allows you to pass props to the parts that the preset draws internally.

| Slot                | Role                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| `dropzone`          | This is an area that accepts drag and drop. `children` is specified in `children` of FileUpload. |
| `hiddenInput`       | A hidden input that opens a file selection dialog.                                               |
| `itemGroup`         | This is an element that compiles a list of selected files.                                       |
| `item`              | This item displays one file. `file` and `children` will be overwritten.                          |
| `itemName`          | This is an element that displays the file name.                                                  |
| `itemSizeText`      | This element displays the file size.                                                             |
| `itemDeleteTrigger` | This is a button to delete a file. The default value of `children` is '×'.                       |

## Styling [#styling-hooks]

The root element is given `sui_file_upload` . Depending on the props, class names such as `sui_file_upload-size_md` , `sui_file_upload-color_grey` , `sui_file_upload-radius_md` , `sui_file_upload-variant_naked` , `sui_file_upload-disabled` , `sui_file_upload-multiple` , `sui_file_upload-required` are also added.

Drop zones are given `sui_file_upload_dropzone` and appended with `sui_file_upload_dropzone-dragover` while dragging. Selected file items are given `sui_file_upload_item` , file names are given `sui_file_upload_item_name` , and sizes are given `sui_file_upload_item_size_text` .

You can override spacing, borders, and background colors with CSS variables such as `--sui_file_upload-gap` and `--sui_file_upload_dropzone-*` .
