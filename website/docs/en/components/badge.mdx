Badge is a small label that shows a status or count. It can stand alone or be overlaid on the corner of an avatar or icon with `position`.

## Basic usage [#basic-usage]

Pass the displayed content to `children`. Use a short number or label, such as a notification count.

<Component path="badge/basic" />

With `variant="dot"`, only a small dot is rendered without content. Add an `aria-label` when the status carries no content.

```tsx
<Badge variant="dot" color="blue" aria-label="You have unread notifications" />
```

**Appearance**

Use `color` for the color scheme and `size` for the size. `outlined` shows a border, and `ring` shows a ring that separates the badge from the element underneath.

```tsx
<Badge color="green">Done</Badge>
<Badge color="orange" outlined>Pending</Badge>
<Badge color="red" ring>3</Badge>
```

## Overlay [#overlay]

With `position`, the badge is absolutely positioned at one of the four corners of the positioned ancestor. `overlap` adjusts where the badge center sits based on the shape of the anchor element.

<Component path="badge/overlay" />

- `overlap="rectangular"`: centers the badge on the corner of a rectangle.
- `overlap="circular"`: centers the badge on the circumference of a circle.

### Inherited props [#inherited-props]

Badge renders a `span`, so it accepts attributes such as `className`, `style`, `id`, `aria-*`, and `data-*`. When using `position`, give the parent `position: relative` or `position: absolute`.

## Styling [#styling-hooks]

The root element gets `sui_badge`. Depending on props, class names such as `sui_badge-size_sm`, `sui_badge-color_red`, `sui_badge-radius_full`, and `sui_badge-variant_dot` are added.

You can adjust it with `className` or `style`, or override sizing and spacing with the `--sui_badge-*` CSS variables.
