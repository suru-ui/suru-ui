Segments is a segmented control selecting one of several related options. Suitable when a few options should always stay visible, e.g. switching time periods or sort orders. It is internally built on tabs.

## Basic usage [#basic-usage]

Pass options as an array to `items`. Each item is either a bare value or an object with `label` and `value`. `defaultValue` sets the initial selection.

<Component path="segments/basic" />

Omitting `items`, you can also pass items directly as `children`. Normally use `items` to keep labels and values explicit.

## Appearance [#appearance]

`activeVariant` is the appearance of the selected item. `solid` is filled, `liquid` is a light fill, and `naked` has no background. Tune with `color`, `size`, `radius`, and `thin`.

<Component path="segments/appearance" />

When `radius` is omitted it matches `size`. `thin` halves vertical padding to reduce height.

## Controlled selection [#controlled]

Passing `value` makes it a controlled component. Receive the new value via `onValueChange` and update state. Passing `disabled: true` on an item disables only that item.

<Component path="segments/controlled" />

```tsx
const [value, setValue] = React.useState("week");

<Segments items={items} value={value} onValueChange={(nextValue) => setValue(String(nextValue))} />;
```

Passing `orientation="vertical"` stacks items vertically.

### slotProps [#slot-props]

| Slot        | Type                                             | Description                                                            |
| ----------- | ------------------------------------------------ | ---------------------------------------------------------------------- |
| `indicator` | `SegmentsIndicatorProps`                         | Props passed to the indicator of the selected item.                    |
| `item`      | `Omit<SegmentsItemProps, "children" \| "value">` | Props passed to every item. `children` and `value` are not overridden. |
| `list`      | `Omit<SegmentsListProps, "children">`            | Props passed to the list arranging items.                              |

## Styling [#styling-hooks]

The root element carries `sui_segments`. Depending on props and state, class names such as `sui_segments-size_md`, `sui_segments-color_blue`, `sui_segments-radius_full`, `sui_segments-active_variant_liquid`, `sui_segments-orientation_vertical`, and `sui_segments-thin` are added.

Inner parts carry `sui_segments_list`, `sui_segments_item`, and `sui_segments_indicator`. The selected item gains `sui_segments_item-active`; disabled items gain `sui_segments_item-disabled`.
