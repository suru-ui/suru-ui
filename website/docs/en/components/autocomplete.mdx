Autocomplete is an input field that narrows down the candidates based on the string you enter. Assists input in situations where there are many candidates, such as search forms and item selection. In addition to arrays of strings, you can pass objects that are pairs of display labels and values, or grouped items.

## Basic usage [#basic-usage]

Specify the list of candidates in `items` and the guidance text for the input field in `placeholder` . Click or type in the input field to open a pop-up with suggestions. If there are no candidates, the contents of `empty` will be displayed.

<Component path="autocomplete/basic" />

In addition to strings, you can also pass objects with `{ label, value }` to `items` . When using objects, `value` is used for the selection value and `label` is used to display suggestions.

```tsx
<Autocomplete
  items={[
    { label: "Tokyo", value: "13" },
    { label: "Osaka prefecture", value: "27" },
  ]}
  placeholder="Search by prefecture"
/>
```

## Grouped [#grouped]

If you pass an array of groups with `{ label, items }` to `items` , each group will be displayed with a heading and a separator line. Specify `separator={false}` to hide the separator line at the end of the group.

<Component path="autocomplete/grouped" />

Items within a group can also be strings or `{ label, value }` objects. If you omit `label` for the group, no heading will be drawn.

## External filtering [#filtering]

You can disable filtering inside the component by specifying `filter={null}` . In this case, pass the suggestions to display to `filteredItems` . Suitable for using search API results or your own matching logic.

<Component path="autocomplete/filtered" />

Get the input value in `onValueChange` and update `filteredItems` accordingly. If you pass the number of items and loading status to `status` , the status will also be transmitted to the screen reader.

## Styling [#styling-hooks]

Input groups are given `sui_autocomplete` . Depending on the props, class names such as `sui_autocomplete-size_md` , `sui_autocomplete-color_blue` , `sui_autocomplete-radius_md` , `sui_autocomplete-variant_liquid` , `sui_autocomplete-outlined` , `sui_autocomplete-open` , `sui_autocomplete-disabled` , `sui_autocomplete-readonly` , `sui_autocomplete-focused` are also added.

Internal parts are given `sui_autocomplete_input` , `sui_autocomplete_item` , `sui_autocomplete_group` , `sui_autocomplete_group_label` , `sui_autocomplete_empty` , `sui_autocomplete_popup` , etc. `sui_autocomplete_item-highlighted` is used for candidate highlighting.

In addition to adjusting `className` and `style` , you can override widths and margins using CSS variables.
