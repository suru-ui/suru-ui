Select picks a value from predefined options. It supports single and multiple selection and can group options. When there are many options, consider Combobox for filterable input.

## Basic usage [#basic-usage]

Specify options in `items` and adjust the display with `label` and `placeholder`. When an option is a string, it is used as both label and value.

<Component path="select/basic" />

`defaultValue` sets the initial value. Passing `value` makes it controlled, so pair it with `onValueChange`.

## Items [#items]

`items` accepts the following forms:

- An array of values such as strings
- An array of objects with `label` and `value`
- An object mapping values to display content
- An array of groups with `label` and `items`

<Component path="select/grouped" />

Groups render with a heading and dividers. Passing `disabled` on an item disables only that item.

## Multiple and controlled [#multiple-and-controlled]

Passing `multiple` allows selecting several values. In that case `defaultValue` and `value` are arrays.

<Component path="select/multiple" />

```tsx
const [value, setValue] = React.useState<string[]>([]);

<Select items={["TypeScript", "Rust", "Go"]} multiple value={value} onValueChange={setValue} />;
```

The `onValueChange` argument is the selected value for single selection or an array for multiple selection. Even with object items, only the value is passed.

## Appearance [#appearance]

`variant` accepts `naked` or `liquid`. Adjust the trigger and popup shape with `size`, `radius`, and `outlined`.

<Component path="select/appearance" />

Passing `true` to `backdrop` shows a backdrop behind the popup. Use `slotProps.backdrop` to change its content or props.

### slotProps [#slot-props]

| Slot              | Description                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------- |
| `arrow`           | Props passed to the popup arrow.                                                              |
| `backdrop`        | Props passed to the backdrop. Specifying it shows the backdrop even when `backdrop` is false. |
| `group`           | Props passed to groups.                                                                       |
| `groupLabel`      | Props passed to group headings.                                                               |
| `icon`            | Props passed to the trigger icon.                                                             |
| `item`            | Props passed to every item. `children` and `value` are not overridden.                        |
| `itemIndicator`   | Props passed to the indicator shown on selected items.                                        |
| `itemText`        | Props passed to item labels.                                                                  |
| `label`           | Props passed to the label above the trigger.                                                  |
| `list`            | Props passed to the list arranging items.                                                     |
| `popup`           | Props passed to the popup.                                                                    |
| `portal`          | Props passed to the portal.                                                                   |
| `positioner`      | Props passed to the positioning element. Accepts `side`, `align`, `sideOffset`, etc.          |
| `scrollDownArrow` | Props passed to the scroll-down arrow.                                                        |
| `scrollUpArrow`   | Props passed to the scroll-up arrow.                                                          |
| `separator`       | Props passed to dividers between groups.                                                      |
| `value`           | Props passed to the current value shown in the trigger.                                       |

`className` and `style` apply to the trigger. The trigger renders a native `button`, so button attributes such as `onClick` and `aria-*` also pass through.

## Styling [#styling-hooks]

The trigger carries `sui_select`. Depending on props and state, class names such as `sui_select-size_md`, `sui_select-radius_full`, `sui_select-variant_liquid`, `sui_select-outlined`, `sui_select-open`, `sui_select-placeholder`, and `sui_select-disabled` are added.

The popup and list carry `sui_select_popup` and `sui_select_list`. Items carry `sui_select_item` plus `sui_select_item-selected` when selected, `sui_select_item-highlighted` when highlighted, and `sui_select_item-disabled` when disabled.
