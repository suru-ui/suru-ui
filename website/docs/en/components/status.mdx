Status shows a state such as online or in-progress with a colored dot and label. Use it to concisely show user presence or background-task progress in lists.

## Basic usage [#basic-usage]

`children` is the label shown beside the dot. Specify the state color with `color`. Omitting the label shows only the dot.

<Component path="status/basic" />

## Ripple [#ping]

Passing `ping` shows a ripple animation spreading from the dot. Use it to emphasize an ongoing state such as processing.

<Component path="status/ping" />

`rippleSize` is the ripple size. Passing `true` to `containRipple` reserves room for ripple overflow, including the ripple in the layout footprint.

## Appearance [#appearance]

`color` offers 8 colors; `size` offers `sm`, `md`, `lg`. Colors apply to the indicator dot; label text color does not change.

### Inherited props [#inherited-props]

Status renders a `span`. It accepts `className`, `style`, `id`, `aria-*`, `data-*`, and similar attributes. `className` and `style` also accept functions receiving `Status.State`, whose state includes `color`, `ping`, `rippleSize`, `size`, and `containRipple`. `render` replaces the root element.

## Styling [#styling-hooks]

The root element carries `sui_status`. Depending on props, class names such as `sui_status-color_green`, `sui_status-size_lg`, `sui_status-ripple_size_sm`, `sui_status-ping`, and `sui_status-contain_ripple` are added.

The indicator carries `sui_status_indicator` plus classes for color, size, and ripple.
