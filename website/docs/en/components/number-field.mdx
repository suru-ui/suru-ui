NumberField is a text field specialized for numeric input. It supports step buttons, keyboard input, and drag-to-change scrubbing, with configurable min, max, and step. Use it for amounts and quantities where strict numeric handling matters.

## Basic usage [#basic-usage]

Pass an initial value via `defaultValue` and a display name via `scrubArea` to show a label above the input. Pass `decrement` and `increment` to show step-down and step-up buttons.

<Component path="number-field/basic" />

Passing `true` to `decrement` and `increment` shows the default icons. Passing any element renders it as the button content.

## Interactions and states [#interactions]

With `scrubArea`, a label region is rendered that changes the value when dragged. When the input is focused, the up/down arrow keys also step the value. Holding Shift steps by `largeStep`; holding Alt steps by `smallStep`.

Use `value` and `onValueChange` to manage the value in external state. The `onValueChange` value is `number | null`, so empty input is representable.

<Component path="number-field/controlled" />

`disabled` and `readOnly` restrict the input itself. `allowOutOfRange` lets directly typed values exceed `min`/`max`. Button and keyboard stepping always stays within range regardless of this setting.

<Component path="number-field/states" />

## Addons [#addons]

Use `startAddons` and `endAddons` to show content at the start and end of the input. Useful for currency symbols or units.

```tsx
<NumberField
  defaultValue={1000}
  startAddons={[<JapaneseYenIcon aria-hidden="true" />]}
  endAddons={["円"]}
/>
```

## Appearance [#appearance]

`variant` accepts `naked` or `liquid`. Combine `color`, `size`, `radius`, and `outlined` to adjust the look.

### slotProps [#slot-props]

| Key               | Description                                                           |
| ----------------- | --------------------------------------------------------------------- |
| `addon`           | Props passed to the start/end addons.                                 |
| `decrement`       | Props passed to the step-down button.                                 |
| `group`           | Props passed to the group wrapping the input and buttons.             |
| `increment`       | Props passed to the step-up button.                                   |
| `input`           | Props passed to the input. Accepts `aria-label`, `autoComplete`, etc. |
| `scrubArea`       | Props passed to the scrub region.                                     |
| `scrubAreaCursor` | Props passed to the cursor during scrubbing.                          |

## Styling [#styling-hooks]

The root element carries `sui_number_field`. Depending on props and state, class names such as `sui_number_field-size_md`, `sui_number_field-color_blue`, `sui_number_field-radius_md`, `sui_number_field-variant_naked`, `sui_number_field-outlined`, `sui_number_field-disabled`, `sui_number_field-focused`, and `sui_number_field-invalid` are added.

Inner parts carry `sui_number_field_group`, `sui_number_field_input`, `sui_number_field_addon`, `sui_number_field_increment`, `sui_number_field_decrement`, `sui_number_field_scrub_area`, and similar class names.
