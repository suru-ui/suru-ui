Tabs switches between related panels. Passing tab labels and content in `items` automatically builds the tab list and matching panels. Move between tabs with arrow keys and select with `Enter` or `Space`.

## Basic usage [#basic-usage]

Each entry in `items` takes `label`, `value`, and `content`. Pass the `value` of the initially shown tab to `defaultValue`. Items without `content` render no panel.

<Component path="tabs/basic" />

Tab width follows the root element width. Adjust with `style` to fit the layout.

## Appearance [#appearance]

`variant` accepts `line` or `segments`. With `segments`, combine with `activeVariant` to change the selected-tab fill.

<Component path="tabs/appearance" />

`size` has 3 steps: `sm`, `md`, `lg`; `thin` halves vertical padding. `radius` defaults to the same value as `size`.

## Orientation and control [#orientation-and-controlled]

Passing `vertical` to `orientation` stacks tabs vertically. Arrow keys follow the direction.

<Component path="tabs/vertical" />

To manage the selected tab yourself, combine `value` and `onValueChange`. `onValueChange` receives the new value.

<Component path="tabs/controlled" />

Passing `disabled` on an `items` entry makes that tab unselectable. Clicking a disabled tab leaves the current value unchanged.

## Styling [#styling-hooks]

The root element carries `sui_tabs`. Depending on props, class names such as `sui_tabs-size_md`, `sui_tabs-radius_md`, `sui_tabs-variant_line`, `sui_tabs-active_variant_liquid`, `sui_tabs-outlined`, `sui_tabs-thin`, and `sui_tabs-orientation_horizontal` are added.

Inner parts carry `sui_tabs_list`, `sui_tabs_tab`, `sui_tabs_indicator`, and `sui_tabs_panel`. The selected tab gains `sui_tabs_tab-active`; disabled tabs gain `sui_tabs_tab-disabled`.
