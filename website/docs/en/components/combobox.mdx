title: Combobox

Combobox is a component that selects a value from predefined items while narrowing down the candidates in an input field. It supports both single selection and multiple selection, and is used in situations where there are many candidates or when you want to obtain candidates according to input. You can also switch to placing the input field inside the popup.

## Basic usage [#basic-usage]

Specify the candidate array in `items` and pass the input field guidance text to `placeholder` . As you type, the default filter narrows down the suggestions.

<Component path="combobox/basic" />

If there are no candidates, the contents of `empty` will be displayed. `status` is used to inform screen readers about the progress of asynchronous searches.

## multiple selection [#multiple]

`multiple` allows you to select multiple values. The selected value will be displayed as a chip in the input field and can be deselected using the Delete Chip button.

<Component path="combobox/multiple" />

Setting `keepFilterOnSelect` to `true` allows the input field to remain filtered and the popup to remain open even after selecting an item.

## Grouped [#grouping]

If objects with `label` and `items` are arranged in `items` , each group will be displayed with a heading and a dividing line. You can remove the separator line at the end of the group with `separator={false}` .

<Component path="combobox/grouped" />

## Asynchronous search [#async-search]

If you want to get suggestions from the server, disable default filtering in `filter={null}` and receive input values ​​in `onInputValueChange` to update `items` . If you pass a search or error message to `status` , it will read the status.

<Component path="combobox/async-search" />

`itemToStringLabel` converts the selected value to a string to be displayed in the input field or chip. By specifying `isItemEqualToValue` , you can independently determine the identity of items.

## Styling [#styling-hooks]

Input groups are given `sui_combobox` . Depending on the state, class names such as `sui_combobox-size_md` , `sui_combobox-color_blue` , `sui_combobox-radius_md` , `sui_combobox-variant_liquid` , `sui_combobox-outlined` , `sui_combobox-open` , `sui_combobox-disabled` , `sui_combobox-placeholder` are also added.

Popups are given `sui_combobox_popup` and `sui_combobox_popup-size_*` , `sui_combobox_popup-open` , `sui_combobox_popup-empty` , `sui_combobox_popup-side_*` , `sui_combobox_popup-align_*` , etc. are added depending on the state.

Candidate items are marked with `sui_combobox_item` and also have a status class such as `sui_combobox_item-selected` , `sui_combobox_item-highlighted` , `sui_combobox_item-disabled` , etc. Chips are marked `sui_combobox_chip` .
