Form is a component that summarizes the form's validation state and collects the values ​​as an object upon submission. By default it draws the native `<form>` element and works with the internal `Field` to control error display. In addition to native form attributes, you can take advantage of the validation mechanisms provided by Form in Base UI.

## Basic usage [#basic-usage]

Create an input field by combining `Field` and `Input` and place a submit button. `onFormSubmit` allows you to receive form values ​​as objects when submitting.

<Component path="form/basic" />

If you specify `onFormSubmit` , the native submit event will automatically call `preventDefault()` . If you want to use regular `onSubmit` , you can still pass event handlers.

## Validation and errors [#validation]

Specify the verification timing with `validationMode` . If you pass a server-side error to `errors` , the message will be displayed in `Field` with the appropriate `name` .

<Component path="form/validation" />

| Value      | Validation Timing                                                                           |
| ---------- | ------------------------------------------------------------------------------------------- |
| `onSubmit` | Validate on submission and then revalidate on each value change. This is the default value. |
| `onBlur`   | Validate when field loses focus.                                                            |
| `onChange` | Validate every time the value changes.                                                      |

The keys of `errors` correspond to `name` of `Field` . The value specifies the message to display. When used with `errorMatches` on the `Field` side, native validation messages can also be displayed in Japanese.

## Submit values ​​and imperative validation [#actions]

The first argument of `onFormSubmit` is passed an object of input values ​​with `name` as the key. The second argument contains the sending details.

```tsx
<Form
  onFormSubmit={(values, details) => {
    console.log(values, details.reason);
  }}
>
  {/*field*/}
</Form>
```

`actionsRef` allows you to perform validation from outside the form. In addition to validating all fields, you can validate only specific field names.

```tsx
const actionsRef = React.useRef<Form.Actions>(null);

<Form actionsRef={actionsRef}>{/*field*/}</Form>;

actionsRef.current?.validate();
actionsRef.current?.validate("email");
```

## Styling [#styling-hooks]

The root element is given `sui_form` . The Form is arranged as a vertical flex container, and `--sui_form-gap` allows you to adjust the spacing between child elements.

```tsx
<Form style={{ "--sui_form-gap": "1.5rem" } as React.CSSProperties}>{/*field*/}</Form>
```
