Suru UI components can be categorized by usage such as forms, navigation, overlays, and data display. On each page you can find usage examples, props, and style hooks.

First of all, reading [Button ](/components/button) and [Badge ](/components/badge) ] will make it easier to understand the relationship between Suru UI presets, parts, and `slotProps` . The common design of components is described in Component Structure ](/guides/component-anatomy) .

## operation [#action-components]

A component that accepts user operations.

| Component                                  | Description                        |
| ------------------------------------------ | ---------------------------------- |
| [Button ](/components/button)              | Represents a clickable action.     |
| [ToggleButton ](/components/toggle-button) | A button that has a pressed state. |
