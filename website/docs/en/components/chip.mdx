Chips are small labels that display tags, attributes, and short state. Used to represent list filtering conditions or labels attached to items. If you replace `render` with `button` element, it can also be used as a pushable tip.

## Basic usage [#basic-usage]

Specify the text and icon to be displayed on `children` . Load the icon from `lucide-react` etc., and add `aria-hidden="true"` if it is for decoration.

<Component path="chip/basic" />

If you want the chip itself to be operational, pass the `button` element to `render` . If the content is only an icon, please supplement the name with `aria-label` .

```tsx
<Chip render={<button type="button" />} onClick={removeTag} aria-label="remove tag">
  design
  <XIcon aria-hidden="true" />
</Chip>
```

## Appearance [#appearance]

`variant` can be selected from `solid` , `naked` , `liquid` . Specify the color scheme with `color` , the size with `size` , and the rounded corners with `radius` .

<Component path="chip/appearance" />

Specifying `outlined` will add a border. The default `radius` is `full` , which results in a rounded tip.

## Styling [#styling-hooks]

The root element is given `sui_chip` . Depending on the props, the following class names will also be added:

| Class name                     | Condition                           |
| ------------------------------ | ----------------------------------- |
| `sui_chip`                     | Always given.                       |
| `sui_chip-size_sm` etc.        | Granted according to `size` .       |
| `sui_chip-color_blue` etc.     | Granted according to `color` .      |
| `sui_chip-radius_full` etc.    | Granted according to `radius` .     |
| `sui_chip-variant_liquid` etc. | Granted according to `variant` .    |
| `sui_chip-outlined`            | Granted when `outlined` is `true` . |

In addition to adjusting `className` and `style` , you can override margins and font size using the CSS variable `--sui_chip-*` .
