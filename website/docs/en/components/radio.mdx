Radio is a radio button selecting one of several options. Selection state is managed by [RadioGroup](/components/radio-group), so Radio is normally used inside one. Give each Radio in the same group a unique `value`.

## Basic usage [#basic-usage]

Place Radios inside a RadioGroup, wrapping each label text in a `label` element. Pressing the label also selects the option, making the whole row clickable.

<Component path="radio/basic" />

`children` renders inside the indicator and is not the label. Normally omit it and use the default indicator. Always associate the label with a `label` element or similar.

```tsx
<RadioGroup defaultValue="a">
  <label>
    <Radio value="a" />
    選択肢 A
  </label>
  <label>
    <Radio value="b" />
    選択肢 B
  </label>
</RadioGroup>
```

## Appearance [#appearance]

Use `color`, `size`, `radius`, `variant`, and `outlined` for appearance. Inside a RadioGroup, group-level values take precedence over individual Radio values.

<Component path="radio/appearance" />

## States [#states]

`disabled` disables the radio button, `readOnly` makes it unchangeable, and `required` makes selection mandatory on form submission. To disable a whole group, use RadioGroup's `disabled`.

## Styling [#styling-hooks]

The root element carries `sui_radio`. Depending on props and state, class names such as `sui_radio-size_md`, `sui_radio-color_blue`, `sui_radio-radius_full`, `sui_radio-variant_naked`, `sui_radio-outlined`, `sui_radio-checked`, `sui_radio-disabled`, and `sui_radio-focused` are added.

The indicator carries `sui_radio_indicator`, plus `sui_radio_indicator-checked` when selected.
