Popover shows supplementary content or actions in a popup when a trigger such as a button is pressed. It holds richer content than a menu, making it suitable for settings descriptions or account info. Trigger and content are linked automatically, with focus and Escape-key handling built in.

## Basic usage [#basic-usage]

Pass the element that opens the popup to `trigger` and the popup content to `children`. By default it appears 8px below the trigger.

<Component path="popover/basic" />

Popover internally composes a trigger, portal, positioner, and popup. Place headings and descriptions inside `children`.

```tsx
<Popover trigger={<Button>詳細を表示</Button>}>
  <h3>共有の設定</h3>
  <p>リンクを知っている人だけが閲覧できます。</p>
</Popover>
```

## Placement and arrow [#placement]

Use `slotProps.positioner` `side` and `align` for position and `sideOffset` for the distance from the trigger. `arrow` set to `true` shows an arrow on the popup.

<Component path="popover/placement" />

`side` accepts `"top"`, `"bottom"`, `"left"`, or `"right"`; `align` accepts `"start"`, `"center"`, or `"end"`. Near viewport edges the position adjusts automatically to stay visible.

## Controlled open state [#controlled]

Use `open` and `onOpenChange` to manage open state externally. Use `defaultOpen` to start open uncontrolled.

<Component path="popover/controlled" />

Passing `true` to `modal` restricts interaction outside the popup. The default is `false`.

## Appearance [#appearance]

Use `size` for popup size and `radius` for corners. Passing `false` to `outlined` removes the border so content is separated by background alone.

### slotProps [#slot-props]

| Key          | Description                                                                          |
| ------------ | ------------------------------------------------------------------------------------ |
| `arrow`      | Props passed to the arrow. Specifying this key shows the arrow even without `arrow`. |
| `backdrop`   | Props passed to the Backdrop. Specifying this key shows it even without `backdrop`.  |
| `popup`      | Props passed to the popup. Accepts `style`, `className`, etc.                        |
| `portal`     | Props passed to the portal.                                                          |
| `positioner` | Props passed to the positioner. Accepts `side`, `align`, `sideOffset`, etc.          |
| `trigger`    | Props passed to the trigger. `children` and `handle` cannot be specified here.       |

## Styling [#styling-hooks]

Popover itself renders no HTML element, so there is no root class. The trigger carries `sui_popover_trigger`, the positioner `sui_popover_positioner`, and the popup `sui_popover_popup`.

The popup also gains class names such as `sui_popover_popup-size_md`, `sui_popover_popup-radius_md`, `sui_popover_popup-side_bottom`, `sui_popover_popup-align_center`, `sui_popover_popup-outlined`, and `sui_popover_popup-open`. The arrow carries `sui_popover_arrow` and the Backdrop `sui_popover_backdrop`.
