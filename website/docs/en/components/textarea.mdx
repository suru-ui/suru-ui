Textarea inputs multiline text. Use it for inquiries, notes, and other long-form content. It accepts the same attributes as the native `textarea`, so it fits easily into existing forms.

## Basic usage [#basic-usage]

Specify the visible row count with `rows`. When omitted, the browser default applies. `placeholder` and `defaultValue` also pass through.

<Component path="textarea/basic" />

To add a label or description, wrap with `Field`. Validation and error display also group into `Field`.

```tsx
<Field label="Inquiry" description="Please be as detailed as possible.">
  <Textarea rows={4} placeholder="Inquiry" />
</Field>
```

## Appearance [#appearance]

`variant` accepts `naked` or `liquid`. Combine `size`, `radius`, `color`, and `outlined` to match surrounding forms.

<Component path="textarea/appearance" />

`size` has 3 steps: `sm`, `md`, `lg`. `radius` defaults to the same value as `size`.

## Control and states [#controlled-and-states]

To manage the input value yourself, combine `value` and `onValueChange`. Useful for character counts and other input-dependent logic.

<Component path="textarea/controlled" />

`disabled` disables input itself; `readOnly` makes the value unchangeable. Combining a validation error with `Field` `invalid` reflects it in the border color.

## Styling [#styling-hooks]

The root element is a `textarea` carrying `sui_textarea`. Depending on props, class names such as `sui_textarea-size_md`, `sui_textarea-color_blue`, `sui_textarea-radius_md`, `sui_textarea-variant_naked`, and `sui_textarea-outlined` are added.

Depending on state, `sui_textarea-focused`, `sui_textarea-filled`, `sui_textarea-invalid`, `sui_textarea-valid`, `sui_textarea-disabled`, `sui_textarea-dirty`, and similar classes are added.
