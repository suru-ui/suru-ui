Pagination navigates list or search-result pages. It builds page-number buttons plus previous/next buttons from the total page count, highlights the current page, and collapses skipped ranges into an ellipsis that opens a jump search.

## Basic usage [#basic-usage]

Pass the total page count to `totalPages`. The initial page is set with `defaultPage`, defaulting to page 1 when omitted.

<Component path="pagination/basic" />

Page-number buttons mark the current page with `aria-current="page"`. The previous/next buttons disable automatically on the first and last pages.

## Visible range [#page-range]

`siblingCount` sets how many pages to show before and after the current page; `boundaryCount` sets how many to always show at the start and end. Both default to `1`.

<Component path="pagination/range" />

Gaps between pages render as an ellipsis (…). Pressing it opens a popup where you can filter by page number and jump.

## Controlled pages [#controlled]

Use `page` and `onPageChange` to manage the current page in external state. The second `onPageChange` argument carries a `reason` describing what triggered the move.

<Component path="pagination/controlled" />

`reason` is `"item"` for page-number buttons, `"previous"` for the previous button, `"next"` for the next button, and `"ellipsis"` for ellipsis jumps.

## Appearance [#appearance]

`color` applies to the current page and the previous/next buttons. The ellipsis always uses `"grey"`. Use `size` for scale and `radius` for corners.

<Component path="pagination/appearance" />

`disabled` disables all page navigation.

### Inherited props [#inherited-props]

The Pagination root renders as a `nav` element, so it accepts `aria-label`, `className`, `style`, `data-*`, and similar attributes. The default `aria-label` is `"ページネーション"`.

Page-number and previous/next buttons are based on Button, so `disabled`, `aria-label`, and similar settings can be applied per part through `slotProps`.

### slotProps [#slot-props]

| Key              | Description                                                                                  |
| ---------------- | -------------------------------------------------------------------------------------------- |
| `ellipsis`       | Props passed to every ellipsis. `start` and `end` are not overridden.                        |
| `item`           | Props passed to every page-number button. `children`, `page`, `selected` are not overridden. |
| `nextButton`     | Props passed to the next-page button.                                                        |
| `previousButton` | Props passed to the previous-page button.                                                    |

## Styling [#styling-hooks]

The root element carries `sui_pagination`. Depending on props and state, class names such as `sui_pagination-size_md`, `sui_pagination-color_blue`, `sui_pagination-radius_md`, and `sui_pagination-disabled` are added.

Inner parts carry `sui_pagination_item`, `sui_pagination_item-selected`, `sui_pagination_previous`, `sui_pagination_next`, `sui_pagination_ellipsis`, and similar class names.
