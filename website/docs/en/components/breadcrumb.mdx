Breadcrumb shows the hierarchy up to the current page as a breadcrumb list. It communicates the location within the site and makes upper pages easy to reach. Listing items in `items` treats the last item as the current page.

## Basic usage [#basic-usage]

Each entry in `items` takes a `label` and an `href`. Items without `href` render as plain items with no destination. The last item is automatically treated as the current page and rendered as a `span` with `aria-current="page"`.

<Component path="breadcrumb/basic" />

Passing `current` explicitly marks an item other than the last as the current page. Passing `disabled` as `true` disables that item's link.

```tsx
<Breadcrumb
  items={[
    { href: "/", label: "Home" },
    { href: "/products", label: "Products", disabled: true },
    { label: "Suru UI" },
  ]}
/>
```

## Collapsed [#collapsed]

With `maxItems`, items beyond that count collapse into an ellipsis. Pressing the ellipsis opens a list to pick the hidden items.

<Component path="breadcrumb/collapsed" />

Values of `maxItems` below 3 are treated as 3. The first item and the trailing items are kept; the rest collapse. When `items` fits within `maxItems`, no collapsing occurs.

## Link states [#link-states]

Items with `disabled` can no longer navigate to their destination. The current-page item renders as a `span` rather than a link, with no `href`.

<Component path="breadcrumb/states" />

Use `slotProps.link` to pass the same props to every link. However, `children`, `current`, and `href` are overridden by each item's values.

### Inherited props [#inherited-props]

Breadcrumb renders a `nav`, so it accepts attributes such as `className`, `style`, `id`, `aria-*`, and `data-*`. The default `aria-label` is the Japanese equivalent of "Breadcrumb". Remaining props are inherited from the base `nav` element.

## Styling [#styling-hooks]

The root element gets `sui_breadcrumb`. Depending on props, class names such as `sui_breadcrumb-size_md` and `sui_breadcrumb-color_grey` are added.

Inner parts get `sui_breadcrumb_list`, `sui_breadcrumb_item`, `sui_breadcrumb_link`, and `sui_breadcrumb_separator`. The current-page link also gets `sui_breadcrumb_link-current`, and disabled links get `sui_breadcrumb_link-disabled`.

You can adjust them with `className` or `style`, or override spacing and text color with CSS variables.
