Input is a component that displays input fields such as text and email addresses. It is based on Base UI's Input, and you can pass the attributes accepted by the native input element as is. If you want to combine labels, explanations, and errors, combine it with `Field` or `Label` .

## Basic usage [#basic-usage]

Specify the type of input item with `type` . If omitted, `"text"` will be used. When `htmlFor` of `Label` and `id` of `Input` are aligned, the label and input field will be associated.

<Component path="input/basic" />

`Field` allows you to manage labels, descriptions, and error displays all at once. `Input` reads the validation state of `Field` and changes the border color when it is an invalid value.

## Appearance [#appearance]

`variant` can be selected from `naked` and `liquid` . `outlined` specifies the presence or absence of a border, `size` specifies the height and font size, and `radius` specifies the size of rounded corners. `color` is used for the border color when focused.

<Component path="input/appearance" />

`radius="full"` will be capsule-shaped and `radius="circle"` will be perfectly circular. `circle` is suitable for cases where you want input fields to appear round, such as search buttons.

## state and control [#states]

Specifying `value` and `onValueChange` allows input values ​​to be managed in external state. Use `defaultValue` to specify an initial value without control. `disabled` and `readOnly` affect both appearance and operation.

<Component path="input/states" />

`onValueChange` accepts a string of input values. Even if you want to treat it as a number, first receive it as a string and convert it as necessary.

## Styling [#styling-hooks]

The root element is given `sui_input` . Class names such as `sui_input-size_md` , `sui_input-color_grey` , `sui_input-radius_md` , `sui_input-variant_naked` , `sui_input-outlined` are also added depending on the props.

`sui_input-valid` , `sui_input-invalid` , `sui_input-unverified` , `sui_input-disabled` , `sui_input-touched` , `sui_input-dirty` , `sui_input-filled` , `sui_input-focused` are assigned depending on the verification state and operation state.

You can adjust the appearance with CSS variables such as `--sui_input-min_height` , `--sui_input-padding_inline` , `--sui_input-border_radius` , and `--sui_input-focusring_width` .
