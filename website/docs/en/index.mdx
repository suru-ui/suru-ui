Suru UI is a UI component library for React. It provides components for building applications, including forms, navigation, overlays, and data display.

## Documentation structure [#documentation-structure]

This site follows the Diátaxis approach, with four sections matched to reader goals.

| Section         | Purpose                  | When to use                                   |
| --------------- | ------------------------ | --------------------------------------------- |
| Getting started | Learn by doing           | Using Suru UI for the first time              |
| Guides          | Solve specific problems  | Composing components, customizing appearance  |
| Components      | Look up specifications   | Checking props, states, and CSS hooks         |
| Explanation     | Understand design intent | Learning the roles of presets, parts, Base UI |
