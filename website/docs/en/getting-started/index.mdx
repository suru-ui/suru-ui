## Prerequisites [#prerequisites]

This tutorial assumes the following environment.

- React 19
- A dev environment that can build JSX

TypeScript is not required, but code examples in this documentation use TypeScript. Suru UI type definitions are included in the package.

## How to learn [#how-to-learn]

1. Install packages and CSS in [Installation](/getting-started/installation).
2. Build a real button in [Your first Button](/getting-started/first-button).
3. See [Guides](/guides) for component structure and customization.
4. Find a component in the [component list](/components).
