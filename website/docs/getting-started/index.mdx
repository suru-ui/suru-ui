## 前提 [#prerequisites]

次の環境を前提としています。

- React 19
- JSX をビルドできる開発環境

TypeScript は必須ではありませんが、このドキュメントのコード例は TypeScript で記述しています。Suru UI の型定義はパッケージに含まれています。

## 進め方 [#how-to-learn]

1. [インストール](/getting-started/installation)でパッケージと CSS を導入します。
2. [はじめての Button](/getting-started/first-button)で、実際にボタンを作ります。
3. コンポーネントの構造やカスタマイズ方法は[ガイド](/guides)を参照してください。
4. 目的のコンポーネントを[コンポーネント一覧](/components)から探せます。
