## 構成

```tsx
import * as Button from "@suru-ui/react/button";

<Button.Root>
  <Button.Content />
  <Button.Pending>
    <Button.CircularProgress>
      <Button.CircularProgressTrack />
      <Button.CircularProgressFill>
        <Button.CircularProgressFillRotation />
      </Button.CircularProgressFill>
    </Button.CircularProgress>
  </ButtonPending>
</ButtonRoot>
```

## API リファレンス

### Button

`Button` は `Root` のプロパティーに加えて、以下のプロパティーを受け入れます:

<TypeTable
  type={{
    children: {
      type: "React.ReactNode",
      description: "ボタンの内容です。Content スロットとして表示されます。",
    },
    indeterminate: {
      type: "boolean",
      description:
        "保留状態のプログレスバーを不定モードで表示するかどうかを指定します。CircularProgress スロットに渡されます。",
    },
    percentage: {
      type: "number",
      description:
        "保留状態の進行状況をパーセンテージ（0〜100）で指定します。未定義または負の値の場合は不定モードになります。CircularProgress スロットに渡されます。",
    },
    slotProps: {
      type: "{ content?: Button.Content.Props; pending?: Button.Pending.Props; circularProgress?: Button.CircularProgress.Props; circularProgressTrack?: Button.CircularProgressTrack.Props; circularProgressFill?: Button.CircularProgressFill.Props; circularProgressFillRotation?: Button.CircularProgressFillRotation.Props }",
      description:
        "各パーツに個別のプロパティーを渡すためのオブジェクトです。各パーツのプロパティーが優先されます。",
    },
  }}
/>

### Root

`ButtonRoot` は [Base UI が受け入れるプロパティー](https://base-ui.com/react/components/button#api-reference) に加えて、以下のプロパティーを受け入れます:

<TypeTable
  type={{
    color: {
      type: '"blue" | "green" | "grey" | "magenta" | "orange" | "purple" | "red" | "yellow"',
      default: '"grey"',
      description: "ボタンの色を指定します。",
    },
    muted: {
      type: "boolean",
      default: "false",
      description: "背景色を控えめにします。",
    },
    outlined: {
      type: "boolean",
      default: "false",
      description: "枠線を表示するかどうかを指定します。",
    },
    pending: {
      type: "boolean",
      default: "false",
      description:
        "true の場合、ボタンは無効化され、Pending スロットが表示される保留状態（ローディング中）になります。",
    },
    radius: {
      type: '"full" | "sm" | "md" | "lg" | "none"',
      default: "size",
      description:
        'ボタンの角丸を指定します。"none" は角を直角にし、"rounded" は標準的な角丸、"full" は完全な丸形（pills 状）になります。',
    },
    size: {
      type: '"sm" | "md" | "lg"',
      default: '"md"',
      description: "ボタンのサイズを指定します。",
    },
    squared: {
      type: "boolean",
      default: "false",
      description:
        "true の場合、幅と高さが等しくなり、アイコンボタンなどに適した正方形になります。",
    },
    variant: {
      type: '"solid" | "naked" | "liquid"',
      default: '"solid"',
      description:
        'ボタンの主な外観を指定します。"solid" は塗りつぶしスタイル、"naked" は背景のないテキストのみ、"liquid" は薄い塗りつぶしになります。',
    },
  }}
/>
