## 使い方

```tsx
import { Avatar } from "@suru-ui/react";
// または、
import { Avatar } from "@suru-ui/react/avatar";

<Avatar src="https://example.com/avatar.png" alt="山田 太郎" />;
```

<Component path="react/avatar/basic" />

`src` の代わりに `children` を指定すると、画像の代わりにフォールバックを表示します。イニシャルやアイコンなどを指定してください。

<Component path="react/avatar/fallback" />

## 例

### 画像

`src` に画像の URL を指定すると画像を表示し、`alt` で代替テキストを指定します。画像を読み込めないときはフォールバックに切り替わります。

<Component path="react/avatar/image" />

### 色

フォールバックの背景色を指定します。

## 構成

```tsx
import * as Avatar from "@suru-ui/react/avatar";

<Avatar.Root>
  <Avatar.Image />
  <Avatar.Fallback />
</Avatar.Root>
```

## API リファレンス

### Avatar

`Avatar` は `Root` のプロパティーに加えて、以下のプロパティーを受け入れます:

      type: "string",

    alt: {

  }}

### Image

アバターの画像をレンダリングします。画像の読み込みに失敗すると、`Avatar.Fallback` を表示します。

[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/avatar#api-reference) を受け入れます。

### Fallback

画像を表示できないときのフォールバックをレンダリングします。

[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/avatar#api-reference) を受け入れます。
