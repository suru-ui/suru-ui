---
title: Progress
description: 時間のかかる処理の進捗を表示するコンポーネントです。
---

## 使い方

```tsx
import { Progress } from "@suru-ui/react";
// または、
import { Progress } from "@suru-ui/react/progress";

<Progress value={70} />;
```

`value` プロパティーには現在の値を指定します。既定では `0` から `100` の範囲に対する割合で表示されます。

<Component path="react/progress/basic" />

`label` プロパティーを指定するとラベルが表示され、現在値も同時に表示されます。

<Component path="react/progress/label" />

`value` プロパティーに `null` を指定すると、不確定状態になります。不確定状態ではインジケーターがアニメーションします。

<Component path="react/progress/indeterminate" />

### 操作と連動

`useProgress` フックで作った疑似ダウンロードの進捗を、ボタンの操作と連動させてゲージに表示します。ファイルサイズの取得中は不確定状態になり、読み込みが始まると現在値が表示されます。

<Component path="react/progress/interactive" />

## 構成

```tsx
import * as Progress from "@suru-ui/react/progress";

<Progress.Root>
  <Progress.Label />
  <Progress.Value />
  <Progress.Track>
    <Progress.Indicator />
  </Progress.Track>
</Progress.Root>;
```
