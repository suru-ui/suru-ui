---
title: Meter
description: 数値の範囲内にある現在値を表示するメーターコンポーネントです。
---

## 使い方

```tsx
import { Meter } from "@suru-ui/react";
// または、
import { Meter } from "@suru-ui/react/meter";

<Meter value={70} />;
```

`value` プロパティーには現在の値を指定します。既定では `0` から `100` の範囲に対する割合で表示されます。

<Component path="react/meter/basic" />

`label` プロパティーを指定するとラベルが表示され、現在値も同時に表示されます。

<Component path="react/meter/label" />

## 構成

```tsx
import * as Meter from "@suru-ui/react/meter";

<Meter.Root>
  <Meter.Label />
  <Meter.Value />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
</Meter.Root>;
```

## API リファレンス

### Meter

`Meter` は `Root` のプロパティーに加えて、以下のプロパティーを受け入れます:

    slotProps: {
