title: Chip
description: 短いラベルや属性を表示するチップコンポーネントです。
---

## 使い方

```tsx
import { Chip } from "@suru-ui/react";
// または、
import { Chip } from "@suru-ui/react/chip";

<Chip>ラベル</Chip>;
```

<Component path="react/chip/basic" />

## 例

### 主な外観

`"solid"` は塗りつぶし、`"naked"` は背景のないテキストのみ、`"liquid"` は薄い塗りつぶしになります。

## 構成

```tsx
import * as Chip from "@suru-ui/react/chip";

<Chip.Root />;
```

## API リファレンス
