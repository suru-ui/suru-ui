---
title: Avatar Group
description: 複数のアバターを重ねて表示するコンポーネントです。表示するアバターの最大数を超えると、余剰分を省略アバターで表示します。
---

## 使い方

```tsx
import { Avatar } from "@suru-ui/react/avatar";
import { AvatarGroup } from "@suru-ui/react/avatar-group";

<AvatarGroup>
  <Avatar src="https://example.com/a.png" alt="山田 太郎" />
  <Avatar src="https://example.com/b.png" alt="鈴木 花子" />
  <Avatar src="https://example.com/c.png" alt="佐藤 次郎" />
</AvatarGroup>
```

<Component path="react/avatar-group/basic" />

`AvatarGroup` の子に置かれた `Avatar` は、グループから色・角丸・大きさを受け取ります。個々の `Avatar` に明示的に指定した場合は、そちらが優先されます。

### 余剰分

子アバターが `max` (既定値: `4`) を超えると、超過分は `+N` の形式で省略アバターにまとめられます。省略アバターも `max` に含まれます。

<Component path="react/avatar-group/surplus" />

## 例

### 色

`color` に `"auto"` を指定すると、子アバターごとに背景色を自動で割り当てます。特定の色を指定した場合は、すべてのアバターにその色が使われます。

## 構成

```tsx
import * as AvatarGroup from "@suru-ui/react/avatar-group";

<AvatarGroup.Root>
  <Avatar />
  <Avatar />
  <AvatarGroup.Surplus>+3</AvatarGroup.Surplus>
</AvatarGroup.Root>
```
