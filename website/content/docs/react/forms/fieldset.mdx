title: Fieldset
description: 関連するコントロールを凡例とともにグループ化するコンポーネントです。
---

## 使い方

```tsx
import { Fieldset } from "@suru-ui/react";
// または、
import { Fieldset } from "@suru-ui/react/fieldset";

<Fieldset>
  <Fieldset.Legend>お支払い情報</Fieldset.Legend>
</Fieldset>;
```

`Fieldset.Legend` で凡例を表示します。`disabled` を指定すると、グループ内のすべてのコントロールが無効になります。

<Component path="react/fieldset/basic" />

## 構成

```tsx
import * as Fieldset from "@suru-ui/react/fieldset";

<Fieldset.Root>
  <Fieldset.Legend />
</Fieldset.Root>;
```

## API リファレンス

### Fieldset

`Fieldset` は `Root` と同じプロパティーを受け入れます。

### Root

`Fieldset.Root` は [Base UI が受け入れるプロパティー](https://base-ui.com/react/components/fieldset#api-reference) を受け入れます。

### Legend

`Fieldset.Legend` は [Base UI が受け入れるプロパティー](https://base-ui.com/react/components/fieldset#api-reference) を受け入れます。
