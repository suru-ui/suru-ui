## 構成

```tsx
import * as TextField from "@suru-ui/react/text-field";

<TextField.Root>
  <TextField.Addon />
  <TextField.Input />
  <TextField.Addon />
</TextField.Root>
```

## API リファレンス

### TextField

`TextField` は `Root` のプロパティーに加えて、以下のプロパティーを受け入れます:

### Root

文字入力欄の入力欄と Addon をまとめるルート要素です。指定したスタイルプロパティーは、子パーツへ継承されます。

/>

### Input

文字入力欄の入力欄です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/input#api-reference) を受け入れます。

`type` プロパティーには、ボタンやチェックボックスなどの入力項目以外の値を指定できます。

### Addon
