title: NumberField

## 使い方

```tsx
import { NumberField } from "@suru-ui/react";
// または、
import { NumberField } from "@suru-ui/react/number-field";

<NumberField defaultValue={100} />;
```

`decrement` と `increment` を指定すると増減ボタンを表示し、`scrubArea` を指定するとラベルのドラッグで値を変更できます。

## 構成

```tsx
import * as NumberField from "@suru-ui/react/number-field";

<NumberField.Root>
  <NumberField.ScrubArea>
    <NumberField.ScrubAreaCursor />
  </NumberField.ScrubArea>
  <NumberField.Group>
    <NumberField.Addon />
    <NumberField.Input />
    <NumberField.Addon />
    <NumberField.Addon>
      <NumberField.Decrement />
    </NumberField.Addon>
    <NumberField.Addon>
      <NumberField.Increment />
    </NumberField.Addon>
  </NumberField.Group>
</NumberField.Root>
```

### Group

入力欄と増減ボタンをまとめるグループ要素です。入力欄以外の場所をクリックすると、入力欄へフォーカスします。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/number-field#api-reference) を受け入れます。

### Input

数値の入力欄です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/number-field#api-reference) を受け入れます。

### Addon

### Decrement

値を減らすボタンです。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/number-field#api-reference) を受け入れます。

### Increment

値を増やすボタンです。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/number-field#api-reference) を受け入れます。

### ScrubArea

ドラッグで値を変更できる領域を提供するコンポーネントです。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/number-field#api-reference) を受け入れます。

### ScrubAreaCursor

スクラブ中にネイティブカーソルの代わりに表示する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/number-field#api-reference) を受け入れます。
