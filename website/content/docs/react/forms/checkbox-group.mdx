## 使い方

```tsx
import { Checkbox } from "@suru-ui/react/checkbox";
import { CheckboxGroup } from "@suru-ui/react";
// または、
import { Checkbox } from "@suru-ui/react/checkbox";
import { CheckboxGroup } from "@suru-ui/react/checkbox-group";

<CheckboxGroup defaultValue={["option-a"]}>
  <label className="flex items-center gap-2">
    <Checkbox value="option-a" />
    オプション A
  </label>
  <label className="flex items-center gap-2">
    <Checkbox value="option-b" />
    オプション B
  </label>
</CheckboxGroup>;
```

`Checkbox` の `value` プロパティーが、グループの選択状態における項目の値になります。グループに指定したスタイルは子要素のチェックボックスより優先され、値を変更するとグループ内へ反映されます。各 `Checkbox` のプロパティーについては、[Checkbox](/docs/react/forms/checkbox/) を参照してください。

## 例

### 親チェックボックス

`parent` プロパティーを指定した `Checkbox` と、グループの `allValues` プロパティーを組み合わせると、「すべて選択」の親チェックボックスを作れます。親をクリックすると全子要素を選択し、子要素の選択状況に応じて親はチェックまたは中間状態になります。

<Component path="react/checkbox-group/parent" />

### 横並び

`orientation` プロパティーに `"horizontal"` を指定すると、チェックボックスを横並びで配置します。

<Component path="react/checkbox-group/horizontal" />

### 無効

グループに `disabled` プロパティーを指定すると、グループ内のすべてのチェックボックスを無効にします。

<Component path="react/checkbox-group/disabled" />

## 構成

```tsx
import * as Checkbox from "@suru-ui/react/checkbox";
import * as CheckboxGroup from "@suru-ui/react/checkbox-group";

<CheckboxGroup.Root>
  <Checkbox.Root>
    <Checkbox.Indicator />
  </Checkbox.Root>
</CheckboxGroup.Root>;
```
