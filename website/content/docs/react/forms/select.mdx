title: Select
description: 定義済みの項目から値を選択するコンポーネントです。
---

## 使い方

```tsx
import { Select } from "@suru-ui/react";
// または、
import { Select } from "@suru-ui/react/select";

<Select items={["りんご", "ばなな", "ぶどう"]} label="果物" />;
```

`items` には選択項目の一覧を指定します。`multiple` を指定すると複数の値を選択できます。項目が多く、入力による絞り込みが必要な場合は Combobox を使用してください。

## 構成

```tsx
import * as Select from "@suru-ui/react/select";

<Select.Root>
  <Select.Label />
  <Select.Trigger>
    <Select.Value />
    <Select.Icon />
  </Select.Trigger>
  <Select.Portal>
    <Select.Backdrop />
    <Select.Positioner>
      <Select.Popup>
        <Select.ScrollUpArrow />
        <Select.Arrow />
        <Select.List>
          <Select.Group>
            <Select.GroupLabel />
            <Select.Item>
              <Select.ItemIndicator />
              <Select.ItemText />
            </Select.Item>
          </Select.Group>
          <Select.Separator />
        </Select.List>
        <Select.ScrollDownArrow />
      </Select.Popup>
    </Select.Positioner>
  </Select.Portal>
</Select.Root>
```

### Root

選択状態とポップアップの開閉状態を管理する Select のルートです。それ自身は HTML 要素をレンダリングせず、スタイルを子パーツへ伝播します。`SelectRoot` は [Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) に加えて、以下のプロパティーを受け入れます:

### Label

選択欄に対応する表示ラベルです。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Trigger

Select ポップアップを開閉するボタン要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Value

現在の選択値またはプレースホルダーを表示する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Icon

ポップアップの開閉を示すアイコンのラッパー要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Portal

ポップアップを DOM の別の場所へ移動する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Backdrop

ポップアップの背後に表示される要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Positioner

ポップアップをトリガーへ位置合わせする要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Popup

選択項目を表示するポップアップ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### List

選択項目を列挙するリスト要素です。スクロール可能な領域でラップされます。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Arrow

ポップアップとトリガーをつなぐ矢印要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Item

選択肢の個々の項目です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### ItemText

選択肢の表示テキストを包む要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### ItemIndicator

選択された項目を示す要素です。既定では選択されていないときも DOM 内に維持されます。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### ScrollUpArrow

上方向へスクロールできることを示す要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### ScrollDownArrow

下方向へスクロールできることを示す要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Group

関連する選択肢をまとめるグループ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### GroupLabel

選択肢グループの見出し要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。

### Separator

項目やグループを区切る要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/select#api-reference) を受け入れます。
