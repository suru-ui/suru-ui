## 使い方

```tsx
import { Slider } from "@suru-ui/react";
// または、
import { Slider } from "@suru-ui/react/slider";

<Slider defaultValue={25} />;
```

## 構成

```tsx
import * as Slider from "@suru-ui/react/slider";

<Slider.Root>
  <Slider.Label />
  <Slider.Value />
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>;
```

## API リファレンス

### Slider

`Slider` は `Root` のプロパティーに加えて、以下のプロパティーを受け入れます:

<TypeTable
  type={{
    slotProps: {
      type: "Slider.SlotProps",
      description:
        "各パーツに個別のプロパティーを渡すためのオブジェクトです。各パーツのプロパティーが優先されます。`label` または `value` を指定した場合だけ、対応するパーツが表示されます。",
    },
  }}
/>

### Root

`Slider.Root` は [Base UI が受け入れるプロパティー](https://base-ui.com/react/components/slider#api-reference) に加えて、以下のプロパティーを受け入れます:

### Label

スライダーのラベル要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/slider#api-reference) を受け入れます。

### Value

スライダーの現在値を表示する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/slider#api-reference) を受け入れます。

### Control

スライダーの操作可能な領域です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/slider#api-reference) を受け入れます。

### Track

スライダーのトラック要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/slider#api-reference) を受け入れます。

### Indicator

スライダーの現在値を示すインジケーター要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/slider#api-reference) を受け入れます。

### Thumb

スライダーのつまみ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/slider#api-reference) を受け入れます。
