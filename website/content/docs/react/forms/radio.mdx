## 使い方

```tsx
import { Radio } from "@suru-ui/react";
// または、
import { Radio } from "@suru-ui/react/radio";

<RadioGroup defaultValue="option-a">
  <label className="flex items-center gap-2">
    <Radio value="option-a" />
    オプション A
  </label>
</RadioGroup>;
```

`Radio` は単体では選択状態を管理しないため、RadioGroup の中に置いて使います。`label` 要素で囲むと、ラベルのテキストのクリックでも選択できます。

### 無効

`disabled` プロパティーを指定すると、操作できないラジオボタンを表示します。RadioGroup に `disabled` を指定すると、グループ内のすべてのラジオボタンを無効化できます。

## 構成

```tsx
import * as Radio from "@suru-ui/react/radio";

<Radio.Root>
  <Radio.Indicator />
</Radio.Root>;
```

## API リファレンス

### Radio

`Radio` は `Root` のプロパティーに加えて、以下のプロパティーを受け入れます:

    },
  }}
/>

### Indicator

チェック状態に応じて子要素の表示・非表示を切り替えるインジケーター要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/radio#api-reference) を受け入れます。
