title: Combobox
description: 入力欄で候補を絞り込み、定義済みの項目を選択するコンポーネントです。
---

## 使い方

```tsx
import { Combobox } from "@suru-ui/react";
// または、
import { Combobox } from "@suru-ui/react/combobox";

<Combobox label="果物" items={["りんご", "ばなな", "ぶどう"]} placeholder="果物を選択" />;
```

`items` には候補項目の一覧を指定します。`multiple` を指定すると、選択値をチップとして入力欄内に表示します。

## 構成

```tsx
import * as Combobox from "@suru-ui/react/combobox";

<Combobox.Root>
  <Combobox.Label />
  <Combobox.InputGroup>
    <Combobox.Chips>
      <Combobox.Value>
        <Combobox.Chip>
          <Combobox.ChipRemove />
        </Combobox.Chip>
      </Combobox.Value>
    </Combobox.Chips>
    <Combobox.Input />
    <Combobox.Clear />
    <Combobox.Trigger>
      <Combobox.Icon />
    </Combobox.Trigger>
  </Combobox.InputGroup>
  <Combobox.Portal>
    <Combobox.Positioner>
      <Combobox.Popup>
        <Combobox.Empty />
        <Combobox.List>
          <Combobox.Group>
            <Combobox.GroupLabel />
            <Combobox.Collection>
              <Combobox.Item>
                <Combobox.ItemIndicator />
              </Combobox.Item>
            </Combobox.Collection>
          </Combobox.Group>
        </Combobox.List>
      </Combobox.Popup>
    </Combobox.Positioner>
  </Combobox.Portal>
</Combobox.Root>
```

### Label

トリガーに対応する表示ラベルです。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Value

現在の選択値を子要素へ反映する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Input

候補を検索するテキスト入力欄です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### InputGroup

入力欄と付属コントロールをまとめるグループ要素です。`Root` のスタイルプロパティーがこの要素へ適用されます。

### Trigger

候補リストを開閉するボタン要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Icon

トリガーの操作を示すアイコンのラッパー要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Clear

選択値を消去するボタン要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Chips

複数選択した値を表示するチップのコンテナーです。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Chip

複数選択した値を表すチップ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### ChipRemove

チップを選択値から削除するボタン要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### List

候補項目のリストを表示するコンテナー要素です。スクロール可能な領域でラップされます。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Status

非同期検索などの状態を読み上げる要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Portal

ポップアップを DOM の別の場所へ移動する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Backdrop

ポップアップの背後に表示される要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Positioner

ポップアップを入力欄へ位置合わせする要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Popup

候補項目を表示するポップアップ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Arrow

ポップアップと入力欄をつなぐ矢印要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Group

関連する候補項目をまとめるグループ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### GroupLabel

候補グループの見出し要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Item

候補リストの個々の項目要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### ItemIndicator

項目が選択されていることを示す要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Row

グリッドリストの 1 行を表示する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Collection

フィルタリングされた項目を列挙する要素です。これ自身は HTML 要素をレンダリングしません。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Empty

候補リストが空のときに内容を表示する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。

### Separator

項目やグループを区切る要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/combobox#api-reference) を受け入れます。
