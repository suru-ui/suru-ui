## 使い方

```tsx
import { Checkbox } from "@suru-ui/react";
// または、
import { Checkbox } from "@suru-ui/react/checkbox";

<label className="flex items-center gap-2">
  <Checkbox />
  設定を有効にする
</label>;
```

`Checkbox` を `label` 要素で囲むと、ラベルのテキストのクリックでもチェックを切り替えられます。複数のチェックボックスを選択状態ごとまとめて管理するときは、[CheckboxGroup](/docs/react/forms/checkbox-group/) を使います。

### 中間状態

`indeterminate` プロパティーを指定すると、チェックも未チェックでもない中間状態で表示します。子要素を持つ項目の一部だけが選択されていることを示すときに使います。

### 無効

`disabled` プロパティーを指定すると、操作できないチェックボックスを表示します。

## 構成

```tsx
import * as Checkbox from "@suru-ui/react/checkbox";

<Checkbox.Root>
  <Checkbox.Indicator />
</Checkbox.Root>;
```

### Indicator

チェック状態に応じて子要素の表示・非表示を切り替えるインジケーター要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/checkbox#api-reference) を受け入れます。
