## 使い方

```tsx
import { Radio } from "@suru-ui/react/radio";
import { RadioGroup } from "@suru-ui/react";
// または、
import { Radio } from "@suru-ui/react/radio";
import { RadioGroup } from "@suru-ui/react/radio-group";

<RadioGroup defaultValue="option-a">
  <label className="flex items-center gap-2">
    <Radio value="option-a" />
    オプション A
  </label>
</RadioGroup>;
```

`Radio` の `value` プロパティーが、グループの選択状態における項目の値になります。グループに指定したスタイルは子要素のラジオボタンより優先され、値を変更するとグループ内へ反映されます。各 `Radio` のプロパティーについては、[Radio](/docs/react/forms/radio/) を参照してください。

## 構成

```tsx
import * as Radio from "@suru-ui/react/radio";
import * as RadioGroup from "@suru-ui/react/radio-group";

<RadioGroup.Root />;
```

## API リファレンス

### RadioGroup

`RadioGroup` は `Root` と同じプロパティーを受け入れます。

### Root
