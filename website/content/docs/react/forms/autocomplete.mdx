## 使い方

```tsx
import { Autocomplete } from "@suru-ui/react";
// または、
import { Autocomplete } from "@suru-ui/react/autocomplete";

<Autocomplete items={["東京", "大阪", "京都", "福岡"]} placeholder="都市を検索" />;
```

`items` には文字列や数値などのプリミティブの配列、`{ label }` や `{ label, value }` の形のオブジェクトの配列を指定できます。表示ラベルは各項目から自動的に解決されます。

## 構成

```tsx
import * as Autocomplete from "@suru-ui/react/autocomplete";

<Autocomplete.Root>
  <Autocomplete.InputGroup>
    <Autocomplete.Addon />
    <Autocomplete.Input />
    <Autocomplete.Addon>
      <Autocomplete.Clear />
    </Autocomplete.Addon>
    <Autocomplete.Addon />
    <Autocomplete.Addon />
  </Autocomplete.InputGroup>
  <Autocomplete.Portal>
    <Autocomplete.Positioner>
      <Autocomplete.Popup>
        <Autocomplete.Empty />
        <Autocomplete.ScrollArea>
          <Autocomplete.Viewport>
            <Autocomplete.Content>
              <Autocomplete.List>
                <Autocomplete.Group>
                  <Autocomplete.GroupLabel />
                  <Autocomplete.Collection>
                    <Autocomplete.Item />
                  </Autocomplete.Collection>
                </Autocomplete.Group>
              </Autocomplete.List>
            </Autocomplete.Content>
          </Autocomplete.Viewport>
          <Autocomplete.Scrollbar>
            <Autocomplete.Thumb />
          </Autocomplete.Scrollbar>
          <Autocomplete.Corner />
        </Autocomplete.ScrollArea>
      </Autocomplete.Popup>
    </Autocomplete.Positioner>
  </Autocomplete.Portal>
</Autocomplete.Root>
```

### Clear

入力値を消去するボタン要素です。入力値があるときだけ表示されます。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### List

検索結果のリストを表示するコンテナー要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Group

関連する項目をまとめるグループ要素です。`Root` の `items` にグループの配列を渡したときに使います。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### GroupLabel

グループに自動的に対応付けられるラベル要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Item

リストの個々の項目要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Row

グリッドリストの 1 行を表示する要素です。`Root` の `grid` プロパティーと一緒に使います。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Collection

フィルタリングされた項目を列挙する要素です。これ自身は HTML 要素をレンダリングしません。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Empty

リストが空のときだけ、その children を表示する要素です。この要素自体は常に DOM に残ります。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Status

リストの状態を読み上げるための非表示の要素です。この要素は常に DOM にマウントされたままにしてください。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Portal

ポップアップを DOM の別の場所へ移動する要素です。既定ではポップアップを `<body>` の末尾に配置します。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Positioner

ポップアップを入力欄に位置合わせする要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### Popup

検索結果リストを表示するポップアップ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/autocomplete#api-reference) を受け入れます。

### ScrollArea

検索結果リストをスクロール可能にするスクロール領域のルート要素です。詳細は [ScrollArea](https://base-ui.com/react/components/scroll-area#api-reference) を参照してください。

### Viewport

スクロール領域のうち、コンテンツをクリップしてスクロール操作を受け付けるビューポート要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/scroll-area#api-reference) を受け入れます。

### Content

スクロール領域のうち、スクロールされるコンテンツを保持する要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/scroll-area#api-reference) を受け入れます。

### Scrollbar

スクロール領域のスクロールバー要素です。子要素として `Thumb` を配置します。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/scroll-area#api-reference) を受け入れます。

### Thumb

スクロール位置とスクロール可能な範囲を示す、スクロールバー内のつまみ要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/scroll-area#api-reference) を受け入れます。

### Corner

水平スクロールバーと垂直スクロールバーの交差部分を埋める要素です。[Base UI が受け入れるプロパティー](https://base-ui.com/react/components/scroll-area#api-reference) を受け入れます。
