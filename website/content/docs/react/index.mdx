## インストール

<Tabs>
  <Tab title="pnpm">
    ```bash
    pnpm add @suru-ui/react
    ```
  </Tab>
  <Tab title="npm">
    ```bash
    npm i @suru-ui/react
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add @suru-ui/react
    ```
  </Tab>
  <Tab title="bun">
    ```bash
    bun add @suru-ui/react
    ```
  </Tab>
</Tabs>

すべてのコンポーネントは単一のパッケージに含まれています。Suru UI はツリーシェイキングに対応しているため、バンドル時には実際に使用するコンポーネントのみが含まれます。
