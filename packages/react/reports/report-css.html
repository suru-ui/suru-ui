レポート 1: CSS スタイリングの不統一

対象: packages/react/src/**/*.css（基準の buttons/button/button.css を除く 35 ファイル）  /  基準: .opencode/skills/css/SKILL.md と button.css

概要

検出件数
98
違反のあるファイル
27 / 35

問題の多い順に並べると、余白・背景などの固定スタイルと var() 参照が混在し「静的」「動的」の区別が守られていないファイル（combobox、select、tabs など）、「変数」目録にない公開変数を「既定値設定」で代入しているファイル（alert、chip など）、「静的」セクションに var() 参照が残っているファイル（avatar、scroll-area、tooltip など）があります。

違反のなかった 8 ファイルは avatar-group、checkbox-group、field、fieldset、form、input、radio、radio-group です。

Base UI が Anchor に自動で設定する環境変数（--transform-origin、--anchor-width、--available-width など）は接頭辞なし変数を参照するため規約上は抵触しますが、フレームワーク側の仕組みで避けられないものです。以下の一覧では該当箇所に注記しました。

同じファイル内で同じ種別の複数箇所（例: avatar の「リセット」混入 3 箇所）は 1 行にまとめています。表の行数は検出件数 98 件とは一致しません。
