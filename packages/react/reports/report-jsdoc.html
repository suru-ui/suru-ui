レポート 2: JSDoc とコメントの不統一

対象: packages/react/src/**/*.parts.tsx と *.tsx（基準の button を除く）  /  基準: .opencode/skills/new-component/SKILL.md、.opencode/skills/jsdoc/SKILL.md

概要

検出件数
88
違反のあるファイル
32 / 35

JSDoc の問題は 3 系統に分かれます。

  • 文言の揺れ: namespace の JSDoc は「状態とプロパティーをまとめた型名前空間です」「に対応する型名前空間です」「の型をまとめた名前空間です」の 3 系統、別名 const の JSDoc は「別名です」「短い名前です」「短縮名です」の 3 系統が混在しています。
  • 形式違反: autocomplete と combobox の 2 ファイルだけが 1 行形式 JSDoc（/** ... */）を使っています。基準は常に複数行です。
  • 欠落と誤参照: scroll-area、select、alert、avatar などで JSDoc そのものが欠けています。また多数のファイルで State/Props の {@link} が namespace 自身（{@link Root}）を指しています。

違反のなかった 3 ファイルは checkbox、input、slider です。
